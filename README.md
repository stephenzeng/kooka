# Project Kooka

Kooka tracks Microsoft Learn documentation changes and turns them into AI-friendly content for learning, grounding, and knowledge sharing.

## Purpose

Microsoft product updates are moving faster than ever. Staying current is important, but increasingly challenging.

Project Kooka is designed to help close that gap.

Kooka tracks content changes published across Microsoft Learn documentation for selected Microsoft products and saves those changes in this repository. This allows you to:

- Review recent documentation updates
- Ground AI tools on the generated files
- Repurpose the content into different formats based on your needs

The goal is to make it easier to stay informed about product changes without manually monitoring Microsoft Learn documentation.
