# Microsoft 365 Copilot Extensibility
**Date created:** 2026-09-01 UTC  
**Tags:** Analytics, Best Practices, Configuration, Guidance, Identity, Monitoring, Performance, Security, Troubleshooting  

## New Articles

- **Monitor agents in Agent Builder**

  Introduced a how-to guide for monitoring agents built with Agent Builder, including prerequisites and access requirements. The article explains how to open the Monitor tab, filter by date ranges, and interpret key metrics such as Total sessions, Avg. DAU, Avg. user messages, and Avg. duration. It also covers Engagement and Knowledge charts, and how to review user feedback via Reactions and Comments. Guidance includes enabling agent feedback sharing and links to related Agent Builder resources.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-builder-monitor-agents

## Major Changes

- **Known issues**

  Expanded the known issues and troubleshooting for custom engine agents to set expectations and speed up resolution. Added a new limitation explaining that file downloads generated by agents won’t appear as clickable downloads in Microsoft 365 Copilot, though they work in Teams and the Copilot Studio test panel. Provided fixes for slow or inconsistent responses (including model selection and reducing SharePoint sources), access errors in Teams, missing Microsoft Entra app registrations causing unresponsive agents, and scenarios where agents work in Copilot Studio but not Teams, with precise Teams admin settings to resolve each.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/known-issues

- **Configure OAuth 2.0 authentication**

  Overhauled OAuth guidance for MCP plugins to adopt PKCE by default and prefer public clients (SPA) to avoid client secrets. Clarified runtime settings for MCP servers (OAuthPluginVault) and when to use Dynamic Client Registration, while advising against AzureKeyVault for agent connectors due to schema validation. Updated Teams developer portal guidance to restrict usage to Any Teams app for MCP servers and warned that binding to a specific app ID can cause 404 errors; matching m365agents.yml examples are provided. Added Microsoft Entra ID considerations (no DCR endpoint, no microsoftEntra auth type, no scope consent verification) and explained how to manage auth configs using oauth/update and the Teams developer portal for deletions.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/plugin-authentication-oauth

## Moderate Changes

- **Build API plugins from an existing API for Microsoft 365 Copilot**

  Updated PKCE guidance: PKCE is now enabled by default, and you should only disable it when the provider doesn’t support it by setting isPKCEEnabled: false in m365agents.yml. The documentation and sample were revised to reflect this new default, streamlining secure setup.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/build-api-plugins-existing-api

- **Configure dynamic client registration**

  Added a warning that Dynamic Client Registration isn’t supported for MCP servers protected by Microsoft Entra ID because there’s no RFC 7591 registration endpoint. Guidance now recommends using static OAuth client registration in this scenario and links to configuration documentation.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/plugin-authentication-dynamic-client-registration

- **Show citations with response semantics**

  Clarified that Adaptive Card instructions for citations apply only to declarative agents. Copilot connectors don’t support the staticTemplate property or Adaptive Card rendering for citations.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/plugin-citations
