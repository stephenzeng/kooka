**Date created:** 2026-08-05 UTC

## Moderate Changes

- **Agent Builder in Microsoft 365 Copilot**

  Updated the limitations to remove the Lockbox restriction and clarify that only Customer Managed Keys (CMK) are not supported for agents created using Microsoft 365 Copilot. This clarifies compliance expectations and helps teams plan data protection and key management strategies accordingly.
