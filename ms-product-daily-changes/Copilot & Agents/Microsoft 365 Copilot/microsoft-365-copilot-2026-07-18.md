# Microsoft 365 Copilot
**Date created:** 2026-07-18 UTC  
**Tags:** Administration, Analytics, Governance, Monitoring  

## Moderate Changes

- **Manage Copilot Cowork for your organization**

  Announced general availability and updated the governance model: Cowork is now treated as an agentic system, replacing preview-era agent-based access controls. Reorganized usage-based billing guidance, clarified Copilot Credits setup and consumption, and added a link to the Cowork Usage report to improve visibility into user engagement. Updated Microsoft 365 admin center navigation steps to find Cowork (Agents > All Agents, then select Cowork).

  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-admin-governance

- **Optimize Microsoft 365 Copilot configuration settings**

  Added a Usage-based billing section explaining which AI experiences are enabled, how Copilot Credits work, and tenant-wide visibility. Introduced spend management guidance with limits, budgets, and alerts via centralized tools such as the Cost management dashboard, and linked to related management guidance.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/optimize-microsoft-365-configuration-settings
