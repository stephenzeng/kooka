# Microsoft 365 Copilot
**Date created:** 2026-07-14 UTC  
**Tags:** Agent  

## Moderate Changes

- **Copilot Cowork common questions**
  
  Updated guidance to use “session” terminology and aligned explanations across feature comparison, skills, sensitivity labels, plugins, attachments, navigation, image outputs, and feedback. Refined approvals with a “More options” menu that lets users approve once and skip prompts for the rest of the session, including scoped approvals for email and Teams by recipient, domain, or action.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-faq

- **Use Copilot Cowork**
  
  Updated instructions to use “session”-based wording and overhauled approvals: replaced “Don’t ask again” with a “More options” menu, added an “Approve All” button with pending count, and enabled granular scopes for email and Teams; approvals apply only within the current session and can be reviewed or revoked. Removed risk level indicators and refreshed side panel, scheduling, file handling, previews, image save locations, and feedback guidance to match the latest UI behaviors.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/use-cowork
