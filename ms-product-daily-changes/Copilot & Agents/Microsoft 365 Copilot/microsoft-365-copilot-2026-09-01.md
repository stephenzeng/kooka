# Microsoft 365 Copilot
**Date created:** 2026-09-01 UTC  
**Tags:** Configuration, Deprecation, Governance, Guidance  

## New Articles

- **Org context**

  Introduced a new how-to article explaining how to configure organizational context for the Workforce Insights agent in Microsoft 365 Copilot. It outlines prerequisites (AI Administrator or Organizational Data Source Administrator), setup via the Workforce Insights admin page, and the option to use a markdown template or free text, with changes propagating in up to 15 minutes. The guidance clarifies privacy considerations, including avoiding sensitive data and understanding that context can appear in responses. It also provides testing steps to validate terms, rules, and acronyms, and recommends iterative refinement to prevent unintended effects.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/context

## Moderate Changes

- **Set Up People Skills for Your Organization**

  Streamlined setup by removing the optional role-to-skill mapping file approach and relying on AI inferencing, reducing configuration overhead. Instructions were simplified, example paths now reference Skills_Library.csv, and file path steps were consolidated to improve clarity and speed of deployment.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/people-skills-setup
