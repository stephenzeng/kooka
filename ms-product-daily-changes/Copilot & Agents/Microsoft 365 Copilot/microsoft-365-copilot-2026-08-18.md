## New Articles

- **Microsoft 365 Copilot prompt defense in depth**

  Introduced a comprehensive defense-in-depth approach that safeguards the prompt lifecycle in Microsoft 365 Copilot. Highlights proactive and runtime protections to mitigate prompt injection, data leakage, and unsafe or malicious content. Details controls such as DLP for prompts and web search, block lists and classifier filtering, agent transparency, citations, and egress filtering. Explains how alerts and investigations surface via Microsoft Defender and Purview with audit visibility. Provides guidance and next steps to help security and compliance teams operationalize these protections.  
  https://learn.microsoft.com/en-us/microsoft-365/copilot/copilot-prompt-defense-in-depth
