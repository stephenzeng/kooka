# Microsoft 365 Copilot
**Date created:** 2026-07-16 UTC  
**Tags:** Administration, Agent, AI, Governance, Security  

## Major Changes

- **Microsoft 365 Copilot release notes**

  Added July 15, 2026 release notes covering significant platform and admin enhancements. Introduced governed submission of Agent Builder agents to the Agent Store and tenant-wide publishing of custom prompt collections. Enabled MCP-based agent access in Word, Excel, PowerPoint, Outlook, and Catalyst, plus centralized deployment and management of Federated Copilot connectors. Also refreshed Microsoft Edge v149 UI, added brand kit creation from uploaded guidelines, and expanded connector controls with hierarchical permissions for Confluence and ServiceNow.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes

## Moderate Changes

- **Data, privacy, and security for web search in Microsoft 365 Copilot and Microsoft 365 Copilot Chat**

  Updated guidance so the Web content toggle and related web search controls now apply to both Microsoft 365 Copilot and Microsoft 365 Copilot Chat. Clarified admin behavior when enabling or disabling web search and streamlined user guidance and headings to match the new scope.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/manage-public-web-access

- **Which Copilot is right for me or my organization?**

  Replaced the prior work/web mode selection with a Work IQ toggle and explained outcomes when it’s on (work-grounded results) versus off (results can include both work data and internet content). Removed legacy UI imagery and refined guidance for using the consumer version to reduce confusion.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/which-copilot-for-your-organization
