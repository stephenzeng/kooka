## Moderate Changes

- **Manage Copilot Cowork for your organization**
  Updated the list of image generation models to use ChatGPT Images 2.0, replacing prior references to Imagen 2. This ensures governance guidance reflects current model availability while leaving links and core content unchanged.
  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-admin-governance

- **Copilot Cowork common questions**
  Clarified that Anthropic Claude models may be used as a subprocessor, shifting language from definitive to conditional usage, and confirmed image generation uses ChatGPT Images 2.0. This sets clearer expectations for external model usage and compliance considerations without altering metadata.
  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-faq

- **Use the local browser with Copilot Cowork**
  Added a minimum Microsoft Edge requirement: Edge 150 Stable 2 (150.0.4078.83). This helps admins ensure compatibility and security for local browser scenarios.
  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-local-browser

- **Responsible AI FAQ for Cowork**
  Updated references from Imagen 2 to ChatGPT Images 2.0 across capability descriptions, image generation details, and model routing. This aligns responsible AI disclosures with current model usage.
  https://learn.microsoft.com/en-us/microsoft-365/copilot/responsible-ai/cowork-responsible-ai-faq

- **Get started with Copilot Cowork**
  Removed the prerequisite to enable Anthropic at the tenant level, clarifying that Anthropic models are optional and may be used as a subprocessor. This simplifies setup and clarifies optional integration paths.
  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/get-started
