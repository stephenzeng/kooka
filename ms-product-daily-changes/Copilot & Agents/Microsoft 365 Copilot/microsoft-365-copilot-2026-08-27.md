# Microsoft 365 Copilot
**Date created:** 2026-08-27 UTC  
**Tags:** Configuration, Consumption, Governance, Guidance  

## Moderate Changes

- **Connect to Mistral AI models**

  Updated admin prerequisites to require AI Administrator or Global Administrator and refined enablement to include explicit legal term acceptance, refreshed UI labels, and a new configuration screenshot. Clarified how to assign user or group access at the provider level and added clearer guidance for Copilot Studio controls in the Power Platform admin center. Simplified disablement by directing admins to set access to “No users” and documented role requirements for disabling.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/connect-mistral-ai-models

- **Choose a model for Copilot Cowork**

  Expanded guidance on effort levels: selections now persist across tasks, defaults can vary by model, and availability is clarified for web, Windows, and macOS. Explained that higher effort may be slower and consume more credits, influenced by model choice, context size, orchestration, and tools; streamlined UI guidance by removing prior compose-box instructions.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-models
