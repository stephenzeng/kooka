# Microsoft 365 Copilot
**Date created:** 2026-08-20 UTC  
**Tags:** Compliance, Configuration, Guidance, Security  

## Moderate Changes

- **Choose a model for Copilot Cowork**

  Updated the model picker to clarify providers and data handling across options, including identifying GPT 5.6 Sol and GPT 5.6 Terra as OpenAI models with links to subprocessor details. Standardized “More information” links for Anthropic models (Opus 5 and Claude Sonnet 5) and revised the Claude Fable 5 (Preview) entry to highlight data retention requirements with references. This helps admins make informed, compliant model selections.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-models

- **Release notes, known issues, and limitations for the Employee Self-Service agent**

  Announced Copilot Hub agent support for GPT-5.5 and provided a one-time action: set suppressPlannerResponse: true for each connected agent and republish to prevent duplicate replies. Replaced prior guidance to stay on GPT-4.1 with details on the default-on platform update and the required mitigation to avoid double responses. This enables upgrading to GPT-5.5 while maintaining clean, non-duplicated responses.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/employee-self-service/known-issues-limitations

- **Zero Query Logging Overview**

  Expanded the scope of where Zero Query Logging applies during web grounding to include Copilot Cowork, Researcher, Analyst, Agent builder agents, and Copilot Studio agents published to Microsoft Copilot, in addition to Microsoft Copilot and Copilot Chat. This clarifies privacy expectations across more Copilot experiences and supports governance reviews.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-zero-query-logging
