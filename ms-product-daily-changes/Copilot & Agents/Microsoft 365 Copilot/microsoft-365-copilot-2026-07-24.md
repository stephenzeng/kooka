# Microsoft 365 Copilot
**Date created:** 2026-07-24 UTC  
**Tags:** Administration  

## Moderate Changes

- **Manage plugins for Copilot Cowork**

  Updated admin navigation to manage Cowork plugins under Agents, with entries appearing under All agents or Tools. Clarifies that some agents also act as Cowork plugins and advises verifying Cowork capabilities in the agent description. Helps admins find and manage the correct plugins more reliably.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-manage-plugins

- **Microsoft 365 Copilot pay-as-you-go service overview**

  Clarified that the article covers Microsoft 365 Copilot Chat, SharePoint Agents, and the Copilot Retrieval API (Preview), while billing for Copilot Cowork and the Work IQ API is handled in the Microsoft admin center. This helps readers choose the correct billing path and documentation for their scenario.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/pay-as-you-go/overview

- **Managing AI experiences enabled by usage-based billing**

  Expanded guidance on spending policies, including unlimited policy count, explicit tenant-level defaults, detailed tie‑breaker rules for users in multiple policies, and behavior when policies are deleted. Clarified billing method controls per policy, immutability after creation, P3 layering, and capacity pack behavior, including how available credits display and cross-service consumption impacts. Added insights on tasks exceeding per-user limits and refined step wording to reduce ambiguity.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/usage-based-billing-manage-copilot-credits

- **Understand usage-based billing and cost management for Copilot Credits**

  Added references to related pay-as-you-go articles for Microsoft 365 Copilot, Copilot Studio, and non-Copilot services (Microsoft 365 Backup, SharePoint Storage, High Volume Email). This directs readers to the appropriate guidance for their product and billing model.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/usage-based-billing-overview-copilot-credits
