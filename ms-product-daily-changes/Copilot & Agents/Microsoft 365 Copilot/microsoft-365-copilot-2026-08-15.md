# Microsoft 365 Copilot
**Date created:** 2026-08-15 UTC  
**Tags:** Best Practices, Configuration, Get Started, Guidance, Performance  

## Moderate Changes

- **Copilot Cowork common questions**

  Updated guidance reflects that the model picker moved from the chat header to the compose box and refreshes the list of available models, including GPT 5.6 variants and current Claude options. Clarifies that some models may require data retention and introduces an “effort level” setting (default Medium) to balance quality, speed, and cost, helping admins and users make informed trade-offs.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-faq

- **Choose a model for Copilot Cowork**

  Added detailed guidance on effort levels (Light, Medium [default], High, Extra High, Max), explaining trade-offs between quality, speed, and cost. Shows where to configure the setting alongside model selection in the compose box so teams can tune performance to their scenario and budget.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-models

- **Get started with Copilot Cowork**

  The getting started page now highlights the new effort level control, enabling users to balance output quality, responsiveness, and spend from the outset. This helps organizations set expectations and configure Cowork appropriately during onboarding.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/get-started
