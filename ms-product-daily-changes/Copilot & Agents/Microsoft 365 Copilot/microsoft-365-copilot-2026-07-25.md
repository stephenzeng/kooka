# Microsoft 365 Copilot
**Date created:** 2026-07-25 UTC  
**Tags:** Administration  

## Moderate Changes

- **OpenAI as a subprocessor in Microsoft Online Services**
  Updated guidance clarifies that, effective July 24, 2026, OpenAI‑operated models are enabled by default for users in eligible commercial tenants, with the option for admins to disable them in the Microsoft 365 admin center. Removed outdated statements indicating the models were disabled by default prior to this date, reducing ambiguity about rollout and administrative control.
  https://learn.microsoft.com/en-us/microsoft-365/copilot/openai-subprocessor
