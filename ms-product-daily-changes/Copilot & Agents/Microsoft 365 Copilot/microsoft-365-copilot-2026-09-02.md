## Moderate Changes

- **Manage plugins for Copilot Cowork**

  Updated governance guidance to prevent unintended plugin sharing: org-wide publishing now requires admin approval, and admins can block previously shared plugins (applies to new conversations). Clarified that shared plugins honor existing Microsoft 365 permissions and require each user to complete connector authentication, with monitoring available via Microsoft Purview audit logs. Minor wording and example refinements improve clarity without changing functionality.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-manage-plugins

- **Microsoft Copilot workflows environment for Copilot workflows experiences**

  Broadened the article’s scope from Workflows agents to all Copilot workflows experiences, with aligned title, roles, and FAQs. Clarified provisioning, visibility, and that tenant-wide disablement affects all Copilot workflows experiences, and expanded DLP details by adding “Microsoft Copilot actions” to the allowlisted connectors to reflect the broader coverage.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/workflows-environment-workflows-agents
