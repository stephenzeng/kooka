## New Articles

- **Using the Microsoft Copilot with Graph-grounded chat service plan**

  Introduced guidance on how the Graph-grounded chat service plan affects Microsoft 365 Copilot when enabled or disabled. Explains the default enabled state for Copilot licenses and the experience differences between Premium grounding (enabled) and Basic grounding (disabled). Notes propagation timings: UI label updates typically appear within 10–15 minutes, with backend convergence taking up to 24 hours. Details the impact when disabled, including reliance on primarily web grounding, reduced organizational graph grounding, and first-party agents that require organizational data (such as Researcher and Analyst) becoming unavailable. Clarifies that prior chats remain but new responses use Basic grounding, Copilot in Word/Excel/PowerPoint uses Basic grounding, and the Integrated Apps control can block Copilot.
