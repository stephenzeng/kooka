# Microsoft 365 Copilot
**Date created:** 2026-08-28 UTC  
**Tags:** Compliance, Get Started, Governance, Guidance, Licensing, Monitoring, Security  

## Major Changes

- **What is Microsoft Copilot?**

  Overhauled the overview with a clearer structure and expanded guidance across Copilot Chat (Basic), Microsoft 365 Copilot (Basic), and Microsoft 365 Copilot (Premium), including access points, capabilities, and admin implications. Added comprehensive data security and privacy coverage, detailing Enterprise Data Protection, how responses are grounded in web vs. organizational data by license, Anthropic subprocessor usage under enterprise protections, and EU Data Boundary information. Introduced model selection options (Auto, Quick response, Think deeper) and expanded app feature coverage, including how Work IQ and Microsoft Graph are used. Enhanced governance with Copilot Control System capabilities such as pinning, image generation controls, agent lifecycle management, web search policy, and removal of access, plus role guidance. Added training resources per license tier and adoption tracking via Copilot Chat and Microsoft 365 Copilot usage reports, and guidance on using Organizational messages to drive adoption.
