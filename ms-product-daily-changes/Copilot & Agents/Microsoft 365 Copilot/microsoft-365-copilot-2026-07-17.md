## New Articles

- **Get ready for Microsoft 365 Copilot with SharePoint Advanced Management**

  New end-to-end readiness guide for deploying Microsoft 365 Copilot and agents with SharePoint Advanced Management. It outlines how to assess and govern content using the Content Management Assessment hub; manage site lifecycle and archival with inactive/ownerless site policies and Microsoft 365 Archive; and prevent oversharing via sharing controls, data access governance reports, and AI insights. The article also details protecting sensitive content using Restricted Access Control and Restricted Content Discovery, and how to leverage the SharePoint Admin Agent for analysis and recommendations. It includes business continuity guidance with Microsoft 365 Backup, with links to setup and usage instructions to help admins reduce risk and accelerate adoption.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/get-ready-copilot-sharepoint-advanced-management
