# Microsoft 365 Copilot
**Date created:** 2026-08-13 UTC  
**Tags:** Analytics, Compliance, Configuration, Governance, Security  

## Major Changes

- **Connect to SpaceXAI models**

  Rebranded the external AI provider to SpaceXAI and aligned the article title, descriptions, and links with updated legal terms, including xAI Enterprise TOS and DPA and Microsoft’s Enterprise AI Services Code of Conduct. Updated Microsoft 365 admin center guidance to clarify SpaceXAI model selection, explicit acceptance of legal terms, and revised navigation/labels. Simplified the disable procedure by directing admins to set access to “No users” and save changes. Clarified that administrator controls for allowing external LLMs are also available in the Power Platform admin center. These updates streamline setup, strengthen compliance clarity, and ensure admins follow the latest governance workflow.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/connect-to-ai-models

- **Microsoft 365 Copilot release notes**

  Added August 11, 2026 updates across platforms highlighting extensibility speed-ups with parallel content/identity crawls and stricter role enforcement for ServiceNow Knowledge and Catalog connectors. Introduced SharePoint Authoritative Sites to prioritize trusted sources, Outlook chat-based coaching and meeting prep, Planner Agent availability for Copilot-licensed users, and PowerPoint enhancements including AEM asset use, web-start presentations, and referencing relevant web sources. Included a Viva Insights Consumption Dashboard to track Copilot credit usage (Cowork and WorkIQ APIs) with scoped access and Cost Management integration, plus Word support for selecting Anthropic models alongside OpenAI. These changes improve performance, governance, user productivity, cost visibility, and model choice across Web, Windows, Mac, Android, and iOS.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes
