# Microsoft Scout (Frontier)
**Date created:** 2026-08-06 UTC  
**Tags:** Administration, AI, Governance, Security  

## Moderate Changes

- **Microsoft Scout common questions**

  Updated the FAQ to clarify that Scout routes prompts through GitHub Copilot and uses its model catalog, which can include Microsoft, third-party, and open-source models; model availability is set by the GitHub Copilot admin and governed by GitHub customer and privacy terms. Clarified availability and compliance: Scout is accessible via the Frontier preview with admin-controlled enablement, is subject to GitHub trade controls and provider-specific regional restrictions, and is not available in US Government or sovereign clouds. Added guidance that admins can restrict available models (for example, via Intune controls) and noted availability may evolve toward general availability.
