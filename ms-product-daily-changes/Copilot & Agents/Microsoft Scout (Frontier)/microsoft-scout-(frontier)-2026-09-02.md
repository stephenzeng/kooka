# Microsoft Scout (Frontier)
**Date created:** 2026-09-02 UTC  
**Tags:** Configuration, Guidance, Troubleshooting  

## Moderate Changes

- **Troubleshoot Microsoft Scout in managed environments**
  Added guidance for cases where GitHub sign-in or authorization fails because GitHub Copilot CLI is not enabled at the enterprise or organization level. Provides step-by-step actions for GitHub administrators to enable Copilot CLI, with links to the relevant GitHub documentation. The Quick reference table was updated to include this scenario, and the guidance clarifies that this cause differs from network allow-listing or TLS inspection issues.
  https://learn.microsoft.com/en-us/microsoft-scout/managed-troubleshoot
