## New Articles

- **SharePoint Knowledge Sources Don't Return Results**

  Introduced a troubleshooting article that explains why SharePoint knowledge sources might return no response in Microsoft Copilot Studio. It outlines common root causes including missing search indexing, unsupported formats or layouts, permission issues, protected or encrypted content, renamed links, authentication scope or consent misconfiguration, file size limits, tenant graph grounding settings, SharePoint list constraints, overly restrictive filters, and content moderation. It provides verification steps, remediation guidance, and a sample KQL query for Application Insights to identify moderation filtering. This guidance helps administrators quickly restore answer coverage and validate configurations end to end.

  https://learn.microsoft.com/en-us/troubleshoot/power-platform/copilot-studio/knowledge/sharepoint-no-response
