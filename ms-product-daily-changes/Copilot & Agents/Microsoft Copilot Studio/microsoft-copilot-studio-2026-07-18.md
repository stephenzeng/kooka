# Microsoft Copilot Studio
**Date created:** 2026-07-18 UTC  
**Tags:** Agent, Security  

## Moderate Changes

- **Extend the capabilities of your agent**

  Updated guidance to better cover how agents can be extended with connectors. Added a dedicated Connectors section detailing integration with enterprise systems and APIs using prebuilt and custom connectors. The article was also renamed, which may impact existing bookmarks or references.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/extend-agent-capabilities

- **Settings (preview)**

  Removed the “Authenticate manually” option from Safety & access, signaling that custom authentication providers are no longer configurable here. Use the remaining methods—No authentication or Authenticate with Microsoft—for access control.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/settings-overview
