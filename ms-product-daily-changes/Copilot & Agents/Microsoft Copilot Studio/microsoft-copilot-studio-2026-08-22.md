# Microsoft Copilot Studio
**Date created:** 2026-08-22 UTC  
**Tags:** Analytics, Get Started, Guidance, Monitoring  

## Moderate Changes

- **Analyze drill-down lists**

  Updated navigation and terminology from Analytics to Monitor and clarified list page context and filter descriptions. Added a new View transcript detail row, included Unengaged in session outcomes, and corrected duplicates. Clarified data retention, noting Monitor stores queries and responses for up to 28 days.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/analytics-drill-down-lists

- **Explore user questions, session, and feedback data**

  Updated UI references from Analytics to Monitor and added a View transcript parameter for question-level analysis. Renamed CSAT to Satisfaction with defined values and introduced a Sentiment field to better interpret user feedback.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/analytics-questions-sessions

- **Build a new agent**

  Refined the agent description to emphasize natural language instructions, knowledge, tools, and components, and clarified the article focuses on manual creation. Introduced the agentic builder (preview) as an alternative path to create agents and workflows, with a link to the quickstart.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/build-new-agent
