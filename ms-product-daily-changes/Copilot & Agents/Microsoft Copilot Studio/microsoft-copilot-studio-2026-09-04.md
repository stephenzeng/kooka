# Microsoft Copilot Studio
**Date created:** 2026-09-04 UTC  
**Tags:** Compliance, Configuration, Governance, Guidance  

## Major Changes

- **Review agent readiness and issue status in Microsoft Copilot Studio**

  Expanded guidance explaining how Agent status evaluates blocking issues, including surfacing the exact admin policy and whether it affects draft or published states. Strengthened governance coverage by showing where policy restrictions appear in the UI—on Tools and Channels—with disabled channel cards and informative popovers to help makers resolve blocks. Introduced a preview Custom guidance message that admins configure in Power Platform admin center (Copilot > Settings > Maker guidance) to display plain-text messages with optional HTTPS link and contact email in Agent status and popovers; messages are limited to 400 characters, not localized, and environment group messages override environment messages. Refreshed terminology and headings to improve clarity.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/authoring-agent-status

## Moderate Changes

- **Microsoft MCP server certification overview (preview)**

  Extended the fallback certification submission path deadline from July 2026 to October 2026, giving publishers more time to transition. Clarifies that existing certified MCPs will move to the new process while publishers may continue the legacy path until the new deadline.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/mcp-certification
