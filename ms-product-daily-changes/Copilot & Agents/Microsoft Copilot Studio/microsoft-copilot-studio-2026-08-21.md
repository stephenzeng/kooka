# Microsoft Copilot Studio
**Date created:** 2026-08-21 UTC  
**Tags:** Compliance, Configuration, Get Started, Identity, Monitoring, Security  

## Major Changes

- **What's new in Copilot Studio**

  Added a July 2026 update that streamlines identity and setup by automatically creating a Microsoft Entra Agent ID for new agents and removing the environment opt-out. Expanded the GitHub Copilot harness with preview support to add workflows and MCP servers as tools, plus an option to submit MCP servers for Microsoft certification, improving extensibility and governance. Introduced multi-channel deployment of the same real-time agent across voice and digital messaging with GPT-5-Chat (Preview) and strengthened observability with Application Insights monitoring and preview export of environment-level telemetry to Azure Application Insights. Enhanced usability for GitHub Copilot harness agents with preview support for users to attach files and view agent-created files. Removed the Release plans section and updated June 2026 entries to use “standard harness” wording, clarifying that features such as Microsoft IQ, skills, memory, connecting other agents, and Foundry IQ apply to agents powered by the GitHub Copilot harness.
