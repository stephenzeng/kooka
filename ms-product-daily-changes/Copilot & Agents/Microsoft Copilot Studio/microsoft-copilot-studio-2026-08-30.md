# Microsoft Copilot Studio
**Date created:** 2026-08-30 UTC  
**Tags:** Analytics, Billing, Consumption, Guidance  

## Moderate Changes

- **Create a single response test set**

  Updated guidance to align with new UI and terminology, transitioning from “test set” to “single response data set” and replacing Evaluate with Run. Added clearer, step-by-step flows including an Additional configuration > Manage path, Generate and Import options with detailed settings, and methods to create datasets from files or preview chats. Clarified test method configuration (pass scores, expected responses/keywords) and noted content moderation limitations.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/analytics-agent-evaluation-create

- **Purchase and manage Copilot credits in usage-based billing**

  Clarified that Copilot Studio administrators allocate and manage credits in the Power Platform admin center and that users should contact administrators for environment assignments. Added links to managing credits and capacity documentation and introduced a Copilot credits estimator to project consumption.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/billing-manage-buy-credits
