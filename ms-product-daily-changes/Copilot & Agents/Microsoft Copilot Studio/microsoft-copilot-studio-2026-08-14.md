- **Add Azure SQL tables as a knowledge source**

  Introduced a step-by-step guide to ground agents with Azure SQL tables using Copilot Studio. Covers prerequisites such as database access, credentials, and network configuration, and explains authentication via the Power Platform SQL connection. Provides database preparation guidance (clear column names, primary keys, descriptive data) and instructions to add and publish the knowledge source. Includes tips to improve answer quality through better table naming, detailed descriptions, selecting relevant tables, and ensuring a readable schema.
