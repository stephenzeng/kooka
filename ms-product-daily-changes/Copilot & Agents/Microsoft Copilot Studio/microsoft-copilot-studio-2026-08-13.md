# Microsoft Copilot Studio
**Date created:** 2026-08-13 UTC  
**Tags:** Governance, Guidance, Monitoring  

## Moderate Changes

- **Analyze conversational agents**

  Updated guidance on Reactions for the Microsoft 365 Copilot channel: admin consent in the Microsoft 365 admin center is now required to share user feedback, and that feedback can be viewed on the Monitor page. Clarified that reactions from this channel aren’t aggregated in the Reactions column for Themes and Knowledge source usage. Noted that Reactions are on by default for all channels except the Microsoft 365 Copilot channel.
