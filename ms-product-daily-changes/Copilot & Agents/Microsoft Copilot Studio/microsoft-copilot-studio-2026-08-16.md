# Microsoft Copilot Studio
**Date created:** 2026-08-16 UTC  
**Tags:** Best Practices, Configuration, Guidance  

## Moderate Changes

- **Configure real-time agents**
  
  Removed Arabic from the list of validated languages to reflect current support. Expanded DTMF setup guidance, clarifying that DTMF-only experiences must define DTMF input on every input node, including menu selections and multi-digit entries like account numbers or PINs. This ensures callers can reliably complete flows using keypad input with corresponding DTMF mappings across all paths.
