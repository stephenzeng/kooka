# Microsoft Copilot Studio
**Date created:** 2026-08-20 UTC  
**Tags:** Analytics, Compliance, Configuration, Governance, Guidance, Monitoring  

## Moderate Changes

- **Quickstart: Create an automated solution with natural language in the GitHub Copilot harness (preview)**

  Updated guidance to indicate Anthropic models are used when available in the environment, rather than being the default in all cases. Revised chat history retention from 22 hours to 28 days and added instructions for accessing and exporting transcripts through transcript control settings, improving auditability and operations.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/create-automation-natural-language

- **Telemetry with Application Insights overview**

  Clarified telemetry scope by harness type: agent-level telemetry is limited to the standard harness, while environment-level telemetry is available for both the standard and GitHub Copilot harnesses. Minor wording updates improve clarity for monitoring configuration.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/telemetry-overview
