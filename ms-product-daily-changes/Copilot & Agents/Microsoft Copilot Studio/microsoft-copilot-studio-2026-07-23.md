# Microsoft Copilot Studio
**Date created:** 2026-07-23 UTC  
**Tags:** Agent  

## Major Changes

- **Add an agent node to a workflow (preview)**

  Added end-to-end automation scenarios that show how to triage support tickets with product knowledge and structured outputs, review expense reports with compliance flags, and prepare meeting briefings using Work IQ with actionable summaries. Introduced an FAQ that helps decide between inline and existing agents, and between an agent node and a prompt node, including a capability comparison (tool orchestration, knowledge sources, human review, task complexity). Clarified that inline agents are scoped to a single workflow and aren’t reusable elsewhere. Added testing and evaluation guidance for agent nodes, including running isolated tests, creating or auto-generating test methods/graders, reviewing pass/fail results with evidence and recommendations, and using an iterative improve-and-retest loop, along with documented limitations and quotas.
