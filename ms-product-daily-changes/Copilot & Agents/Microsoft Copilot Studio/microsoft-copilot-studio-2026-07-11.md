## Moderate Changes

- **Classic vs. new agent experience (preview)**

  Removed a preview/disclaimer note that previously called out differences between the classic and new agent experiences, including transfer limitations and feature gaps. This streamlines the page and reduces distracting caveats, helping readers focus on the current guidance.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/classic-vs-new

- **Best practices for improving conversational agent performance**

  Updated guidance to caution against using Power Automate flows or agent flows as the primary IVR integration for latency‑sensitive, high‑concurrency scenarios due to synchronous execution and throttling limits. Recommends evaluating alternative integration patterns to achieve predictable low‑latency performance.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/guidance/conversational-agents-performance-improvement
