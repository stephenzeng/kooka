## Moderate Changes

- **Connect to an agent over the Agent2Agent (A2A) protocol**

  Updated the step-by-step procedure to match the current UI, including renaming the menu option to “Add agent,” simplifying the connection choice to “A2A agent,” and changing the action button to “Save.” These refinements align the instructions with the latest interface to reduce confusion and streamline setup.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/add-agent-agent-to-agent

- **Troubleshooting and limitations of computer use**

  Added a hosted browser throttling guideline that limits each session to a maximum of three hours, after which the session ends automatically. This helps set user expectations and plan workflows that avoid unexpected session timeouts.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/troubleshooting-computer-use
