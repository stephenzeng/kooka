# Microsoft Copilot Studio
**Date created:** 2026-07-31 UTC  
**Tags:** Administration  

## Moderate Changes

- **Share agents with other users**

  Updated guidance to introduce the Agent viewer role for sharing access to an agent’s Evaluation page without granting edit permissions. Clarifies permitted actions (view/run, rename, cancel, delete evaluations) and the role’s limited scope. Includes steps to assign the role via the Share dialog to streamline collaboration while maintaining governance.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/admin-share-bots

- **Run evaluations and view results**

  Expanded evaluation documentation to cover sharing via the Agent viewer role. Explains allowed actions and restrictions, emphasizes that it confers no environment- or tenant-level privileges, and provides step-by-step assignment instructions to enable controlled reviewer access.

  https://learn.microsoft.com/en-us/microsoft-copilot-studio/analytics-agent-evaluation-results
