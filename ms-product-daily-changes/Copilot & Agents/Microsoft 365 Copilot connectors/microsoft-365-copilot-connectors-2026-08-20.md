# Microsoft 365 Copilot connectors
**Date created:** 2026-08-20 UTC  
**Tags:** Configuration, Guidance  

## Moderate Changes

- **Manage connector connections**

  Added guidance on a new bulk export capability that lets admins export configuration details of the currently displayed connections to a CSV file from More actions in Your Connections. This streamlines auditing, backup, and sharing of connection settings across environments.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/connectors/manage-connector

- **ServiceNow Tickets connector overview**

  Expanded guidance to enumerate supported ServiceNow ticket record types and updated capabilities to reflect the searchable tables. Revamped the Data types indexed section with a table of commonly indexed task child tables and clarified broader indexing coverage, helping admins understand what data is searchable and plan connector deployment effectively.

  https://learn.microsoft.com/en-us/microsoft-365/copilot/connectors/servicenow-tickets-overview
