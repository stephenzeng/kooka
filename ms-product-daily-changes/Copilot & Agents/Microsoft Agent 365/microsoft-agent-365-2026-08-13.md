## New Articles

- **Connected platforms in the Microsoft 365 agent registry**

  Introduced a new article on Connected platforms that enables admins to discover and synchronize AI agents from external platforms into the Microsoft Agent 365 agent registry. The guidance covers creating and managing platform connections, triggering synchronizations, and viewing run status and results with key post-sync details. It documents supported platforms (Amazon Bedrock, Google Vertex AI, Salesforce Agentforce, Databricks Genie, Anthropic Claude Managed Agents (preview), and Oracle Generative AI Agents). The article provides platform-specific authentication and setup steps, including required roles/permissions, OAuth and keys, service principals, and least-privilege IAM policies.

  https://learn.microsoft.com/en-us/microsoft-agent-365/admin/connected-platforms
