# Microsoft Agent 365
**Date created:** 2026-07-24 UTC  
**Tags:** Agent, Analytics  

## Major Changes

- **Use and collaborate with agents with their own identity in Agent 365 (preview)**

  Updated guidance clarifies follow-up scheduling and campaign expiry, including interval behavior, send-window considerations, final-email handling, queued follow-ups, cancellation impacts, and default expiry settings. Added a comprehensive reporting section for the Sales Development agent that explains when to use each report, how to generate a campaign summary, and how to interpret metrics with an illustrative example. Included steps to obtain prospect-level reports and export all or specific stages to CSV for further analysis. These updates help teams configure outreach cadences confidently and make data-driven decisions with clearer, exportable insights.
