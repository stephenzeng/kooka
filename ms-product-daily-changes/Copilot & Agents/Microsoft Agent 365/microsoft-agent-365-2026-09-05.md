# Microsoft Agent 365
**Date created:** 2026-09-05 UTC  
**Tags:** Governance, Guidance  

## Moderate Changes

- **Agent 365 CLI develop-mcp Command Reference**

  Updated guidance to clarify that publishing an MCP server does not grant approval; a tenant administrator must approve the server in the Microsoft 365 admin center (Requested Tools) before agents can use it. The CLI now reminds users to request admin approval after a successful publish, helping enforce governance and avoid deployment delays.

  https://learn.microsoft.com/en-us/microsoft-agent-365/developer/reference/cli/develop-mcp
