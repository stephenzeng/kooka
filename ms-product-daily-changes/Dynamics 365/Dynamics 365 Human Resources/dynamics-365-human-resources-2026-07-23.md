## New Articles

- **What's new or changed in Dynamics 365 Human Resources 10.0.49 (September 2026)**

  Introduced a comprehensive what's-new article for version 10.0.49, covering preview/GA timelines and feature highlights. Added an Onboarding agent (preview) that unifies HR and new-hire experiences in Microsoft Teams with automated tasks and write-back to HR. Improved Employee self-service to show all leave entries on a manager’s absence calendar for the same date, and streamlined Recruiting by properly disabling controls, removing the recruiting request column from position views while retaining creation from positions, and showing recruiter personnel IDs in requests. Enabled year‑round contribution changes for HSA/FSA and 401(k) plans using effective‑dated records without re‑enrollment or qualifying events. Notes include default-on features, platform updates, bug fixes via LCS, regulatory updates, and links to the 2026 release wave 1 plan.
