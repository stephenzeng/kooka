## Major Changes

- **Trace Parser Agent**

  Transitioned the page from a placeholder to a full guide with a TIP linking to the GitHub Trace Parser agent template. Published a comprehensive Overview and architecture describing a dual MCP setup (TraceParser MCP via Data API Builder and Microsoft Learn MCP) with deterministic SQL access to trace data. Documented how the agent detects performance anti-patterns and pairs findings with relevant documentation and X++ samples. This provides actionable guidance for diagnosing and improving performance.

  https://learn.microsoft.com/en-us/dynamics365/guidance/agent-templates/trace-parser-agent

## Moderate Changes

- **Implementation Agent Templates Overview**

  Updated the overview to reflect currently available implementation agent templates, standardized naming, and added a new Template column, including renaming the Release Planner Helper Agent to Roadmap Planner Helper Agent and capitalizing Trace Parser Agent. Shifted terminology from release planning to roadmap planning, added a TIP linking to the Implementation Agents repository, and aligned related content with the new names to improve discoverability and consistency.

  https://learn.microsoft.com/en-us/dynamics365/guidance/agent-templates/implementation-agents-overview

- **Roadmap Planner Helper Agent**

  Renamed the agent from Release Planner to Roadmap Planner and reframed guidance around continuous roadmap delivery, integrating roadmap sources and clarifying feature status and availability timelines. Refreshed the Overview, benefits, and scenarios; replaced the unavailability notice with a TIP to the GitHub folder; and restored previously hidden sections such as prerequisites and work item creation to streamline adoption.

  https://learn.microsoft.com/en-us/dynamics365/guidance/agent-templates/release-planner-agent
