# Dynamics 365 Guidance
**Date created:** 2026-08-05 UTC  
**Tags:** Administration, AI, Agent  

## Major Changes

- **Use Copilot to Find Guidance in the Implementation Portal**

  Added a comprehensive section on AI agent capabilities in the Implementation Portal, including how agents profile projects and update key details from uploaded files. Updated guidance covers supported file types, tracking processing status, reviewing agent-updated fields, and using agents during project onboarding. Refined examples for Copilot queries, aligned terminology from “bots” to “agents,” and added a walkthrough video and Responsible AI FAQs to strengthen governance and user confidence.

  https://learn.microsoft.com/en-us/dynamics365/guidance/implementation-portal/implementation-copilot

- **Migrate to Dynamics 365 online**

  Expanded migration guidance with a new “Migrate from Dynamics SL” path, including supported versions and SQL Server compatibility requirements. Added explicit lifecycle timelines for Dynamics GP and contextualized Dynamics NAV’s final release and extended support dates to aid planning. Updated cloud benefit examples to include Copilot, reinforcing the value case for moving online.

  https://learn.microsoft.com/en-us/dynamics365/guidance/migrate/overview

## Moderate Changes

- **Introduction to the Success by Design framework**

  Replaced per-workload agent listings with consolidated links to each app’s “Copilot and AI agent capabilities” documentation. Added a pointer to the Dynamics 365 hub overview, streamlining navigation and making it easier to find the latest, authoritative guidance.

  https://learn.microsoft.com/en-us/dynamics365/guidance/implementation-guide/success-by-design
