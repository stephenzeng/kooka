**Date created:** 2026-08-12 UTC  
**Tags:** Configuration, Consumption, Guidance  

## Moderate Changes

- **Set up Sales agent in Microsoft 365 Copilot**

  Updated guidance on Dataverse search for Dynamics 365, clarifying that Sales agent queries CRM data through indexed Dataverse search. Explained the storage impact of indexing searchable tables and how it scales with data volume. Provided recommendations to reduce index-related storage by removing tables from Dataverse search, noting that those tables will no longer be queryable by the Sales agent.
