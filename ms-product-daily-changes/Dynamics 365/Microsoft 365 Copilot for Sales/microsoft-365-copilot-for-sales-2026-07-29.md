# Microsoft 365 Copilot for Sales
**Date created:** 2026-07-29 UTC  
**Tags:** Administration, Agent  

## New Articles

- **Configure starter prompts for Sales agent chat**

  Introduced a new admin guide for setting up starter prompts used in Sales agent chat across Dynamics 365 and Microsoft 365 Copilot. Explains prerequisites, where to find the Starter Prompts settings, and how to create prompts with titles, content, app contexts, and automatic translations. Covers managing prompts end-to-end, including editing, enabling or disabling, deleting, reordering for priority, and filtering by context, type, and status. Highlights availability of Microsoft-provided default prompts that can be disabled to match organizational needs.

  https://learn.microsoft.com/en-us/microsoft-sales-copilot/starter-prompts
