# Microsoft 365 Copilot for Sales
**Date created:** 2026-08-11 UTC  
**Tags:** Configuration, Guidance  

## Moderate Changes

- **Connect your agents to a data source**

  Updated Salesforce server-to-server connection guidance to use the term “external client app” instead of “connected app,” and aligned setup, management steps, and UI text with the new terminology. Clarified that existing connections using connected apps continue to work, while new connections should use an external client app. Updated the list of created Salesforce components to include the external client app with the new naming conventions.
