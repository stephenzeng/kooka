# Microsoft 365 Copilot for Sales
**Change date:** 2026-08-07 UTC  
**Tags:** AI, Agent  

## Moderate Changes

- **Overview of Sales agent in Microsoft 365 Copilot**

  Expanded capabilities to clarify the agent now derives insights from past customer conversations across Outlook email, Teams meetings, and Teams messages. Added example prompts to surface common topics in recent interactions, identify unanswered questions, and prepare guidance before replying. These updates help sellers quickly capture context and respond with greater confidence.

  https://learn.microsoft.com/en-us/microsoft-sales-copilot/sales-chat-overview

- **Use Sales agent in Microsoft 365 Copilot**

  Updated guidance to include Graph-grounded data sources (email, meetings, Teams messages) in addition to CRM, with a licensing note: Microsoft 365 Copilot is required for Graph data; Dynamics 365 Sales Enterprise/Premium without Microsoft 365 Copilot supports CRM-only scenarios. Introduced a new section on staying on top of inbox and calendar with example prompts, and clarified that results respect user permissions. This helps sellers prioritize communications while maintaining proper access controls.

  https://learn.microsoft.com/en-us/microsoft-sales-copilot/use-sales-chat
