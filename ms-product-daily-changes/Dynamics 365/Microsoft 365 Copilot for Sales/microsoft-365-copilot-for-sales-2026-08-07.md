# Microsoft 365 Copilot for Sales
**Date created:** 2026-08-07 UTC  
**Tags:** Administration, Agent, Governance, Monitoring, Security  

## New Articles

- **Audit Sales agent activity with Microsoft Purview**

  Introduced guidance for auditing Sales agent activity across Dynamics 365 and Salesforce using Microsoft Purview. Outlines required roles and prerequisites, expected latency and retention, and step-by-step instructions to search, review, and export audit records. Clarifies what fields are captured (agent, user, org, action, resource, timestamp) and what is excluded (no prompts or full responses), helping compliance teams monitor usage without exposing sensitive content. Includes links to related auditing and data-handling documentation to support governance and monitoring workflows.

  https://learn.microsoft.com/en-us/microsoft-sales-copilot/audit-sales-agent-purview

## Moderate Changes

- **Configure how Outlook emails and events are saved to CRM**

  Updated admin guidance to configure how emails and meetings connect to Dynamics 365 records, with options to link a single primary record (Regarding), multiple records (Related to), or both. Clarifies that post-meeting experiences rely on the primary (Regarding) record and that the feature supports only Dynamics 365, with revised setup steps and visuals to help admins apply the configuration consistently.

  https://learn.microsoft.com/en-us/microsoft-sales-copilot/save-additional-details-outlook

- **Save Outlook activities to your CRM**

  Clarified user experience for saving to Dynamics 365: connect to one primary record for the activity and optionally associate additional related records. Notes that availability depends on admin configuration and that post-meeting notes and insights use only the primary record, guiding users to choose the correct connection for downstream experiences.

  https://learn.microsoft.com/en-us/microsoft-sales-copilot/save-outlook-activities-crm
