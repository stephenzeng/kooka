# Dynamics 365 Field Service
**Date created:** 2026-08-05 UTC  
**Tags:** Administration  

## Major Changes

- **Work order experience**

  Retired the guidance on opting out of the default work order experience and removed instructions for reverting to the legacy experience or uninstalling related solutions, clarifying that the current experience is the default. Standardized terminology by eliminating “new” vs. “classic” references and updated UI names (for example, Dynamic Booking to Booking and Functional location to Location) to match the product. Restored the form switcher image to help users understand how to move between default and legacy forms, reducing confusion and aligning documentation with the latest UI.

  https://learn.microsoft.com/en-us/dynamics365/field-service/work-order-experience

## Moderate Changes

- **Use manual inventory journals in Field Service**

  Refocused the article to explain that manual inventory journals directly update product quantities without requiring purchase orders or transfers, with clear scenarios like external integrations and documenting lost/stolen/damaged stock. Clarified how the Inventory Journal table works, how journals differ from inventory adjustments (including support for all inventory types and negative quantities), updated prerequisites to the essentials, and streamlined steps and labels for creating and viewing journals to speed setup and reduce errors.

  https://learn.microsoft.com/en-us/dynamics365/field-service/manual-inventory-journals
