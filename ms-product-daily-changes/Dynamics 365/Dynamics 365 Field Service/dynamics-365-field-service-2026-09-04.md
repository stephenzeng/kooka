# Dynamics 365 Field Service
**Date created:** 2026-09-04 UTC  
**Tags:** Guidance, Troubleshooting  

## Moderate Changes

- **Get help for the Field Service mobile app**

  Updated support guidance to first review common mobile app issues before opening a ticket, helping users resolve problems faster. Directed users to the contact-support section for submitting requests and clarified that session ID and app version should be included, with steps to find them via Account picture > Info.

  https://learn.microsoft.com/en-us/dynamics365/field-service/mobile/get-help

- **Resource Scheduling Health Diagnostics Tool**

  Added a clear step to run diagnostics and explained how results appear in the Diagnostic details section. Clarified several diagnostic checks to better specify conditions and references without changing the overall diagnostics list, improving accuracy and troubleshooting confidence.

  https://learn.microsoft.com/en-us/dynamics365/field-service/health-diagnostics-tool

- **Work IoT data on the mobile app**

  Updated IoT viewing guidance by removing references to the Device Readings tab, renaming the section to focus on summary tiles, and clarifying navigation to Assets > customer asset > Summary. Refreshed device registration steps to match the current UI (New and More ... > Register Device) and refined wording for clarity, reducing confusion during field use.

  https://learn.microsoft.com/en-us/dynamics365/field-service/mobile/iot-mobile
