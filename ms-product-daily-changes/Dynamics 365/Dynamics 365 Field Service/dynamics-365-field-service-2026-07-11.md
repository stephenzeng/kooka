# Dynamics 365 Field Service
**Date created:** 2026-07-11 UTC  
**Tags:** Administration  

## New Articles

- **Configure Field Service settings for common scenarios**

  Introduced a practical how-to guide that consolidates recommended Field Service settings for common scenarios. Provides step-by-step guidance on pricing, costs, taxes, and invoice creation to improve billing accuracy. Explains how to automate work orders and invoices from agreements, including lookahead windows and generation timing. Covers standardizing auto-numbering formats, common configuration mistakes to avoid, and troubleshooting settings behavior. Includes links to default settings, agreements, tax setup, and troubleshooting resources.

  https://learn.microsoft.com/en-us/dynamics365/field-service/configure-settings-common-scenarios

## Moderate Changes

- **Process a return (RMA and RTV)**

  Updated and clarified end-to-end return processing, including creating RMAs with optional tracking numbers, revised UI labels, and explicit fields and processing actions for RMA products. Added guidance for creating receipts, how inventory journals post when returns go to warehouses, and a refined RTV flow with confirmation. Introduced an optional step for crediting customers directly from receipts to streamline post-return billing.

  https://learn.microsoft.com/en-us/dynamics365/field-service/process-return
