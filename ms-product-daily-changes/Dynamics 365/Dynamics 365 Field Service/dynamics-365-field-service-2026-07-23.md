# Dynamics 365 Field Service
**Date created:** 2026-07-23 UTC  
**Tags:** Administration  

## Moderate Changes

- **Set up frontline workers in your organization**

  Updated guidance streamlines worker setup through a single form on the Get started page, enabling quick creation of users as bookable resources and assignment of skills, territories, time zones, security roles, field security profiles, and mobile offline profiles. Clarifies configuration steps and includes an option to email new workers a link to download the mobile app, improving onboarding speed and accuracy.

  https://learn.microsoft.com/en-us/dynamics365/field-service/frontline-worker-set-up

- **Configure offline data synchronization**

  Added a troubleshooting section covering how to review last sync details and errors in Device Status, trigger manual syncs, and resolve common issues via a symptom-to-article mapping table. Included best-practice references to reduce timeouts and large sync durations for more reliable offline performance.

  https://learn.microsoft.com/en-us/dynamics365/field-service/mobile/offline-data-sync

- **Add property logs**

  Clarified the purpose and benefits of property logs to build asset history and track measurements over time. Improved the procedure to record values, noting that Reading Time defaults to the current date/time and should be set to the actual reading time, helping ensure accurate service history.

  https://learn.microsoft.com/en-us/dynamics365/field-service/property-logs

- **Add preferred resources for a requirement**

  Updated the process to add additional resource preferences using the New Requirement Resource Preference action. Added guidance on reviewing preferences during scheduling from the schedule board with Find Availability, helping dispatchers make faster, more informed assignments.

  https://learn.microsoft.com/en-us/dynamics365/field-service/resource-preferences
