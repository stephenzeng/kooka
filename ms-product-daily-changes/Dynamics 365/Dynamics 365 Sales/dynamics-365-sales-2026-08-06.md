# Dynamics 365 Sales
**Date created:** 2026-08-06 UTC  
**Tags:** Administration, Agent  

## Moderate Changes

- **Configure requirements for Sales Close Agent**

  Updated guidance to set the Synchronization Method for Appointment, Contacts, and Tasks to None for the agent user, as only mailbox synchronization is required. This reduces unnecessary data synchronization and clarifies the minimal configuration needed for reliable agent operation.

  https://learn.microsoft.com/en-us/dynamics365/sales/configure-requirements-for-sales-close-agent
