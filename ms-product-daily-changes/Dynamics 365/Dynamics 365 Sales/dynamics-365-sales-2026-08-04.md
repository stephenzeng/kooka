# Dynamics 365 Sales
**Date created:** 2026-08-04 UTC  
**Tags:** Administration, Agent  

## Moderate Changes

- **Configure requirements for Sales Qualification Agent**

  Updated guidance to set the Synchronization Method for Appointments, Contacts, and Tasks to None for the agent user in server-side synchronization. This clarifies that only mailbox synchronization is needed, reducing unnecessary data sync and potential conflicts.
