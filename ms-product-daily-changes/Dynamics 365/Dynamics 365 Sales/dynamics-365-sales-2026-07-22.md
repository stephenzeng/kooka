# Dynamics 365 Sales
**Date created:** 2026-07-22 UTC  
**Tags:** Administration, AI, Agent  

## Moderate Changes

- **Set up and configure AI-powered Data Enrichment**

  Updated prerequisites with a new “Before you begin” and “Verify prerequisites” flow, and split Microsoft 365 Services and Microsoft Teams meetings into distinct requirements. Added a tenant admin requirement and step-by-step connection guidance for Teams meetings, including what data is used (transcripts, attendee list, AI summaries). These clarifications help admins configure data sources correctly and avoid activation issues.

  https://learn.microsoft.com/en-us/dynamics365/sales/data-enrichment-agent-configure

- **Edit AI-powered Data Enrichment settings**

  Added a “Verify prerequisites” section with steps and a screenshot to confirm required connections. Clarified that you must select Save before Start agent when activating. This reduces setup errors when updating settings.

  https://learn.microsoft.com/en-us/dynamics365/sales/data-enrichment-agent-edit-settings

- **Review and approve Data Enrichment suggestions**

  Introduced a new prerequisite for Teams-based enrichment: admins must connect Microsoft Teams meetings to the Data Enrichment agent. Added guidance to contact your admin if suggestions are missing. This helps users diagnose missing suggestions and get the right connection in place.

  https://learn.microsoft.com/en-us/dynamics365/sales/use-data-enrichment-agent
