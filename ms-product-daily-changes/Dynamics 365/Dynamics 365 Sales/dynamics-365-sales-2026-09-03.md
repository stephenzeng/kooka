- **Connect Dynamics 365 CX MCP Server - Sales through Agent 365 Tooling Gateway**

  Introduced a step-by-step guide to connect Dynamics 365 Sales MCP Server to Copilot Studio and other MCP clients using Agent 365 Tooling Gateway. Explains OAuth 2.0 discovery, required audiences/scopes, and token flow via the gateway with on-behalf-of exchange to Dataverse, helping teams set up secure, environment-scoped integrations. Provides instructions for provisioning the ATG service principal, granting admin consent, and creating a customer-owned confidential client with delegated permissions. Details how to configure a Copilot Studio custom connector and add the MCP tool, plus example setups for discovery-capable clients like VS Code and GitHub Copilot CLI. Includes compliance notes (such as FedRAMP boundary and data egress) and troubleshooting tips to resolve common authentication and configuration issues.
