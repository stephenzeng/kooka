# Dynamics 365 Sales
**Date created:** 2026-07-25 UTC  
**Tags:** Administration  

## Moderate Changes

- **Removed or deprecated features in Dynamics 365 Sales**

  Added a deprecation notice for the Sales Hub Dialer (preview), effective July 2026, after which it will be removed from all environments. This change prevents sellers from making or receiving calls within Sales Hub. Customers should transition to the Microsoft Teams dialer within Dynamics 365 Sales, following the provided calling guidance.

  https://learn.microsoft.com/en-us/dynamics365/sales/deprecations-sales
