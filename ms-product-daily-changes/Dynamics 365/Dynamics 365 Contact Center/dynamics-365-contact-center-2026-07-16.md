# Dynamics 365 Contact Center
**Date created:** 2026-07-16 UTC  
**Tags:** AI, Administration, Automation, Monitoring  

## New Articles

- **Manage ongoing Quality Evaluation Agent conversations**

  Introduced guidance for supervisors to monitor ongoing Quality Evaluation Agent conversations using the new Ongoing QEA conversations view in Copilot Service workspace. Clarifies prerequisites (including the Omnichannel Supervisor role) and how to navigate to the view. Explains how to open real-time scores via the Real-time Score action or score links and interpret overall and section-level sentiment in the side pane. Provides links to related evaluation plan and criteria pages to streamline follow-up actions.

  https://learn.microsoft.com/en-us/dynamics365/contact-center/use/ongoing-quality-evaluation-agent-conversations

- **Use evaluations for real-time conversations**

  Added step-by-step guidance to create and manage real-time evaluation plans for ongoing conversations with the Quality Evaluation Agent. Covers prerequisites such as required roles, enabling the agent, Copilot credits, and regional data movement consent. Details key configuration choices including using the Conversations record type, Real-Time frequency, selecting workstreams, enabling criteria scoring, and choosing the AI agent evaluation method. Notes that simulation is not supported for real-time plans and points to resources for viewing scores and managing the plan lifecycle (activate, pause, resume, delete, and edit).

  https://learn.microsoft.com/en-us/dynamics365/contact-center/use/realtime-evaluation-plan
