# Dynamics 365 Contact Center
**Date created:** 2026-07-30 UTC  
**Tags:** Administration, AI, Agent  

## New Articles

- **Use industry templates to set up a contact center (preview)**

  Introduced step-by-step guidance for using industry templates in Service Operations Agent to quickly set up an AI-first contact center. Covers prerequisites like a voice channel, configured phone number, and environment readiness, along with billing via Pay-as-you-go with an Azure subscription and Copilot Studio AI credit usage. Details the guided setup to select Retail or Telecom templates, choose a phone number, start the transformation, monitor status, and validate through simulations, noting that the chosen number is reassigned to a new workstream. Explains automated provisioning across workstreams, knowledge, real-time voice agent capabilities, and simulation readiness. Includes troubleshooting to republish the Transformation Agent Chat Bot if the latest version isn’t found and recommends running simulations and test calls after setup.

  https://learn.microsoft.com/en-us/dynamics365/contact-center/administer/use-industry-templates

## Major Changes

- **Copilot feature availability across products**

  Overhauled the feature availability matrix by removing the Microsoft 365 Copilot for Service column and consolidating the view to three columns for Dynamics 365 Customer Service and Dynamics 365 Contact Center (standalone and embedded). Updated multiple feature support statuses to reflect the refined product scope, improving accuracy and comparability. Examples include email assist from editor no longer supported in embedded and scenarios referencing non-Microsoft CRMs now marked as not supported across the remaining products. This streamlines evaluation of capabilities and reduces confusion.

  https://learn.microsoft.com/en-us/dynamics365/contact-center/use/copilot-feature-availability

## Moderate Changes

- **Customize Copilot conversation summaries**

  Expanded structured summary configuration to let admins add custom sections with a title and extraction instructions, and to reset back to default sections when needed. Clarified that default sections (such as Root Cause, Customer Issue, Troubleshooting steps, Outcome, Error codes) remain available and can be reordered to fit operational needs.

  https://learn.microsoft.com/en-us/dynamics365/contact-center/administer/customize-copilot-conv-summary
