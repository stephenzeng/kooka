# Dynamics 365 Project Operations
**Date created:** 2026-09-03 UTC  
**Tags:** Configuration, Guidance  

## Moderate Changes

- **Understand how cost prices, sales prices, transfer prices, and taxes work together**

  Updated guidance clarifying that when the “Streamline project budget committed cost for purchase orders with Item Requirement activated” feature is enabled, committed cost calculations include non-deductible taxes from purchase order taxes and charges for Item Requirement scenarios and purchase orders created from Item Requirements. This improves budget accuracy and cost forecasting for projects using item requirements. Minor wording edits improve clarity without altering technical behavior.
