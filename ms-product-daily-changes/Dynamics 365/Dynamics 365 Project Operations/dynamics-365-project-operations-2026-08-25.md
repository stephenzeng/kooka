# Dynamics 365 Project Operations
**Date created:** 2026-08-25 UTC  
**Tags:** Guidance  

## Moderate Changes

- **Use general journals for advanced accounting**

  Updated guidance clarifies that general journals are best used for daily low-volume entries and month-end adjustments. References to integrations from external systems were removed to prevent misinterpretation and help users choose appropriate data entry or integration methods.

  https://learn.microsoft.com/en-us/dynamics365/project-operations/project-accounting/general-journals
