# Dynamics 365 Project Operations
**Date created:** 2026-07-23 UTC  
**Tags:** Administration  

## New Articles

- **Support multiple draft budgets**

  Introduced documentation for the Multiple Project Budget Drafts capability, including prerequisites and steps to enable it. Explains the budget lifecycle with major/minor versioning, how to create drafts manually or via import, and how version assignment works. Provides guidance to compare drafts, submit for approval, and understand approval impacts, along with re-import strategies (merge, preserve manual edits, or full re-create). Covers revising approved budgets, deleting drafts, security considerations, and key best practices to manage parallel budget iterations efficiently.

  https://learn.microsoft.com/en-us/dynamics365/project-operations/pro/budget/support-multiple-budget-drafts

## Moderate Changes

- **Manage a proforma project invoice with modern invoice form**

  Added guidance on setting an accounting date on a proforma invoice, enabled by the “Enable Invoice Date Driven Accounting” feature. Clarifies how the accounting date controls posting periods for billed sales actuals and the related customer invoice in Finance and Operations, with steps to configure and noted limitations so you can manage period posting without altering transaction dates.

  https://learn.microsoft.com/en-us/dynamics365/project-operations/proforma-invoicing/modern-invoicing
