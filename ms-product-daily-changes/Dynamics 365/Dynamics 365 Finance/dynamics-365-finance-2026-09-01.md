# Dynamics 365 Finance
**Date created:** 2026-09-01 UTC  
**Tags:** Configuration, Troubleshooting  

## Moderate Changes

- **Prerequisites for installing Business performance analytics**

  Updated prerequisites to require allowing unmanaged customizations when appropriate and to verify the Finance and Operations virtual entities solution is installed. Added guidance on the Block unmanaged customizations setting, required access, and links to related Power Platform documentation, plus dependency details and example error behavior when the virtual entities solution is missing. These updates help prevent setup failures and streamline BPA installation.

  https://learn.microsoft.com/en-us/dynamics365/finance/business-performance-analytics/configure-BPA

- **Business performance analytics troubleshooting**

  Added troubleshooting guidance for missing Administration controls when the UI language isn't English. Provides a temporary workaround by switching the environment language pack, personal Dataverse language, and browser language to English (United States) until localization is available.

  https://learn.microsoft.com/en-us/dynamics365/finance/business-performance-analytics/current-challenges
