# Dynamics 365 Finance
**Date created:** 2026-07-18 UTC  
**Tags:** Administration, Governance  

## New Articles

- **Set up the SAF Fixed Assets Tax report (JPK_KR_ST)**

  Introduced a new article for Poland that explains how to set up and generate the SAF Fixed Assets Tax report (JPK_KR_ST). It outlines prerequisites such as supported Finance versions, Polish localization, fixed assets configuration, and access to Electronic Reporting (ER). Guidance includes importing ER configurations (SAF-T model, fixed assets mapping, JPK_KR_ST XML format), configuring Application Specific Parameters, and selecting the ER format in General ledger parameters per legal entity. It also details generation steps and parameters (date range, tax/accounting books, currency, reclassification) and highlights validation behavior when mappings aren’t configured.

  https://learn.microsoft.com/en-us/dynamics365/finance/localizations/poland/emea-pol-jpk-audit-file-fixed-assets-reporting
