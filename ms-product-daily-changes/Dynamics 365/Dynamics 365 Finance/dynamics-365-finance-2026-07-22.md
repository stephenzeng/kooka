# Dynamics 365 Finance
**Date created:** 2026-07-22 UTC  
**Tags:** Administration  

## Moderate Changes

- **Account structures overview**

  Clarified that account structures and advanced rules validate only Ledger account types in journal lines and accounting distributions, and do not validate financial dimensions for non-ledger types (such as Vendor, Customer, or Bank). Added guidance to set default financial dimensions on non-ledger records to steer data entry and improve consistency.

  https://learn.microsoft.com/en-us/dynamics365/finance/general-ledger/configure-account-structures
