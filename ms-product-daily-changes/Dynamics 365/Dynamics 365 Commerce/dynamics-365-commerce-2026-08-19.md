# Dynamics 365 Commerce
**Date created:** 2026-08-19 UTC  
**Tags:** Configuration, Guidance, Performance  

## Major Changes

- **Modernized transaction grid in Store Commerce**

  Added an “Improvements for faster throughput” section that introduces high-volume enhancements: transaction line search, multiselect cart line updates, bulk add to cart, and a configurable Quick Operations panel for discounts, notes, and PO numbers. Documented keyboard shortcuts for button grids and how to configure them with conflict validation. Updated the Version history with a 10.0.49 entry and included images to illustrate setup and runtime behavior. These updates help cashiers process transactions faster and more consistently in busy store environments.

  https://learn.microsoft.com/en-us/dynamics365/commerce/pos-modern-transaction-grid

## Moderate Changes

- **Store configurations for Retail statements**

  Added guidance on configuring bank transaction types for Commerce payments across channels, clarifying the role of the two fields and how they apply to customer orders, transactional statements, and financial statements (including bank drops). Provides step-by-step setup for channel payment methods and per card type via Electronic payment setup, ensuring accurate posting and reconciliation.

  https://learn.microsoft.com/en-us/dynamics365/commerce/tasks/store-configurations-retail-statements
