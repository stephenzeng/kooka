# Dynamics 365 Commerce
**Date created:** 2026-08-21 UTC  
**Tags:** Configuration  

## Moderate Changes

- **Store Commerce app**

  Updated prerequisites to clearly state .NET Desktop Runtime and SDK requirements per Commerce version. Guidance now specifies: 10.0.49+ requires .NET Desktop Runtime 10 (and .NET 10 SDK for extensions), 10.0.42–10.0.48 require .NET 8, and 10.0.41 and earlier require .NET 6.0.16. This helps admins and developers install the correct runtime and avoid compatibility issues; minor wording improvements were also made.
