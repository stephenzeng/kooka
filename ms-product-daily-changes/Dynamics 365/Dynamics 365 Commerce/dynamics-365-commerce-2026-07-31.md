- **Troubleshoot the Node.js 24 upgrade**

  Introduced a comprehensive troubleshooting guide for upgrading the Dynamics 365 Commerce online SDK to Node.js 24, including prerequisites and supported versions. Clarifies how to resolve common build and install issues (yarn/lockfiles, webpack/OpenSSL) and details the migration from node-sass to sass with guidance for SCSS changes such as replacing slash division, handling variadic mixins, and addressing @import deprecation. Covers fixes for native modules (for example, upgrading canvas to 3.x) and TypeScript definition compatibility by pinning specific @types packages. Explains test stability changes in Node.js 24 and provides patterns to await async operations reliably, along with a step-by-step migration checklist.
