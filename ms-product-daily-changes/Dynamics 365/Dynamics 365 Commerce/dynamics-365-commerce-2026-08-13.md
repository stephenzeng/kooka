- **Modern receipt designer in Commerce headquarters**

  Introduced a new browser-based, React receipt designer that replaces the legacy ClickOnce tool and saves structured receipt layouts. Provides prerequisites and step-by-step guidance to open the designer, build layouts using a canvas and field palette, resolve validation errors, and save designs. Adds support for custom fields, localized labels (v10.0.49), reusable templates, and embedded preview after save. Clarifies how structured receipts are consumed across Store Commerce flows (post-sale, journal, customer transactions, cash management), the effect of print/preview settings, the need to open and save existing formats to generate structured data, and that modern edits don’t sync back to legacy formats.
