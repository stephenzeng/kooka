## New Articles

- **Run Siemens Teamcenter on Oracle Database@Azure**

  Introduced a new reference architecture for running Siemens Teamcenter PLM on Azure using Oracle Exadata Database Service via Oracle Database@Azure. The article details end-to-end architecture, including application tiers, delegated subnet networking between Azure and OCI, and identity integration with Microsoft Entra and Oracle IDCS. It provides deployment methodology, supported versions, backup and recovery with Oracle Autonomous Recovery Service, and validation results with performance observations. Guidance is organized by Azure Well-Architected pillars and includes diagrams and related resources to accelerate planning and implementation.

  https://learn.microsoft.com/en-us/industry/manufacturing/architecture/siemens-teamcenter-oracle-azure
