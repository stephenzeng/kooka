- **Run Autodesk 3ds Max on AMD-based V710 GPU on an Azure VM**

  Introduced a reference architecture for running Autodesk 3ds Max 2026 on Azure NVads V710 v5 virtual machines with AMD Radeon PRO V710 GPUs. The article provides end-to-end guidance including prerequisites, graphics configuration (Nitrous Direct3D 11), and a detailed architecture using Azure components such as VNets, NSGs, public IPs, managed disks, and RDP. It documents validation methodology, tested configurations, and scenario results to help teams assess functionality and performance (with NVIDIA/OptiX-specific items marked not applicable). The guidance aligns with Azure Well-Architected pillars to inform reliability, security, cost, performance, and operational practices.
