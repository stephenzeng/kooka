## New Articles

- **Siemens NX performance on Azure RTX PRO 6000 Blackwell Edition**
  
  Introduced a new reference architecture and performance validation for running Siemens NX 2506 on Azure Virtual Desktop with NVIDIA RTX PRO 6000 Blackwell GPUs on Azure NC v6. Provides end-to-end setup guidance (AVD, NC v6 SKUs, NVIDIA drivers, licensing, access) and a detailed architecture with workflow and operational steps. Includes benchmarking with Siemens NX ATS/NXCP for 15 and 30 concurrent users across single- and dual-host configurations, showing significant gains in GPU-intensive tasks with one minor regression noted. Outlines use cases and comprehensive Well-Architected guidance across reliability, security, cost, operations, performance, and scalability.
