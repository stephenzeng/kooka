# Dynamics 365 Customer Insights
**Date created:** 2026-07-18 UTC  
**Tags:** Analytics, Automation, Programming  

## Moderate Changes

- **Generate iCalendar files for events and sessions**
  
  Updated guidance to configure Add to Calendar links in emails and generate personalized .ics files for events, sessions, or both. Added instructions to tailor calendar descriptions for HTML and plain-text clients and to use a check-in link wildcard for streamed events, helping recipients receive accurate details and easy access to check-in.

  https://learn.microsoft.com/en-us/dynamics365/customer-insights/journeys/add-to-calendar

- **Push notification user mapping for application developers**
  
  Added an end-to-end “User mapping architecture” and restructured implementation steps to clarify entity selection and passing record IDs, improving accuracy of notification targeting. Refined the example for retrieving a contact ID via OData and improved accessibility with clearer alt text, making integration more reliable and easier to follow.

  https://learn.microsoft.com/en-us/dynamics365/customer-insights/journeys/developer-push-user-mapping

- **Export segments to MoEngage (preview)**
  
  Marked the feature as preview and clarified that exports focus on unified customer profiles for email marketing. Streamlined setup and export steps, explained default permissions and connection prerequisites, and adjusted guidance so segment creation in MoEngage is user-driven, setting clearer expectations for behavior.

  https://learn.microsoft.com/en-us/dynamics365/customer-insights/data/export-moengage
