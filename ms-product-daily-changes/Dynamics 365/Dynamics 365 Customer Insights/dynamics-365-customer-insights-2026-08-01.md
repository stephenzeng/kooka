# Dynamics 365 Customer Insights
**Date created:** 2026-08-01 UTC  
**Tags:** Administration  

## Moderate Changes

- **Diagnose Customer Insights - Journeys with Solution Health Hub**

  Updated the Solution Health Hub rule set for Customer Insights - Journeys by introducing the MissingFieldSecurityProfiles rule, replacing MissingMktConfiguration and MissingRolesToApplicationUser, and noting its impact on SMS and push notifications. Standardized a rule name to CheckIfProcessesOwnedByDisabledUsers and refreshed the example results to match; also removed MissingRolesToApplicationUser from rules that support Resolve actions. These changes help admins interpret health checks accurately and know which issues can be automatically resolved.
