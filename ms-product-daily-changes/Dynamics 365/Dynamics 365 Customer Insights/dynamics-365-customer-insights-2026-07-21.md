# Dynamics 365 Customer Insights
**Date created:** 2026-07-21 UTC  
**Tags:** Security  

## Moderate Changes

- **Use calculated measures in Dataverse-based applications**

  Updated permissions guidance by removing outdated Marketing roles and clarifying role requirements for using measures. Clarified that the Customer Insights Data Read Access role provides access to the measure's virtual entity and should be assigned for Customer Insights - Journeys scenarios, including personalization and test sends. This helps administrators assign the correct roles and prevent permission issues.

  https://learn.microsoft.com/en-us/dynamics365/customer-insights/data/dataverse-measures
