# Dynamics 365 Customer Insights
**Date created:** 2026-08-13 UTC  
**Tags:** Analytics, Configuration, Get Started, Guidance, Security, Troubleshooting  

## Moderate Changes

- **Data enrichment (preview) overview**

  Updated and expanded the overview to explain how enrichments standardize addresses and add attributes like interests, affinities, and demographics to improve customer profiles. Clarified that Microsoft-provided enrichments are included, while third‑party options require separate subscriptions, and that outputs are stored in linked tables by customer ID. Strengthened guidance on address validation and geocoding with Azure Maps, and refined configuration steps including using admin-set connections, visibility of limits, and reusing connections across similar enrichments.

  https://learn.microsoft.com/en-us/dynamics365/customer-insights/data/enrichment-hub

- **Overview of Customer Insights - Journeys forms**

  Added a getting-started overview for creating, customizing, and publishing forms in the form editor. Updated security guidance to note HIP captcha removal as of June 2026 and directed users to implement reCAPTCHA for bot protection.

  https://learn.microsoft.com/en-us/dynamics365/customer-insights/journeys/real-time-marketing-form-overview

- **Customer Insights - Journeys forms security and privacy**

  Updated bot protection guidance to reflect HIP captcha removal in June 2026 and emphasized that existing forms using HIP lack protection until reCAPTCHA is configured and republished. Clarified reCAPTCHA setup with Site key and Secret key in default form configuration and added a new troubleshooting section; minor security note wording was refined without changing behavior.

  https://learn.microsoft.com/en-us/dynamics365/customer-insights/journeys/real-time-marketing-form-security-privacy
