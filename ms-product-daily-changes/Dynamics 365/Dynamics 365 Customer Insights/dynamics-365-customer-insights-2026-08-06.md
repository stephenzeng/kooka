# Dynamics 365 Customer Insights
**Date created:** 2026-08-06 UTC  
**Tags:** Administration, Agent, AI, Automation  

## Moderate Changes

- **Create content blocks that you can reuse in multiple designs**

  Removed the preview notice and the feature-switch steps for dynamic content blocks, indicating the capability is now available without a preview toggle. This streamlines setup and reduces friction for teams standardizing reusable content.

  https://learn.microsoft.com/en-us/dynamics365/customer-insights/journeys/content-blocks

- **New and upcoming features**

  Added the August 2026 update with several enhancements: a GA capability to keep emails current using Power Fx for text, date, and number transformations; a public preview for advanced personalization via simple formulas; and a Journey Creation Agent to accelerate journey design. Also introduced tracking of journey origin by stamping created records or triggers with live journey metadata to improve analytics and governance.

  https://learn.microsoft.com/en-us/dynamics365/customer-insights/journeys/whats-new-marketing
