## New Articles

- **Troubleshoot reCAPTCHA in Customer Insights - Journeys Forms**

  Added a troubleshooting guide for reCAPTCHA issues in Customer Insights - Journeys forms. It provides a configuration checklist for defaults, key storage, domain registration, and republishing, and clarifies that reCAPTCHA does not appear in Preview. It details fixes for common errors like “Invalid domain for site key” and “This reCAPTCHA is for testing purposes only,” including when to use v2 keys and register domains. It also shows how to capture validation errors via plug-in trace logs and verify keys through the Data API, with links to related security and forms troubleshooting.
