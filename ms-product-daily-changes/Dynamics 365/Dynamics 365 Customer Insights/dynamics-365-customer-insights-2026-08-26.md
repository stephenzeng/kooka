# Dynamics 365 Customer Insights
**Date created:** 2026-08-26 UTC  
**Tags:** Configuration, Troubleshooting  

## Moderate Changes

- **Troubleshoot reCAPTCHA in Customer Insights - Journeys Forms**

  Expanded troubleshooting guidance clarifying domain registration for Google reCAPTCHA: use your website’s domain for embedded forms, and register mkt.dynamics.com for standalone pages to cover all CDN subdomains. Added an important note explaining why registering only a specific CDN subdomain (for example, assets-gbr.mkt.dynamics.com) can cause failures. Updated the “Invalid domain for site key” error section and table to reflect this guidance.

  https://learn.microsoft.com/en-us/troubleshoot/dynamics-365/customer-insights/journeys/forms/troubleshoot-recaptcha
