# Dynamics 365 Supply Chain Management
**Date created:** 2026-08-19 UTC  
**Tags:** Analytics, Performance  

## Major Changes

- **What's new or changed in Demand planning**

  Added Version 1.4 enhancements including Best fit model v4 with SMAPE-based selection, a new forecast accuracy page with model distribution and average SMAPE visuals, deeper explainability drilldowns for planning objects, and full forecast component breakdowns. Expanded data handling with options to fill missing signal values and added new aggregation methods (Average, Max, Min, Last value) while advancing engineering alignment for Dataverse storage. Introduced a fix preventing unsaved edits from resetting on double-click. Also documented Version 1.2 data cleanup for obsolete time series/versions, improved stability, enabled export API availability, boosted export performance via a new SCM index, and enhanced forecast performance, alongside clearer terminology and guidance.
