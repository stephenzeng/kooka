# Dynamics 365 Supply Chain Management
**Date created:** 2026-07-22 UTC  
**Tags:** AI, Administration, Agent, Governance  

## New Articles

- **Use the agent deployment wizard to set up impact analysis features (preview)**

  Introduced a guided setup wizard for configuring the Procurement Agent’s impact analysis features from Copilot Hub, reducing manual steps and errors. The wizard verifies prerequisites such as DLP policies and Supply Chain Management version requirements, then helps create the agent identity with the correct roles and licenses across Power Platform, Entra ID, and Supply Chain Management. It connects the agent by establishing the required connections, activates needed flows, assigns Agent manager and Agent user permissions, and enables features by publishing Copilot Studio agents and turning on SCM capabilities. The article also notes when manual setup is appropriate, reuses supplier communications setup where applicable, and provides troubleshooting tips for DLP and feature availability.

  https://learn.microsoft.com/en-us/dynamics365/supply-chain/procurement/procurement-agent-impact-analysis-setup-wizard

## Moderate Changes

- **Set up impact analysis (production-ready preview)**

  Updated prerequisites to require a specific Supply Chain Management build (10.0.48 build 10.39.2117 or newer) and Copilot for finance and operations apps version 10.0.03473.2 or later, with a clarified installation order. Guidance emphasizes installing both Copilot components and using the newest builds to ensure compatibility and a smoother deployment experience.

  https://learn.microsoft.com/en-us/dynamics365/supply-chain/procurement/procurement-agent-impact-analysis-setup
