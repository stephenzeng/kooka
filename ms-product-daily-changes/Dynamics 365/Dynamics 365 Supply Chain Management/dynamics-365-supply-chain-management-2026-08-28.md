# Dynamics 365 Supply Chain Management
**Date created:** 2026-08-28 UTC  
**Tags:** Analytics, Configuration, Identity, Monitoring, Performance, Security  

## Major Changes

- **What's new or changed in the Warehouse Management mobile app**

  Introduced a 4.1.5.0 release section that adds expanded barcode format support, a customizable scan frame, selectable success/failure/warning sounds, an initial ProGlove arm‑scanner bridge with image capture, and per‑connection client settings including TLS 1.2 and default credential options. Improved startup time, reduced UI redraws and token renewals, enabled centrally adjustable network behavior, made details cards scrollable by default, targeted Android 16 (API level 36), updated MSAL/OneAuth, and delivered multiple security and dependency updates with enhanced telemetry and accessibility (including iOS VoiceOver). Fixed issues causing data mutation after submit, duplicate submissions, escaped character rendering, SSO broker errors, startup failures, unclear errors and layouts, calculator input loss, spinner and dialog glitches, and promoted field formatting. Resolved platform‑specific problems: Windows connectivity/startup/barcode decoding/UI, Android full sign‑out/ignored barcode formats/MDM diagnostics, and iOS barcode scanning with Apple Vision and scan‑frame positioning. Added an Older versions link to the release notes archive to improve discoverability.
