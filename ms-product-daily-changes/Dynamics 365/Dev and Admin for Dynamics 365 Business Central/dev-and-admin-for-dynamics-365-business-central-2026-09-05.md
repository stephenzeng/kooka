# Dev and Admin for Dynamics 365 Business Central
**Date created:** 2026-09-05 UTC  
**Tags:** Automation, Configuration, Guidance  

## Major Changes

- **Feature details in update 29.0 public preview for 2026 release wave 2**

  Updated Copilot chat guidance to reflect staged availability, optional enablement via the Copilot & Agent Capabilities page, and licensing-based benefits, with a new pricing reference. Removed the extensive “Deliver AI agents in Business Central” content set to streamline guidance and reduce redundancy. Added an Ecommerce section detailing how Shopify exchanges and refunds are processed, including creation of returned and replacement lines and how negative lines can be split into a new sales document while preserving links to the originating order. These changes clarify setup, simplify navigation, and improve understanding of financial flows for Shopify scenarios.

  https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/whatsnew/preview-feature-details

## Moderate Changes

- **What's New or Changed in Business Central 2026 release wave 2 - Update 29.0 preview**

  Added a feature entry for a unified Copilot chat experience aligned with Microsoft Copilot that can reason over business data, web results, and general knowledge. This modernized chat improves discoverability and consistency across experiences and links to detailed preview guidance.

  https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/whatsnew/whatsnew-update-29-0
