- **Quality Evaluation Agent Errors and Recommended Actions**

  Introduced a troubleshooting guide for failed quality evaluations in Omnichannel for Customer Service, covering common causes like missing metadata, permissions, configuration issues, and connectivity. Provides steps to review AI agent error details in evaluation grids and run history and clarifies when a retry is appropriate. Explains retry behavior, including reusing configuration, overwriting the record, preserving Created On, updating Modified On/Requested By, and not auto-upgrading the criteria version. Includes a table of error codes with recommended actions and links to related evaluation features.
