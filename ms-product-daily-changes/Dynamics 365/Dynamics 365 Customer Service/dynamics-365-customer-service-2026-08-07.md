# Dynamics 365 Customer Service
**Change date:** 2026-08-07 UTC  
**Tags:** Administration  

## Major Changes

- **Configure a chat widget in Dynamics 365 Contact Center**

  Introduced a Modern chat widget (Preview) with end-to-end setup and configuration guidance, including adding to existing or new chat channels. Expanded configuration coverage across general settings, workstream details, UI elements, behaviors, and user features such as file sharing, transcripts, voice/video, screen sharing, and co-browse. Added version management guidance within a workstream, including editing configurations, copying version-specific test scripts, setting an active version, and rolling back. Updated the classic widget documentation to clarify version selection, label behavior, add notifications configuration, and refine wording for collaboration options to support smoother migration from classic to modern.

  https://learn.microsoft.com/en-us/dynamics365/customer-service/administer/add-chat-widget
