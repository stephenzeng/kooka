# Dynamics 365 Customer Service
**Date created:** 2026-09-04 UTC  
**Tags:** Configuration, Guidance  

## Moderate Changes

- **Enable file attachments**

  Updated guidance on file attachment settings: do not block the .txt extension, as doing so prevents access to conversation transcripts after a conversation is closed. This clarification helps admins preserve transcript availability and avoid data loss in closed conversations.

  https://learn.microsoft.com/en-us/dynamics365/customer-service/administer/enable-file-attachments
