# Dynamics 365 Customer Service
**Date created:** 2026-07-15 UTC  
**Tags:** Administration, Agent, Programming  

## Moderate Changes

- **createSession method (app profile manager) JavaScript API Reference**

  Added an optional shouldRestore parameter to SessionInput to control whether a created session automatically restores in the agent workspace. This gives developers precise control over session behavior, enabling creation without UI restoration when needed.

  https://learn.microsoft.com/en-us/dynamics365/customer-service/develop/reference/methods/createSession

- **Overview of Workforce Management**

  Updated scheduling guidance by removing Automatic break distribution and its references to reflect current capabilities. Added guidance on shift rotation policies to refine recommended scheduling practices.

  https://learn.microsoft.com/en-us/dynamics365/customer-service/use/workforce-management-overview
