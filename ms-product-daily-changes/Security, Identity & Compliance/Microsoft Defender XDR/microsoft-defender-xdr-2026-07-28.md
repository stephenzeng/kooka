# Microsoft Defender XDR
**Date created:** 2026-07-28 UTC  
**Tags:** Security  

## Moderate Changes

- **Investigate an identity**
  
  Updated guidance on identity remediation actions across connected systems (on-premises Active Directory, Microsoft Entra ID, IAM platforms, and SaaS apps). The section now emphasizes core actions like disabling/enabling accounts, revoking sessions, forcing password changes, and flagging users as compromised, and clarifies how to view account settings. Details are streamlined with a pointer to a central reference for the full list of supported actions and providers, helping investigators quickly choose the right response and find authoritative coverage.
  
  https://learn.microsoft.com/en-us/defender-xdr/investigate-users
