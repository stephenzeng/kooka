# Microsoft Defender XDR
**Date created:** 2026-08-27 UTC  
**Tags:** Analytics, Security  

## New Articles

- **CallActivityEvents table in the advanced hunting schema**

  Introduced a new reference page for the CallActivityEvents table, enabling advanced hunting over activities during Microsoft Teams calls. The article documents key columns such as ActivityTimestamp, CallId, ActivityType, and participant identifiers to support investigations and detection scenarios. It clarifies that data originates from Defender for Office 365 and that queries return results only when the service is deployed. It also outlines planned support for event streaming API, Microsoft Sentinel integration, and additional attributes.

  https://learn.microsoft.com/en-us/defender-xdr/advanced-hunting-callactivityevents-table

## Moderate Changes

- **Understand the advanced hunting schema**

  Updated the schema overview to include the new CallActivityEvents table and link to its reference. This helps analysts quickly locate Teams call activity data and aligns the navigation with the newly added hunting capability.
