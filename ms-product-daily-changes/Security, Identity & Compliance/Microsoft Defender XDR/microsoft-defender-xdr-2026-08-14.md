- **DeviceBaselineComplianceAssessmentKB (Preview)**

  Updated the advanced hunting table schema by adding the ConfigurationBenchmarkVersion column to record the benchmark version used. These updates improve query precision, reduce ambiguity in versioning, and strengthen compliance reporting and analysis.
