# Microsoft Defender XDR
**Date created:** 2026-07-19 UTC  
**Tags:** AI, Security  

## Moderate Changes

- **What is Microsoft Defender XDR?**

  Expanded threat hunting guidance to include identity, email, and cloud app data alongside endpoint and Office data. Clarified cross-product hunting by explicitly naming data sources across Defender for Endpoint, Defender for Office 365, Defender for Identity, and Defender for Cloud Apps, helping analysts run broader, more effective hunts.

  https://learn.microsoft.com/en-us/defender-xdr/microsoft-365-defender

- **Microsoft Security Copilot and Chat in Microsoft Defender**

  Added instructions for using Security Copilot on the Email entity page in Defender for Office 365 to generate AI-authored message summaries that consolidate metadata, timeline events, URLs, and attachments. Included an example prompt to quickly summarize an email and extract key indicators, improving triage speed and consistency.

  https://learn.microsoft.com/en-us/defender-xdr/security-copilot-in-microsoft-365-defender
