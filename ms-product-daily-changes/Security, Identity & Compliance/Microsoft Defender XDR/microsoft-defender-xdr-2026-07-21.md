# Microsoft Defender XDR
**Date created:** 2026-07-21 UTC  
**Tags:** AI, Security  

## Major Changes

- **AI agent posture risk in Microsoft Defender (preview)**

  Comprehensive rewrite that broadens scope from only enterprise agents to all AI agents and clarifies the risk model as a function of likelihood of compromise and potential impact. Streamlines prior tables into a generalized set of agent risk indicators with examples (such as weak instructions, high usage, indirect prompt injection exposure, privileged access, and active threats) and adds a new section explaining how risk is assessed. Emphasizes device and user context for local agents, notes that some indicators reflect intentional design choices and may not be remediable, and removes outdated granular tables. Enhances security recommendations with indicator-to-recommendation mapping and adds updated visuals, while consolidating portal guidance.

  https://learn.microsoft.com/en-us/defender-xdr/security-for-ai/ai-agent-risk-assessment

## Moderate Changes

- **What's new in Microsoft Defender XDR**

  Added a July 2026 Preview entry for AI agent posture risk assessment, covering both enterprise and local agents with risk levels derived from configuration, access, runtime activity, endpoint/user context, and active alerts. This update helps customers discover the capability and use its recommendations to prioritize risky agents and strengthen security posture.

  https://learn.microsoft.com/en-us/defender-xdr/whats-new
