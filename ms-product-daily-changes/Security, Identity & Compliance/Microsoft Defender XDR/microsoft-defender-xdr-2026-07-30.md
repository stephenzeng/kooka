# Microsoft Defender XDR
**Date created:** 2026-07-30 UTC  
**Tags:** Security  

## Major Changes

- **Deploy AI agents in Microsoft Defender**

  Added guidance for the Data Security Triage Agent in Data Loss Prevention, including where it works (Exchange, Teams, OneDrive, SharePoint, Endpoint) and how it uses AI to triage incidents, generate rationale, and optionally send Teams reminders. Consolidated capabilities and prerequisites into a clear table covering identity, licensing, permissions, products, plugin, RBAC, and triggers. Clarified that deployment and management are coordinated across the Microsoft Purview and Defender portals. Provided step-by-step instructions to enable and configure the agent in the Defender XDR portal, helping teams accelerate DLP triage and standardize governance.
