# Microsoft Intune
**Date created:** 2026-07-26 UTC  
**Tags:** Administration, Automation, Monitoring  

## New Articles

- **Integrate Samsung Knox E-FOTA with Microsoft Intune**

  Introduced a new end-to-end guide for integrating Samsung Knox E-FOTA with Intune to centrally control firmware updates across Samsung devices. The article covers prerequisites, setting up the Samsung connector, deploying required Knox apps, and configuring devices using OEMConfig for precise firmware control. It also explains how to create and manage update campaigns, monitor status with hourly refresh, review device registration reports, and safely disconnect the connector. This helps admins standardize firmware versions, reduce update disruption, and improve device reliability and governance.

  https://learn.microsoft.com/en-us/intune/device-updates/android/setup-samsung-knox
