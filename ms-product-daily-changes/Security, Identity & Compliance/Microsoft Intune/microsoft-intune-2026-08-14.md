# Microsoft Intune
**Date created:** 2026-08-14 UTC  
**Tags:** Configuration, Guidance, Monitoring  

## Moderate Changes

- **Intune Management Extension for Windows**

  Clarified that using Sync from device Settings or the Intune admin center triggers both MDM and Intune Management Extension check-ins on Windows. Detailed that on-demand sync processes configuration policies, app detection and deployment state, scripts and remediations, and other management signals. Added guidance to track progress in the Device sync status tab on the device overview.

  https://learn.microsoft.com/en-us/intune/device-management/tools/management-extension-windows

- **Device action: sync**

  Expanded device sync guidance to cover iOS/iPadOS in addition to Windows, with a new section describing on-demand processing for policies, apps, scripts/remediations, and other signals. Updated notes to confirm the Device sync status tab applies to iOS/iPadOS and Windows, and to enable the Preview new device view toggle to see the improvements.

  https://learn.microsoft.com/en-us/intune/device-management/actions/sync
