# Microsoft Intune
**Date created:** 2026-09-05 UTC  
**Tags:** Configuration, Deprecation  

## Moderate Changes

- **Enable Mobile Threat Defense connector in Microsoft Intune**

  Removed documentation for the “Automatically launch Defender for Endpoint during setup on Android COBO and COPE devices” setting and its related note about the “Grant MTD role permissions” toggle, indicating the option is no longer available or supported. Admins should no longer expect automatic app launch during setup and should review onboarding workflows for Android corporate devices. Update deployment guidance and permissions assumptions accordingly.

  https://learn.microsoft.com/en-us/intune/device-security/mobile-threat-defense/enable-connector
