# Microsoft Intune
**Date created:** 2026-08-20 UTC  
**Tags:** Compliance, Deprecation, Guidance  

## Major Changes

- **Policy Configuration Agent in Microsoft Intune**

  Added a deprecation banner stating that the Policy Configuration Agent is deprecated. This signals the feature’s retirement and helps admins avoid new deployments. Review alternatives and plan to transition configurations that depend on this agent. No functional guidance changed in this article.

  https://learn.microsoft.com/en-us/intune/copilot/agents/policy-configuration-agent

## Moderate Changes

- **Change Review Agent overview**

  Added a deprecation notice to mark the Change Review Agent as deprecated. This alerts admins to begin planning transitions and avoid new use. Content remains otherwise unchanged.

  https://learn.microsoft.com/en-us/intune/copilot/agents/change-review-agent

- **Diagnostic and usage data for supported current branch versions**

  Renamed and reframed the article to cover all supported current branch versions rather than a single release. Introduced a Version-specific notes section and updated headings and references to reflect broad applicability. This reduces version churn and clarifies that the enumerated data items are consistent across supported versions.

  https://learn.microsoft.com/en-us/intune/configmgr/core/plan-design/diagnostics/levels-of-diagnostic-usage-data-collection

- **Levels of diagnostic usage data**

  Consolidated version-specific details into a single description that applies across supported current branch versions. Replaced per-version links with one canonical list of collected data and a link to currently supported releases. This simplifies navigation and makes guidance easier to keep current.

  https://learn.microsoft.com/en-us/intune/configmgr/core/plan-design/diagnostics/levels-overview
