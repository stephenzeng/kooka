# Microsoft Intune
**Date created:** 2026-08-13 UTC  
**Tags:** Compliance, Governance, Security  

## Moderate Changes

- **Use Intune properties catalog to collect device properties from Windows devices**

  Updated guidance clarifies that registry key inventory results are accessed through Device Inventory and are governed by existing device inventory permissions. Added a caution that this access could unintentionally expose sensitive configuration details, and recommends reviewing security and privacy implications and tightening permissions before enabling broad access.

  https://learn.microsoft.com/en-us/intune/device-configuration/collect-device-properties
