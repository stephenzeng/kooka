# Microsoft Intune
**Date created:** 2026-08-15 UTC  
**Tags:** Guidance, Monitoring  

## Moderate Changes

- **Use Android Management API for personally owned devices with work profiles**

  Updated guidance on monitoring migrations to the Android Management API for personally owned work profile devices. Added steps to track progress using the "Personal Devices on Android Management API" report under Devices > Monitor, and clarified that migration status won't appear in policy assignment status or device configuration views.

  https://learn.microsoft.com/en-us/intune/device-enrollment/android/android-management-api-overview
