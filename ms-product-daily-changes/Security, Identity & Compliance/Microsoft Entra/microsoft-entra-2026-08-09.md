# Microsoft Entra
**Date created:** 2026-08-09 UTC  
**Tags:** Security  

## Moderate Changes

- **Microsoft-managed Conditional Access policies**

  Updated rollout timelines for Microsoft-managed Conditional Access policies, reducing the enablement window from at least 45 days to at least 30 days and shortening customer notifications from 28 days to two weeks. Guidance and notes were revised to reflect the faster enablement caveat, and the docs now clarify that a new security group is created with the "Require remediation for high-risk users" policy to scope affected users. This helps tenants plan change windows more precisely and understand how affected users are targeted.

  https://learn.microsoft.com/en-us/entra/identity/conditional-access/managed-policies
