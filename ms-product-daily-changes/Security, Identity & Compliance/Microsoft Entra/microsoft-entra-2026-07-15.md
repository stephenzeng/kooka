# Microsoft Entra
**Date created:** 2026-07-15 UTC  
**Tags:** Administration, Security  

## Moderate Changes

- **Configure Akamai for Single sign-on with Microsoft Entra ID**

  Restructured the tutorial for clearer navigation and added step-by-step configuration guidance across general, authentication, session, directory, UI, advanced SSO, and deployment settings. Clarified SPN and delegation requirements with refined examples and keytab instructions, and expanded guidance for Remote Desktop, SSH, and Kerberos scenarios. These updates streamline setup and reduce misconfiguration risk.

  https://learn.microsoft.com/en-us/entra/identity/saas-apps/akamai-tutorial

- **Configure Bpanda for automatic user provisioning with Microsoft Entra ID**

  Added support for Client Credentials and long-lived bearer token authentication methods. This expands deployment options and simplifies secure, automated provisioning.

  https://learn.microsoft.com/en-us/entra/identity/saas-apps/bpanda-provisioning-tutorial

- **Configure Netskope User Authentication for automatic user provisioning with Microsoft Entra ID**

  Introduced a required step to select OAuth2 Client Credentials Grant, enter the Client ID/Secret from Netskope, and test the connection, with guidance for handling failures. This improves authentication setup reliability and speeds troubleshooting.

  https://learn.microsoft.com/en-us/entra/identity/saas-apps/netskope-administrator-console-provisioning-tutorial

- **Configure attribute write-back from Microsoft Entra ID to SAP SuccessFactors**

  Added explicit steps to create permission roles/groups and grant roles, clarified picklist preparation, and corrected data flow direction for write-back. Updated language to reference provisioning quarantine and improve consistency, helping admins configure write-back accurately.

  https://learn.microsoft.com/en-us/entra/identity/saas-apps/sap-successfactors-writeback-tutorial
