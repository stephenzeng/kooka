## Moderate Changes

- **Privileged roles and permissions in Microsoft Entra ID (preview)**

  Clarified that the Security Operator and Entra SOC Identity Responder roles are restricted to non-administrative user accounts and cannot act on privileged accounts. Notes were added in the tenant-scope role permission tables to prevent misinterpretation and guide correct role assignment and governance.
