# Microsoft Defender for Office 365
**Date created:** 2026-08-25 UTC  
**Tags:** Guidance, Security, Troubleshooting  

## Moderate Changes

- **Remove blocked users from the Restricted entities page**

  Updated guidance on identifying and managing restricted senders in Exchange Online PowerShell, clarifying when to use a UPN for hosted mailboxes versus an SMTP address for nonhosted senders. Command examples for Get-BlockedSenderAddress and Remove-BlockedSenderAddress now specify the correct identifier type, improving accuracy when viewing or removing restricted senders.
