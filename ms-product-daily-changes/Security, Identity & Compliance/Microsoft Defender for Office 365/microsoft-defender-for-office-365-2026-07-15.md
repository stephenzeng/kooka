# Microsoft Defender for Office 365
**Date created:** 2026-07-15 UTC  
**Tags:** Administration, Security  

## Moderate Changes

- **What's new in Microsoft Defender for Office 365**

  Added a July 2026 entry announcing that Unified RBAC is now the default permission model for new Defender for Office 365 Plan 2 organizations. Provides links to configuration guidance and the related Message Center post so admins can plan migrations and adjust role assignments accordingly.

  https://learn.microsoft.com/en-us/defender-office-365/defender-for-office-365-whats-new

- **How to run attack simulations for your team**

  Updated guidance with a clearer Overview, explicit scope, and concrete prerequisites (Defender for Office 365 Plan 2 and Security Administrator role). This improves setup accuracy for simulated phishing campaigns by clarifying required permissions, target selection, and training assignment steps.

  https://learn.microsoft.com/en-us/defender-office-365/step-by-step-guides/how-to-run-attack-simulations-for-your-team

- **Microsoft Defender for Office 365 permissions in the Microsoft Defender portal**

  Added an IMPORTANT note recommending Unified RBAC and noting it becomes the default for new Plan 2 tenants starting July 2026. Clarified that Email & collaboration roles are legacy and unavailable for new Plan 2 organizations, with links to Unified RBAC guidance to support migration planning.

  https://learn.microsoft.com/en-us/defender-office-365/mdo-portal-permissions

- **Roles and role groups in Microsoft Defender for Office 365 and Microsoft Purview**

  Clarified terminology and guidance by standardizing on “Microsoft Defender unified role-based access control (Unified RBAC).” Reinforced that Unified RBAC is recommended for Plan 2 and will be the default for new Plan 2 organizations starting July 2026, with references to related RBAC documentation for consistency.

  https://learn.microsoft.com/en-us/defender-office-365/scc-permissions

- **Steps to use manual email remediation in Threat Explorer**

  Added performance guidance to remediate in batches of 50,000 or fewer and to filter by delivery location and remediable folders for faster results. Included prerequisite reminders for licensing and permissions, and refined steps around approvals and how alerts and investigations are displayed to reduce errors and delays.

  https://learn.microsoft.com/en-us/defender-office-365/step-by-step-guides/search-for-emails-and-remediate-threats
