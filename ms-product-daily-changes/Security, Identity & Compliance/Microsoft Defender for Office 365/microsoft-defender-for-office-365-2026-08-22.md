# Microsoft Defender for Office 365
**Date created:** 2026-08-22 UTC  
**Tags:** Guidance, Security  

## Moderate Changes

- **Anti-phishing policies in cloud organizations**

  Updated guidance clarifying when the first contact safety tip is not applied, including for S/MIME-signed messages, messages that bypass spam filtering via an SCL -1 transport rule, and messages sent to newly created mailboxes (less than seven days old). Added a reference to SCL documentation to help admins validate and configure mail flow exceptions.

  https://learn.microsoft.com/en-us/defender-office-365/anti-phishing-policies-about
