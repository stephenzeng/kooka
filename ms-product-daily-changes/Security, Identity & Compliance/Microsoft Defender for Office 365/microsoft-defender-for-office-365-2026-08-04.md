# Microsoft Defender for Office 365
**Date created:** 2026-08-04 UTC  
**Tags:** Security  

## Moderate Changes

- **Bulk email detection and bulk complaint level (BCL) in cloud organizations**

  Clarified bulk mail handling: messages from senders in accepted domains aren’t labeled as Promotions, and the Promotions tag takes precedence over the External tag. This update helps admins better predict tagging outcomes and message placement in accepted-domain scenarios.
