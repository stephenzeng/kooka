# Microsoft Defender for Cloud Apps
**Date created:** 2026-08-07 UTC  
**Tags:** Administration, Security  

## Moderate Changes

- **How Defender for Cloud Apps helps protect your ServiceNow environment**

  Updated ServiceNow connection guidance to clarify prerequisites and account usage. Added Australia to the supported ServiceNow versions, instructed setting Scope Restriction to “Broadly Scoped,” and clarified authentication using the ServiceNow user name with an option to use a non-admin account. Introduced an optional least-privilege setup to create a non-admin user by defining custom read ACLs across multiple tables and assigning a common custom role, strengthening security and governance.
