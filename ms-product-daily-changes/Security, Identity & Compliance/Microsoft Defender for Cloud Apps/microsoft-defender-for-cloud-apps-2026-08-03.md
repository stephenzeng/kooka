# Microsoft Defender for Cloud Apps
**Date created:** 2026-08-03 UTC  
**Tags:** Security  

## Moderate Changes

- **Anomaly detection policies in Microsoft Defender for Cloud Apps**

  Updated guidance to reflect ongoing migration of anomaly detection policies to the dynamic threat detection model, including deprecating and renaming “Activity performed by terminated user” to “Activity by a deprovisioned user.” Standardized several policy names and headings, clarified Impossible travel sensitivity behavior, and refined malware detection and file sandboxing guidance. References were updated for Microsoft Defender XDR integration with Exchange Online, and redundant instructions about re-enabling deprecated policies were removed to reduce confusion.

  https://learn.microsoft.com/en-us/defender-cloud-apps/anomaly-detection-policy
