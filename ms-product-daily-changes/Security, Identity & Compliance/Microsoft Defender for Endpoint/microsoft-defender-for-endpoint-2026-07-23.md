# Microsoft Defender for Endpoint
**Date created:** 2026-07-23 UTC  
**Tags:** Administration, Security  

## New Articles

- **Configure Dynamic Preview Rings for Microsoft Defender on mobile**

  Introduced a new guide to enable Dynamic Preview Rings in the Microsoft Defender mobile app using Intune policies. Explains how to activate preview features with the DefenderPreview key (set to 1) for Android and iOS across both MDM (managed devices) and MAM (managed apps) scenarios. Details prerequisites, pilot scoping, and user experience indicators (yellow banner), along with benefits such as eliminating separate preview builds and simplifying testing. Highlights limitations, including no per-feature toggles and incompatibility with Microsoft Tunnel scenarios on Android, and provides step-by-step configuration and validation guidance.

  https://learn.microsoft.com/en-us/defender-endpoint/mobile-dynamic-preview-rings-configure

## Moderate Changes

- **Microsoft Defender for Endpoint release notes**

  Added July 2026 entries for Android (platform 1.0.9107.0101) and iOS (platform 1.1.79080103) to the release notes and tables. These updates focus on performance improvements and general bug fixes to enhance reliability on mobile platforms.

  https://learn.microsoft.com/en-us/defender-endpoint/microsoft-defender-endpoint-releases

- **Resources for Microsoft Defender for Endpoint for mobile devices**

  Updated the capabilities table to include Dynamic Preview Rings, enabling admins to turn on preview features for selected users in the production Defender app. Introduces the DefenderPreview setting (default 0, set to 1 to enable) across platforms, clarifying configuration options for targeted pilots.

  https://learn.microsoft.com/en-us/defender-endpoint/mobile-resources-defender-endpoint
