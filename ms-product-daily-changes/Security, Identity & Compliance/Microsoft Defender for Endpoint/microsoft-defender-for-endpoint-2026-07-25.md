# Microsoft Defender for Endpoint
**Date created:** 2026-07-25 UTC  
**Tags:** Administration, Security  

## Major Changes

- **Configure Microsoft Defender for Endpoint on iOS features**
  Updated guidance to reflect that OS update notifications are discontinued as of mid-July 2026. Starting in late July 2026, no configuration is required to suppress these notifications and related settings no longer apply, reducing admin overhead and preventing confusion. Prior suppression guidance is retained for historical context to help interpret older configurations and documentation.
  https://learn.microsoft.com/en-us/defender-endpoint/ios-configure-features

## Moderate Changes

- **User Experiences in Microsoft Defender for Endpoint on iOS**
  Added a deprecation notice for the Device Health feature beginning mid-July 2026, completing by late July 2026. The Device Health (iOS Update) recommendation card will no longer appear starting in late July 2026, clarifying expected user experience changes.
  https://learn.microsoft.com/en-us/defender-endpoint/ios-new-ux

- **New features in Microsoft Defender for Endpoint**
  Announced GA of the Defender Deployment Tool for Linux (version 101.26042.0011+), providing a consolidated workflow for install, onboarding, upgrade, and uninstall with automated prerequisite checks and support for custom paths and version/channel selection. The tool enhances fleet monitoring and troubleshooting through Device Timeline integration, Advanced Hunting signals, and detailed error reporting (stage, status, exit code, failure reason).
  https://learn.microsoft.com/en-us/defender-endpoint/whats-new-in-microsoft-defender-endpoint
