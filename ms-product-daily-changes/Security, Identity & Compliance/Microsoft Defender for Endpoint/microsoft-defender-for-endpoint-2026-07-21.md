# Microsoft Defender for Endpoint
**Date created:** 2026-07-21 UTC  
**Tags:** Security  

## Moderate Changes

- **Deployment guidance for Microsoft Defender for Endpoint on Linux for SAP**

  Added specific Pacemaker process exclusions to antivirus configuration for Linux on SAP, including pacemaker-controld, pacemaker-schedulerd, pacemaker-attrd, pacemaker-based, pacemaker-execd, and pacemaker-fenced, alongside existing pacemakerd and crm_* entries. Updated operational steps for disabling ClamAV under Azure Security policy with explicit restart and status verification, and clarified real-time protection terminology for greater consistency and accuracy.
