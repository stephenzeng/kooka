# Microsoft Defender for Endpoint
**Date created:** 2026-08-11 UTC  
**Tags:** Monitoring, Security  

## Moderate Changes

- **New features in Microsoft Defender for Endpoint**

  Added preview support for vulnerability assessment of Microsoft Store applications in Defender Vulnerability Management, enabling visibility into risks for Store-installed apps. The update clarifies how Software evidence presents file paths for vulnerable apps and provides a sample query to identify affected applications by name, version, and file location.
