# Microsoft Sentinel
**Date created:** 2026-08-19 UTC  
**Tags:** Security  

## Moderate Changes

- **How Microsoft names threat actors**

  Expanded the publicly disclosed threat actor list with new entries, then updated classifications for multiple Storm clusters to reflect current understanding (including reclassifying Storm-2581, 2981, 2999, 3075, and 3127 as financially motivated; moving Storm-2945 to Group in development and removing the “Midnight Blizzard sub-cluster” alias). Updated guidance to reference Microsoft Defender XDR threat analytics and aligned API references to Microsoft Threat Intelligence APIs in Microsoft Graph. These changes improve accuracy of actor tracking and clarify how to use APIs to support SecOps workflows.
