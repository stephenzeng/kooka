# Microsoft Sentinel
**Date created:** 2026-08-03 UTC  
**Tags:** Security  

## Moderate Changes

- **Manage security operations cases natively in the Microsoft Defender portal**

  Clarified that Projects in Microsoft Defender Threat Intelligence are deprecated and directed users to link indicators to a case in the Microsoft Defender portal to organize and investigate threat intel. This helps teams avoid outdated workflows and adopt the supported, case-centric process.

  https://learn.microsoft.com/en-us/unified-secops/cases-overview

- **Hunting in the Microsoft Defender portal**

  Updated hunting guidance to replace “Infrastructure chaining” with “Threat analytics,” including a revised tools table and instructions for the reactive stage. This aligns hunting workflows with current capabilities so analysts can investigate emerging threats and assess impact using Threat analytics.

  https://learn.microsoft.com/en-us/unified-secops/hunting-overview

- **Microsoft Defender portal**

  Renamed the service from “Microsoft Defender Threat Intelligence” to “Microsoft Threat Intelligence” and refined the description to highlight integrated threat intelligence across Microsoft Defender XDR and Microsoft Sentinel. Emphasizes aggregated and enriched threat data to support IOC investigations and threat hunting, clarifying product positioning and workflows.

  https://learn.microsoft.com/en-us/unified-secops/overview-defender-portal
