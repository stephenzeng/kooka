## Moderate Changes

- **Enable sensitivity labels for files in SharePoint and OneDrive**

  Updated guidance to reflect that MP4 video labeling support is now generally available rather than in preview, enabling broader production use. Clarifies that admins must still enable the capability via PowerShell, ensuring proper configuration before users can label MP4 files for data protection.
