# Microsoft Purview
**Date created:** 2026-07-29 UTC  
**Tags:** Security  

## Moderate Changes

- **Audit log activities**

  Expanded audit activities to capture additional EHR device connector operations, including installation from packages, listing, enabling/disabling, configuration updates, package verification, viewing, and deletion. This improves traceability of connector lifecycle actions for compliance and troubleshooting in healthcare-related environments. Administrators can better monitor changes and investigate issues across EHR device connectors.

  https://learn.microsoft.com/en-us/purview/audit-log-activities
