## New Articles

- **Microsoft Purview Endpoint DLP on macOS 27 (Preview)**

  Introduced comprehensive guidance on Endpoint DLP behavior changes in macOS 27, where required permission shifts from Accessibility to Device Control and Data Access. Details how turning off the permission affects signal collection (such as loss of browser/URL context), user notifications, and configurable protection modes for cloud egress and paste-to-browser activities. Provides configuration keys and MDM deployment samples for Microsoft Intune and Jamf Pro, along with an Audit mode to assess impact before enforcement. Includes prerequisites, administrator readiness steps, and portal-based permission monitoring to help plan and validate rollout.

  https://learn.microsoft.com/en-us/purview/endpoint-dlp-macos-27-changes
