# Microsoft Purview
**Date created:** 2026-07-23 UTC  
**Tags:** Administration, Governance, Security  

## Moderate Changes

- **Take mitigation actions in Data Security Investigations**

  Clarified purge permissions so that only members of the Data Security Investigation Admin or Data Security Investigation Investigator role groups can delete content during investigations. This strengthens role-based access controls and helps organizations enforce least-privilege practices without changing other procedures.

  https://learn.microsoft.com/en-us/purview/data-security-investigations-mitigation-actions

- **Get started with data loss prevention policies for Fabric and Power BI**

  Added guidance on gaining visibility into DLP activity and adoption through Fabric governance experiences in the OneLake catalog. Administrators can now track where DLP evaluates assets, see where sensitive information is detected, monitor policy adoption, prioritize remediation of high-risk items, and assess overall DLP effectiveness across the organization.

  https://learn.microsoft.com/en-us/purview/dlp-powerbi-get-started
