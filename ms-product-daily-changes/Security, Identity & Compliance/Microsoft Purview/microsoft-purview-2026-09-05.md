# Microsoft Purview
**Date created:** 2026-09-05 UTC  
**Tags:** Automation, Governance, Guidance  

## Moderate Changes

- **Search for data assets**
  
  Updated guidance clarifies how governed assets appear in search and what actions are needed for removal. It specifies that ungoverned assets must be deleted manually, with APIs available to automate deletion. It also explains that when an asset is removed from the Data Map but remains governed, links to data products, glossary terms, and critical data elements must be removed before it no longer appears in governed search.
  
  https://learn.microsoft.com/en-us/purview/unified-catalog-data-assets-search
