# Microsoft Purview
**Date created:** 2026-09-01 UTC  
**Tags:** Compliance, Governance, Monitoring  

## Moderate Changes

- **Audit log activities**

  Added new audit log coverage for Microsoft 365 Archive, including file-level events for when files are archived automatically, reactivated, or when reactivation is requested. Introduced a dedicated section for archive file-level policy activities that records policy creation, changes, site scoping, run start/completion, deletion, and outcomes with counts. These updates provide finer-grained visibility into archive actions and policy lifecycle to strengthen compliance monitoring and investigations.

  https://learn.microsoft.com/en-us/purview/audit-log-activities
