# Microsoft Purview
**Date created:** 2026-08-04 UTC  
**Tags:** Monitoring, Security  

## Moderate Changes

- **Audit log activities**

  Added coverage for Microsoft Defender for Cloud by introducing a new section that documents related audit events. Expanded audit event references to include operations across cloud environment connectors (AWS, Azure, GCP, GitHub, JFrog, Azure DevOps), enablement rule collections, global settings, rule collections, and individual rules. This helps security and compliance teams more accurately track creation, modification, enablement, and disablement actions across integrated environments.

  https://learn.microsoft.com/en-us/purview/audit-log-activities
