# Microsoft Purview
**Date created:** 2026-08-02 UTC  
**Tags:** Governance, Security  

## Major Changes

- **Automatically apply a sensitivity label to Microsoft 365 data**

  Expanded and reorganized guidance for auto-labeling, including a new pre-flight checklist and clearer prerequisites such as encryption requirements and SIT considerations. Added a comprehensive licensing and surfaces section with an entitlement table, common licensing symptoms, and explicit coverage for SharePoint/OneDrive and Exchange. Clarified simulation mode behaviors, provisioning delays, and limits, and refined override guidance to prevent unintended unlabeled content while explaining when removals/downgrades can leave content unlabeled. Introduced detailed instructions for removing or downgrading labels and a step-by-step troubleshooting flow to diagnose why items were or were not labeled.

  https://learn.microsoft.com/en-us/purview/apply-sensitivity-label-automatically

## Moderate Changes

- **Use Microsoft Purview to manage data security & compliance for AI agents**

  Updated the agent support matrix to reflect that ChatGPT Enterprise agents are no longer supported for discovery or governance. This change helps customers accurately assess integrations and adjust compliance strategies accordingly.

  https://learn.microsoft.com/en-us/purview/ai-agents
