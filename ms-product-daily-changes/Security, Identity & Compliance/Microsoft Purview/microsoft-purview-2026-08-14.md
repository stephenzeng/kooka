# Microsoft Purview
**Date created:** 2026-08-14 UTC  
**Tags:** Guidance, Troubleshooting  

## Moderate Changes

- **Automatically apply a sensitivity label to Microsoft 365 data**

  Updated prerequisites for OneDrive auto-labeling: the OneDrive account must be associated with the corresponding user account; detached accounts aren’t supported for auto-labeling or simulation. Guidance directs admins to use a properly associated account or move content to a supported SharePoint or OneDrive location before rerunning simulations to avoid failed or incomplete results.

  https://learn.microsoft.com/en-us/purview/apply-sensitivity-label-automatically
