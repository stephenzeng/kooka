# Azure SQL
**Date created:** 2026-09-02 UTC  
**Tags:** Configuration, Guidance, Identity, Security, Troubleshooting  

## Major Changes

- **Extended Events in Azure SQL**

  Added in-depth guidance for using Extended Events with Network security perimeter (preview), detailing required outbound access when writing and reading event data. Clarified supported scenarios across transition and enforced modes, including when resources must be within the same or linked perimeters and when FQDN rules or managed identity are needed. Provided step-by-step configuration for managed identity versus SAS tokens, highlighted limitations and potential silent failures, and documented key error codes (for example, 25602, 25759, 25717) with remediation. Included diagnostic steps using system views and perimeter logs and linked to related NSP content.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/xevent-db-diff-from-svr?view=azuresql

## Moderate Changes

- **Microsoft Entra-only authentication with Azure SQL**

  Added guidance on the system-generated CloudSA administrator account created during provisioning when Entra-only authentication is enabled. Clarified that this account can’t be used for sign-in, isn’t a break-glass path, and that its password is discarded after provisioning; also added an inline reference and minor wording improvements.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/authentication-azure-ad-only-authentication?view=azuresql

- **Azure SQL Database elastic query overview (preview)**

  Documented how Network security perimeter (preview) affects elastic query: queries are supported only when both the querying and remote databases are in the same perimeter. Cross-perimeter queries are blocked at execution time, and creating external data sources doesn’t validate connectivity; added links to related NSP guidance.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/elastic-query-overview?view=azuresql

- **Deploy Azure SQL Database for free**

  Introduced a new limitation: databases in the free offer can’t be copied. To copy, first convert the database to a paid service tier.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/free-offer?view=azuresql

- **Network security perimeter for Azure SQL Database (preview)**

  Updated preview terminology to Transition mode and added a Feature support section: Extended Events supported with outbound access considerations, elastic query supported within a single perimeter, and SQL Data Sync not supported. Noted availability only in Azure public cloud regions and added links to supplemental terms and onboarded services, with clarifications to setup guidance.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/network-security-perimeter?view=azuresql

- **What is SQL Data Sync for Azure?**

  Clarified that SQL Data Sync isn’t supported with Network security perimeter because it relies on a proxy service without a fixed FQDN/IP, and perimeter modes block required paths. Advised moving to a data movement solution that supports NSP if a logical server is associated with a perimeter; minor phrasing clarifications were also made.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/sql-data-sync-data-sql-server-sql-database?view=azuresql
