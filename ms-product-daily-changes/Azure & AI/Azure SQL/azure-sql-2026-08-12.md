# Azure SQL
**Date created:** 2026-08-12 UTC  
**Tags:** Best Practices, Configuration, Governance, Security  

## Moderate Changes

- **Azure SQL Database elastic query overview (preview)**
  
  Added a dedicated security section for external data sources, including guidance to use FQDNs instead of IPs, restrict ALTER ANY EXTERNAL DATA SOURCE permissions, periodically review sys.external_data_sources, and limit outbound networking to approved destination FQDNs. Updated limitations to clarify that, although examples use Azure SQL Database as the remote source, the LOCATION isn't syntactically restricted to Azure SQL Database and now cross-references the new security guidance. These updates help harden cross-database queries and reinforce separation of duties.
