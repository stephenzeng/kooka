# Azure SQL
**Date created:** 2026-08-18 UTC  
**Tags:** Configuration, Guidance, Performance  

## Major Changes

- **Availability through local and zone redundancy - Azure SQL Managed Instance**

  Announced preview support for zone redundancy in the Next-gen General Purpose service tier, enabling configuration of zone-redundant managed instances. Clarified that the preview supports flexible memory on Premium-series hardware and detailed how components are distributed across availability zones. Added a new subsection explaining the upgraded Elastic SAN-based remote storage layer to improve resilience and performance.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/high-availability-sla-local-zone-redundancy?view=azuresql

- **Use Next-gen General Purpose service tier - Azure SQL Managed Instance**

  Updated guidance to indicate that zone redundancy for Next-gen General Purpose is in preview, with support for flexible memory on Premium-series hardware. Added references to availability and resource limit documentation to help plan deployments and understand constraints. These updates streamline planning for high availability and memory scalability in this tier.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/service-tiers-next-gen-general-purpose-use?view=azuresql

## Moderate Changes

- **What's new in Azure SQL Managed Instance?**

  Expanded the Flexible memory entry to apply to all managed instances and documented preview availability of zone redundancy for Next-gen General Purpose. Added details that the preview supports flexible memory on Premium-series hardware and linked to availability and resource limits for quick discovery.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/doc-changes-updates-release-notes-whats-new?view=azuresql

- **Configure zone redundancy - Azure SQL Managed Instance**

  Updated configuration steps and considerations to include zone-redundant Next-gen General Purpose instances now in preview. Clarified that the preview supports flexible memory on Premium-series hardware, replacing earlier guidance that it wasn’t available.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/instance-zone-redundancy-configure?view=azuresql

- **Modifiable configuration reference for Azure SQL Managed Instance**

  Adjusted the zone redundancy configuration reference to reflect preview support for Next-gen General Purpose. This ensures the reference aligns with current capabilities.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/modifiable-configuration-reference?view=azuresql

- **Feature availability by region - Azure SQL Managed Instance**

  Added a note that zone redundancy for Next-gen General Purpose is in preview and supports flexible memory on Premium-series hardware. This helps determine regional deployment options and capabilities.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/region-availability?view=azuresql

- **Overview of Azure SQL Managed Instance resource limits**

  Clarified flexible memory availability for Next-gen General Purpose to cover both locally redundant (GA) and zone-redundant (preview) instances. This distinction helps with sizing and resilience planning across redundancy options.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/resource-limits?view=azuresql
