# Azure SQL
**Date created:** 2026-07-18 UTC  
**Tags:** Administration  

## Moderate Changes

- **T-SQL differences between SQL Server and Azure SQL Managed Instance**
  Updated the Compatibility levels section to state that Azure SQL Managed Instance supports compatibility level 100 and above, replacing version-specific listings. Guidance now clarifies that the default compatibility level for new databases depends on the instance's update policy, while restored databases keep their existing level if it is 100 or higher. Minor refinements were made to reference text for clarity.
  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/transact-sql-tsql-differences-sql-server?view=azuresql

- **Configure a workgroup availability group**
  Updated prerequisites to require Windows Server 2019 or later and SQL Server 2017 or later for configuring a workgroup availability group. This change aligns guidance with supported platforms and helps ensure reliable deployments.
  https://learn.microsoft.com/en-us/azure/azure-sql/virtual-machines/windows/availability-group-clusterless-workgroup-configure?view=azuresql
