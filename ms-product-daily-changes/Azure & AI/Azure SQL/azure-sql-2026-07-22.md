## Moderate Changes

- **Automated Backup for SQL Server on Azure VMs**

  Updated troubleshooting guidance for disabling Automated Backup when metadata issues occur. The steps now direct users to stop SQL Server Agent and SQL IaaS Agent, run a corrected T‑SQL command (USE msdb; EXEC autoadmin_metadata_delete), then restart both services before disabling from the Azure portal. This sequence reduces errors and streamlines remediation.
