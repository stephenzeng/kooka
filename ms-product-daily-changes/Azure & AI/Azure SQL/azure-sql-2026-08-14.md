# Azure SQL
**Date created:** 2026-08-14 UTC  
**Tags:** Configuration, Deprecation, Guidance  

## Moderate Changes

- **Active geo-replication**

  Clarified backup behavior differences across service tiers: in General Purpose, backups are taken on the primary, while in Business Critical they’re taken on secondary replicas (with reference). Updated guidance reinforces how to configure backup storage redundancy and highlights post-failover billing implications based on selected storage.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/active-geo-replication-overview?view=azuresql

- **What's new in Azure SQL Managed Instance?**

  Updated the AMQP deprecation entry by removing the requirement that new stream groups must use Azure Event Hubs as the destination_type. The timeline remains unchanged: AMQP deprecation begins August 15, 2026, and existing AMQP-based stream groups continue to work until April 2027, with migration guidance retained.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/doc-changes-updates-release-notes-whats-new?view=azuresql
