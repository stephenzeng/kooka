## New Articles

- **Modifiable Configuration Reference**

  Introduced new reference content that catalogs which Azure SQL Database and Azure SQL Managed Instance settings can be changed post-deployment and which are immutable. The guidance is organized by category (compute and storage, networking, security, HA/DR, backup and restore, and more) and notes constraints, required tools (portal, CLI, PowerShell), and operational impacts like downtime or one-way upgrades. It highlights key areas such as scaling options, connectivity and endpoints, authentication and encryption, redundancy and replication, maintenance windows, and diagnostics, and calls out unchangeable settings and service-specific constraints (for example, Hyperscale and Managed Instance). This helps teams plan safer changes, enforce governance, and streamline operations after deployment.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/modifiable-configuration-reference?view=azuresql
