# Azure SQL
**Date created:** 2026-08-01 UTC  
**Tags:** Administration, Security  

## Moderate Changes

- **What's new in Azure SQL Database?**

  Added preview support for regex-based dynamic data masking using REGEXP_REPLACE to create flexible, pattern-driven masking rules for variable-length strings. Announced deprecation of the AMQP protocol for Change Event Streaming: new stream groups must use Azure Event Hubs starting August 15, 2026, with existing AMQP groups supported until April 2027, guiding customers to plan migrations.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/doc-changes-updates-release-notes-whats-new?view=azuresql

- **Feature availability by region - Azure SQL Managed Instance**

  Updated regional availability: removed North Central US; removed Australia Southeast and India Central; added Central India and China North 3; added Austria East and Belgium Central. Clarified guidance for blocked zone redundant deployments, including capacity constraints, alternative regions/configurations, retry recommendations, and when to escalate via Azure support to improve deployment planning.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/region-availability?view=azuresql

- **vCore purchasing model - Azure SQL Managed Instance**

  Removed the note that memory-optimized premium-series hardware is in preview, aligning the page with current availability. Directs readers to the resource limits documentation for up-to-date specifications, reducing confusion and ensuring accurate sizing guidance.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/service-tiers-managed-instance-vcore?view=azuresql
