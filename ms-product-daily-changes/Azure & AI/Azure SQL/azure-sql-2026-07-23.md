- **Regex-based dynamic data masking (preview)**

  Introduced regex-based dynamic data masking for Azure SQL Database (public preview), enabling pattern-driven obfuscation for variable-length string data using the REGEXP_REPLACE masking function. Provides T-SQL syntax for creating and altering columns with regex masks, with practical examples for phone numbers and email addresses. Clarifies limitations and scope (T-SQL only, no new permissions, fixed arguments), supported data types, and validation via sys.masked_columns. Offers guidance on selecting patterns, handling unmatched values, and testing to ensure effective data protection.
