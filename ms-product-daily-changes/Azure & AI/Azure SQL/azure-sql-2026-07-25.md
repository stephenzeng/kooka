## Moderate Changes

- **Extended security updates (ESUs) for SQL Server on Azure Virtual Machines**

  Updated regional availability by removing the US Government Virginia region from ESU support for SQL Server on Azure Virtual Machines. This clarifies that ESUs are no longer offered in that region, impacting compliance and lifecycle planning for customers hosted there. Verify region eligibility and adjust deployment or support strategies accordingly.
