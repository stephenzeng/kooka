# Azure SQL
**Date created:** 2026-09-01 UTC  
**Tags:** Compliance, Configuration, Security  

## Moderate Changes

- **Automatic backup immutability for Azure SQL Database and Azure SQL Managed Instance**

  Clarified that on Azure SQL Managed Instance, automatic backup immutability is supported only when using the Always-up-to-date or SQL Server 2025 update policy, and not with the SQL Server 2022 policy. Reformatted the limitations into a bulleted list for easier scanning. This helps administrators choose compatible update policies and avoid compliance gaps.

  https://learn.microsoft.com/en-us/azure/azure-sql/automatic-backup-immutability?view=azuresql

- **Update policy in Azure SQL Managed Instance**

  Added automatic backup immutability to the set of features available under the SQL Server 2025 update policy. Removed the temporary note and caution about switching from SQL Server 2025 to Always-up-to-date being disabled, reflecting current behavior. This provides clearer guidance on feature availability and policy management.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/update-policy?view=azuresql
