# Azure SQL
**Date created:** 2026-07-30 UTC  
**Tags:** Administration, Monitoring  

## New Articles

- **Serverless auto-pause and auto-resume**

  Introduced a dedicated article explaining when Azure SQL Database serverless pauses and resumes, with prerequisites and limitations (supported in General Purpose). Outlines features and activities that block auto-pause and enumerates resume triggers from platform services and management actions. Provides guidance to trace resume events via Azure Monitor Activity log, sets expectations for latency, and explains BYOK TDE implications for key operations. Includes troubleshooting recommendations with connection retry logic and a T-SQL query to find sessions preventing pause.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/serverless-tier-auto-pause-resume?view=azuresql

- **Serverless Compute Tier Autoscaling**

  Added comprehensive guidance on autoscaling behavior in the serverless compute tier, including fast CPU scale-up within configured limits and rare rebalancing that can briefly drop connections. Clarifies memory management differences from provisioned compute and when cache is reclaimed or rehydrated. Details Hyperscale’s RBPEX disk cache growth and shrink behavior tied to workload demands.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/serverless-tier-auto-scaling?view=azuresql

- **Serverless compute tier billing**

  Documented how per-second billing is calculated based on the higher of CPU vCores or memory (normalized at 3 GB per vCore), including minimum bill behavior and the impact of paused state. Introduces new monitoring metrics for billed compute and explains reporting cadence. Provides step-by-step scenarios for General Purpose and Hyperscale (including replicas) to illustrate vCore-seconds and cost calculations, and clarifies that Azure Hybrid Benefit and Reservations don’t apply.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/serverless-tier-billing?view=azuresql

- **Create and configure a serverless database**

  Published a how-to guide for creating and configuring serverless databases via Azure portal, PowerShell, Azure CLI, and T-SQL, including setting min/max vCores and auto-pause delay. Covers moving databases between provisioned and serverless tiers and updating serverless settings after deployment. Notes important constraints such as Hyperscale not supporting auto-pause and default behaviors when provisioning via T-SQL.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/serverless-tier-create-configure?view=azuresql

- **Monitor Serverless Compute Tier**

  Introduced monitoring guidance tailored to serverless, explaining how billed compute is derived and which metrics matter most (CPU, memory, IO, workers, sessions). Shows how to view pause/resume history and current status in the portal, PowerShell, and Azure CLI, with clear status definitions. Helps teams track consumption trends and diagnose connectivity or performance issues more efficiently.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/serverless-tier-monitor?view=azuresql

## Major Changes

- **Serverless compute tier for Azure SQL Database**

  Restructured the overview for clarity and navigation, moving detailed procedures and troubleshooting to focused articles and updating references.
