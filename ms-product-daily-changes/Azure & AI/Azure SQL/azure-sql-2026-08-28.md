# Azure SQL
**Date created:** 2026-08-28 UTC  
**Tags:** Compliance, Deprecation, Governance, Security  

## Major Changes

- **Data Discovery & Classification**

  Retired label-based access protection using Microsoft Purview Information Protection policies for Azure SQL Database, and clarified that existing policies are no longer enforced. Updated the article to remove prior preview guidance and added a prominent notice reflecting the retirement. Introduced guidance directing customers to Microsoft Fabric protection policies for label-based access control going forward. Minor structural clean-up and image references were refreshed.
