# Azure SQL
**Date created:** 2026-07-31 UTC  
**Tags:** Analytics, Security  

## Moderate Changes

- **What's new in Azure SQL Managed Instance?**

  Added support for streaming SQL change events to Microsoft Fabric Eventstreams alongside Azure Event Hubs, expanding integration options for downstream analytics. Clarified that events are emitted for row-level DML on tracked tables and detailed CloudEvent payload contents (schema, previous values, new values) with JSON or Avro serialization; updates were applied across the features table and prior preview entry to align guidance.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/doc-changes-updates-release-notes-whats-new?view=azuresql

- **Azure Private Link for Azure SQL Database and Azure Synapse Analytics**

  Introduced preview support for IPv6 with Azure Private Link for Azure SQL Database, enabling configuration of private endpoints using IPv6 addresses. This improves connectivity options for IPv6-only and dual-stack networks and links to configuration guidance for deployment.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/private-endpoint-overview?view=azuresql
