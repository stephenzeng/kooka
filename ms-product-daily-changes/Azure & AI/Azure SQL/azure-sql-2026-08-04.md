**Date created:** 2026-08-04 UTC  
**Tags:** Administration, Security  

## New Articles

- **Automatic backup immutability**

  Introduced a new concept article explaining automatic backup immutability for Azure SQL Database and Azure SQL Managed Instance. The most recent seven days of point-in-time restore backups are now immutable by default, at no cost and without configuration, protecting restore points from tampering or deletion. This enhances resilience against ransomware and accidental deletion and supports regulatory record‑retention scenarios. Notes related backup capabilities and clarifies that Hyperscale is currently not supported.

  https://learn.microsoft.com/en-us/azure/azure-sql/automatic-backup-immutability?view=azuresql
