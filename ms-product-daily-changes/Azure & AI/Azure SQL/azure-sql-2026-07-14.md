# Azure SQL
**Date created:** 2026-07-14 UTC  
**Tags:** Administration, Security  

## Moderate Changes

- **Configure link with SSMS - Azure SQL Managed Instance**

  Updated guidance to note a preview in SSMS v22.7.0 for adding multiple databases when creating a link. The capability is disabled by default and requires an access request, helping teams plan adoption timelines and feature availability.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/managed-instance-link-configure-how-to-ssms?view=azuresql

- **Move Azure SQL Managed Instance across subnets**

  Added prerequisites to verify end-to-end connectivity on ports 5022 and 11000–11999 before a subnet move, including checks across UDRs, NVAs, and firewalls. Clarified failover group requirements to ensure the target subnet and full network path allow the same replication traffic, reducing move failures and preserving replication continuity.

  https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/vnet-subnet-move-instance?view=azuresql
