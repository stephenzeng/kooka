# Azure SQL
**Date created:** 2026-08-06 UTC  
**Tags:** Security  

## Moderate Changes

- **Transparent data encryption (TDE) with customer-managed keys at the database level**

  Added support for storing symmetric (AES) TDE protector keys in Azure Key Vault Premium (preview) alongside Azure Key Vault Managed HSM. Clarified that ongoing key lifecycle operations (including recovery and revalidation) are supported when keys reside in Key Vault Premium (preview) or Managed HSM, and clarified import and backup responsibilities.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/transparent-data-encryption-byok-database-level-overview?view=azuresql

- **Azure SQL transparent data encryption with customer-managed key**

  Expanded support for symmetric TDE protector keys to include Azure Key Vault Premium (preview) in addition to Azure Key Vault Managed HSM. Updated limitations to state that lifecycle operations and one-time key imports must use Key Vault Premium (preview) or Managed HSM, and that recovery and revalidation rely on these services.

  https://learn.microsoft.com/en-us/azure/azure-sql/database/transparent-data-encryption-byok-overview?view=azuresql
