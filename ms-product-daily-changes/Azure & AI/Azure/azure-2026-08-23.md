# Azure
**Date created:** 2026-08-23 UTC  
**Tags:** Configuration, Guidance, Identity, Monitoring, Performance, Security  

## Moderate Changes

- **API Management self-hosted gateway Arc settings**

  Clarified configuration semantics and standardized Required and Default values for multiple settings, including backup PVC options and Dapr integration fields, to make optionality and defaults explicit. Corrected the valid StatsD tagFormat to “librato” and refined notes for NodePort-related settings. These updates reduce misconfiguration risk and improve deployment predictability.

  https://learn.microsoft.com/en-us/azure/api-management/self-hosted-gateway-arc-reference

- **Understanding Azure API Management Service Limits**

  Added guidance on gateway capacity throttling that can return HTTP 429 to protect the service under load. Provides clear actions to scale out or up and links to capacity planning guidance to prevent request rejection.

  https://learn.microsoft.com/en-us/azure/api-management/service-limits

- **SMART on FHIR**

  Expanded the SMART user role documentation to detail supported read and search capabilities, including SMART v2 verb mapping and the requirement for “s” to enable searches beyond read-by-ID. Documented restrictions such as limits on $export, $member-match, complex include/revinclude and chained searches to uncovered resource types, and the absence of write permissions; also noted that the role alone without SMART clinical scopes grants no data access. Updated configuration guidance to reference these capabilities and clarify scope- and fhirUser-based limitations.

  https://learn.microsoft.com/en-us/azure/healthcare-apis/fhir/smart-on-fhir
