## Major Changes

- **Azure Cosmos DB support matrix**

  Introduced daily incremental backups with a mandatory weekly full to achieve a 1-day RPO and clarified that incremental-only policies aren’t supported. Specified that on-demand backups are full-only and described restore chain requirements. Added limitations including lack of NSP support and clarified auto-heal scope for scheduled backups.

  https://learn.microsoft.com/en-us/azure/backup/backup-azure-cosmos-db-support-matrix

- **Create an App Service Environment**

  Clarified that Regional deployments don’t distribute plan instances across availability zones and can face downtime during zone/region outages. Expanded zone-redundant guidance: require at least two instances per plan and multiple active app replicas, and warned that per-app scaling limit of one doesn’t provide a simultaneous replica. Noted that recovery may rely on cold-starting replicas and isn’t guaranteed.

  https://learn.microsoft.com/en-us/azure/app-service/environment/creation

- **Per-app scaling for high-density hosting**

  Major overhaul clarifying perSiteScaling and worker limits versus plan capacity and observed instances. Added detailed configuration steps for CLI, PowerShell, Bicep, ARM, and REST with verification, property model, and modern API versions. Emphasized placement behavior, scale-in effects, zone redundancy interactions, and workload-specific recommendations for high-density hosting.

  https://learn.microsoft.com/en-us/azure/app-service/manage-scale-per-app

- **Quickstart: Work Item Filtering With the Durable Task SDKs**

  Expanded to cover .NET and Java with language pivots and clarified that .NET now auto-generates filters from the task registry (no explicit opt-in required). Added clean-up steps, strict routing experiments, and deployment/monitoring guidance, plus a note that JavaScript/Python/PowerShell aren’t yet supported. Enhanced examples and next steps for getting started.

  https://learn.microsoft.com/en-us/azure/durable-task/scheduler/quickstart-work-item-filtering-durable-task

- **Azure Firewall SNAT private IP address ranges**

  Substantially restructured and expanded content, removing preview status for auto-learn SNAT routes and clarifying support for VNets and secured vHubs. Added end-to-end configuration by method (Portal/ARM for policy, PowerShell/CLI for classic), ARM samples with updated API versions, and steps for new/existing firewalls. Detailed prerequisites and verification for auto-learn with notes that CLI doesn’t support auto-learn configuration.

  https://learn.microsoft.com/en-us/azure/firewall/snat-private-range

- **Troubleshoot Azure Front Door common issues**

  Refocused timeouts on 504 errors with updated diagnostics and default/max origin response timeouts. Reworked HTTPS failures to 502 with root causes like incomplete certificate chains and provided OpenSSL commands and SNI guidance; clarified custom domain routing rules and HTTPS redirection configuration. Updated rate limiting guidance for 429s, removed obsolete content, and aligned status codes for IP-origin scenarios.

  https://learn.microsoft.com/en-us/troubleshoot/azure/front-door/troubleshoot-issues

- **Monitor a multi-agent app with OpenTelemetry and Application Insights (.NET)**

  Expanded the tutorial to cover applying GenAI monitoring patterns across .NET, Python, Node.js, and Java, including integrating agents with existing logic and instrumenting telemetry.
