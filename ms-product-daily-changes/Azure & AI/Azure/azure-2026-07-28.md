## New Articles

- **Backup and restore Azure API center**

  Introduced detailed guidance to back up and restore Azure API Center with the apiops CLI, including what’s included and excluded in backups. Provides step-by-step extract and publish workflows, options for scheduling, DR, and cross-tenant migrations, and handling of Key Vault secret references. Includes verification steps and a troubleshooting table to speed resolution.

  https://learn.microsoft.com/en-us/azure/api-center/backup-restore

- **Azure Elastic SAN datastore support on AVS using service endpoints**

  Added a how-to for configuring Elastic SAN datastores on Azure VMware Solution Gen 2 using Virtual Network service endpoints for lower cost and simpler routing versus Private Endpoints. Explains architecture, hostname-based iSCSI discovery, firewall and VNet rules, and security considerations (private backbone, optional CHAP). Lists requirements and limitations, including same-region deployment and DNS resolution.

  https://learn.microsoft.com/en-us/azure/azure-vmware/elastic-san-datastore-support-service-endpoints

- **Infrastructure Resiliency Manager overview - Azure**

  Introduced Infrastructure Resiliency Manager (preview) to assess and improve resiliency posture at scale. Explains capabilities like goals and recommendations, Availability Zone down drills, and recovery orchestration planning. Describes how to manage resources and service groups, assign goals, attest configurations, and interpret posture categories.

  https://learn.microsoft.com/en-us/azure/resiliency/infrastructure-resiliency-manager-overview

- **Assign IP addresses from defined pools to P2S VPN users - Azure CLI**

  New guide for assigning client IPs from defined address pools to Point-to-site VPN users with Azure CLI. Covers prerequisites, supported authentication methods, and a complete configuration workflow for policy groups, address pools, and client profiles. Provides commands to verify mappings and clean up configurations.

  https://learn.microsoft.com/en-us/azure/vpn-gateway/point-to-site-user-groups-create-cli

- **Mitigate hot partitions in Azure Blob Storage**

  New conceptual article explaining hot partitions, how to detect throttling via metrics and logs, and how to alert on key indicators. Recommends mitigation strategies such as improving naming to distribute load, using exponential backoff retries, and gradually ramping traffic. Links to related performance targets and monitoring best practices.

  https://learn.microsoft.com/en-us/azure/storage/blobs/storage-performance-mitigate-hot-partitions

## Major Changes

- **Azure networking services overview**

  Added a new Container networking category with services for security and observability, consolidated under Advanced Container Networking Services for AKS. Included a summary table mapping networking areas to services, use cases, and learn-more links. Highlighted the deprecation of Basic Load Balancer (retiring Sep 30, 2025), clarified SKU availability, expanded Azure Front Door positioning, detailed Bastion SKU tiers, and improved service descriptions and structure to guide selection.

  https://learn.microsoft.com/en-us/azure/networking/networking-overview

- **Troubleshooting guide for Azure Service Bus | Microsoft Docs**

  Expanded troubleshooting with new pre-checks (Service Health/Resource Health), deeper timeout analysis, and per-SDK guidance on receive behavior and retry policies. Added managed identity troubleshooting, including required roles, token scopes, credential resolution, propagation delays, and AKS workload identity configuration. Introduced TLS certificate chain guidance to resolve trust issues while emphasizing keeping TLS validation enabled, with supporting references for each topic.

  https://learn.microsoft.com/en-us/azure/service-bus-messaging/service-bus-troubleshooting-guide

## Moderate Changes

- **Azure Service Bus - Automatically update messaging units**

  Added cost guidance for autoscale, explaining hourly billing based on peak messaging units. Recommends longer scale-down cool-downs (30+ minutes) and conservative thresholds to avoid unintended costs, with links to additional autoscale conditions.

  https://learn.microsoft.com/en-us/azure/service-bus-messaging/automate-update-messaging-units

- **Azure Load Balancer components**

  Clarified protocol support in limitations: load-balancing and inbound NAT rules support TCP/UDP, and internal load balancer HA Ports support TCP, UDP, and ICMP. This removes ambiguity around protocol capabilities for specific rule types.

  https://learn.microsoft.com/en-us/azure/load-balancer/components

- **Configure an NFS client for Azure NetApp Files**

  Added guidance for NFSv4.1 when LDAP is enabled, addressing issues like UID/GID lookup failures and “nobody” ownership. Advises validating LDAP/SSSD configuration and disabling fully qualified names in SSSD to resolve identity mapping problems.

  https://learn.microsoft.com/en-us/azure/azure-netapp-files/configure-nfs-clients

- **Cross-subscription load balancer**

  Documented that SyncMode must be set before adding backend addresses and listed the specific error when misconfigured. Clarified key requirements and unsupported scenarios (API versions, VNet specification immutability, same-region scope, NAT pools, cross-region backends, and Gateway Load Balancer chaining), and refined explanations of Automatic vs Manual SyncMode.

  https://learn.microsoft.com/en-us/azure/load-balancer/cross-subscription-overview

- **Configure TCP reset and idle timeout for Azure Load Balancer**

  Clarified idle timeout ranges by rule type: Load Balancer and inbound NAT rules remain 4–100 minutes, while outbound rules support 4–120 minutes. Reiterated the 4-minute default across all rule types to align deployments and expectations.

  https://learn.microsoft.com/en-us/azure/load-balancer/load-balancer-tcp-idle-timeout

- **Load Balancer TCP Reset and Idle Timeout**

  Corrected idle timeout guidance, noting outbound rules allow 4–120 minutes while other rules remain 4–100 minutes, with a consistent 4-minute default. This resolves prior ambiguity that grouped outbound with the 4–100 minute range.

  https://learn.microsoft.com/en-us/azure/load-balancer/load-balancer-tcp-reset

- **Manage health probes for Azure Load Balancer using the Azure portal**

  Clarified probe Interval defaults: Azure portal pre-fills 5 seconds, while ARM/REST/CLI/PowerShell default to 15 seconds (minimum 5 seconds). Also confirmed Path applies to both HTTP and HTTPS probes and is required when using HTTP.

  https://learn.microsoft.com/en-us/azure/load-balancer/manage-probes-how-to

- **Azure Front Door (classic) and CDN Standard from Microsoft (classic) migration FAQ**

  Added Applies to coverage and retirement notices for Front Door (classic) and Azure CDN from Microsoft (classic). Minor clarifications improve downtime statements and post-migration DNS/CNAME steps.
