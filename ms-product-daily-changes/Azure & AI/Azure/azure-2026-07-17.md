**Date created:** 2026-07-17 UTC

## Major Changes

- **Azure ExpressRoute: Router configuration samples**

  Added Arista router configuration alongside Cisco IOS-XE and Juniper MX and reorganized the content into vendor-specific tabs for interfaces, BGP, route policies, BFD, and MACsec. The article now includes Arista examples for Dot1Q/QinQ, routing, and security, and consolidates guidance to reduce ambiguity. A new Next steps section helps readers navigate to related guidance, streamlining multi-vendor deployments and reducing configuration errors.

  https://learn.microsoft.com/en-us/azure/expressroute/expressroute-config-samples-routing

- **About ExpressRoute connections in Azure Virtual WAN**

  Introduced a comprehensive section on ExpressRoute FastPath in Virtual WAN, explaining how eligible flows bypass the gateway to improve performance. Clarified default enablement for ExpressRoute Direct circuits when the Virtual WAN ExpressRoute Gateway has at least 5 scale units, with detailed applicability across destinations and hub security scenarios. Added IP address capacity limits by circuit type and recommended setting Azure Monitor alerts to prevent hitting thresholds, helping teams plan scale and maintain reliability.

  https://learn.microsoft.com/en-us/azure/virtual-wan/virtual-wan-expressroute-about

## Moderate Changes

- **Azure ExpressRoute FastPath: Features, availability, and limitations**

  Expanded guidance to cover FastPath behavior with Azure Virtual WAN, including default enablement for ExpressRoute Direct circuits connected to Virtual WAN gateways with at least 5 scale units. Updated the availability table and gateway SKUs to reflect Virtual WAN scenarios, helping readers validate eligibility quickly.

  https://learn.microsoft.com/en-us/azure/expressroute/about-fastpath

- **Release notes for ALB Controller**

  Updated the latest release to 1.11.3 with security patches, WAF fixes, and an Istio cert-rotation fix, and expanded the release history. The notes also reintroduce 1.11.1 features and add 1.10.32 changes, giving operators clearer upgrade guidance and security context.

  https://learn.microsoft.com/en-us/azure/application-gateway/for-containers/alb-controller-release-notes

- **ExpressRoute FAQ**

  Added an FAQ explaining how FastPath works with Azure Virtual WAN, noting that it’s automatically enabled for ExpressRoute Direct circuits when the Virtual WAN ExpressRoute Gateway has at least 5 scale units. This clarifies eligibility and configuration expectations to speed deployments.

  https://learn.microsoft.com/en-us/azure/expressroute/expressroute-faqs

- **Use the Resiliency agent in Infrastructure Resiliency Manager (preview)**

  Updated IaC guidance to remove Terraform from generated outputs; the agent now produces ARM or Bicep templates with resiliency settings. This clarifies supported tooling and avoids setup confusion.

  https://learn.microsoft.com/en-us/azure/resiliency/goals-recommendations-use-agent

- **Enable secure settings in Azure IoT Operations**

  Clarified that OIDC issuer and workload identity for AKS can be enabled during cluster creation or on existing clusters. This flexibility helps teams align identity settings with their provisioning and upgrade workflows without re-creating clusters.

  https://learn.microsoft.com/en-us/azure/iot-operations/secure-iot-ops/howto-enable-secure-settings

- **Prepare your Azure Arc-enabled Kubernetes cluster**

  Reorganized guidance for Azure Container Storage enabled by Azure Arc (ACSA), replacing distro-specific notes with a dedicated, generalized section. Added links to overview, Linux prep, and Edge Volumes setup, and clarified ACSA is optional and installed separately, simplifying planning and installation.

  https://learn.microsoft.com/en-us/azure/iot-operations/deploy-iot-ops/howto-prepare-cluster

- **Quickstart: Deploy Application Gateway for Containers ALB Controller**

  Updated Helm command examples to use chart version 1.11.3 for both installation and upgrades across Bash and PowerShell. This ensures users deploy the latest build with recent fixes.

  https://learn.microsoft.com/en-us/azure/application-gateway/for-containers/quickstart-deploy-application-gateway-for-containers-alb-controller-helm

- **SAP HANA Backup support matrix**

  Clarified snapshot policy availability: Standard policy snapshots are GA and Enhanced policy snapshots are in Preview. Added instance snapshot backup support (Preview, Enhanced policy only) and reaffirmed that HANA scale-out backups remain in Preview, helping customers choose appropriate policies.

  https://learn.microsoft.com/en-us/azure/backup/sap-hana-backup-support-matrix

- **About the SAP HANA database backup on Azure VMs**

  Expanded HSR guidance to support both Backint and instance snapshot backups through the Enhanced (Preview) policy, and clarified policy subtypes (Standard GA vs. Enhanced Preview). Noted that both HSR nodes must remain registered to the same vault as a single logical container and updated scale-out status, improving configuration accuracy.

  https://learn.microsoft.com/en-us/azure/backup/sap-hana-database-about

- **Back up SAP HANA database instances on Azure VMs**

  Added support details for HSR-enabled systems, specifying that snapshot backups require both nodes registered to the same vault and are available only with the Enhanced (Preview) policy. Introduced snapshot policy subtypes and a new section on snapshot consistency, I/O quiescing, backup cadence (initial full, incremental thereafter, weekly full), and restore behavior with log replay, guiding reliable protection and recovery.

  https://learn.microsoft.com/en-us/azure/backup/sap-hana-database-instances-backup

- **Install and run Azurite emulator**

  Raised the required Node.js version for GitHub-based installation to 21.0 or later. Developers should update local environments to avoid install failures.

  https://learn.microsoft.com/en-us/azure/storage/common/storage-install-azurite

- **Stream data as input into Stream Analytics**

  Added an Important notes section explaining that Event Hubs application property names are treated as case-insensitive with a first-win policy for duplicates differing only by case. This helps prevent unexpected property overwrites in input streams.

  https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-define-inputs

- **What's new in the Azure Backup service**

  Added a July 2026 entry announcing preview support for HSR with SAP HANA instance snapshot backups. The update explains how HSR systems can use HANA-consistent snapshots alongside Backint for long-term retention and point-in-time recovery, with links to configuration and the support matrix.

  https://learn.microsoft.com/en-us/azure/backup/whats-new
