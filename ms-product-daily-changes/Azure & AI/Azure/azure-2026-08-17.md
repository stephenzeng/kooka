# Azure
**Date created:** 2026-08-17 UTC  
**Tags:** Automation, Configuration, Get Started, Guidance, Monitoring  

## Major Changes

- **Migrate data from Google Cloud Storage to Azure Blob Storage with Azure Storage Mover**

  Updated the guide with end-to-end, tabbed instructions for both the Azure portal and Azure CLI. Added CLI steps to secure GCS HMAC keys in Key Vault, create a GCS source endpoint using S3-compatible HMAC, and configure a Blob Storage target endpoint. Introduced CLI-based RBAC assignments using managed identities to grant Key Vault and Blob permissions required for migrations. Expanded CLI coverage to create projects and job definitions (including optional private connections), start jobs, and monitor runs, enabling fully automated deployments. The reorganization removes placeholders and provides concrete, repeatable automation guidance.

  https://learn.microsoft.com/en-us/azure/storage-mover/google-migration

- **Job scheduling in Azure Storage Mover**

  Added comprehensive scheduling guidance with portal/CLI tabs and detailed CLI examples. You can now create one-time, daily, weekly (specific days), and monthly (specific days) schedules with precise start/end dates, activation controls, and execution times. The update also documents how to update, show, enable, or disable schedules via CLI without deleting them, improving operational control and repeatability for automated migrations.

  https://learn.microsoft.com/en-us/azure/storage-mover/job-scheduling

## Moderate Changes

- **Migrate multicloud data from external sources using Azure Storage Mover private connections**

  Expanded configuration guidance with portal/CLI tabs for setting up private connections using Private Link Service Direct Connect. New CLI examples cover creating and approving private endpoint connections, verifying status, and referencing approved connection resource IDs in job definitions for S3 and GCS to Azure Blob migrations. The guidance clarifies that only approved connections can be used and suggests using multiple connections to increase throughput.

  https://learn.microsoft.com/en-us/azure/storage-mover/cloud-to-cloud-private-network-configuration
