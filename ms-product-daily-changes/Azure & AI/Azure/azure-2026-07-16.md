## Major Changes

- **Azure Load Balancer portal settings**
  Updated guidance to reflect retirement of the Basic SKU for Load Balancer and Public IPs, leaving only Standard and Gateway SKUs. Standardized public IP guidance to Standard with zone resiliency and removed Basic-specific behaviors. Also adjusted Public IP Prefix sizes (IPv4 /28–/31; IPv6 /124–/127) and removed Basic-related availability zone limits, simplifying configuration choices.
  https://learn.microsoft.com/en-us/azure/load-balancer/manage

- **Key-values**
  Added API pivots v24-09 and v26-04 and introduced tags filtering for Get/List operations, enabling combined key/label/tags queries. For v26-04, added a description field to key-values and updated schemas, examples, pagination, and conditional listing guidance across pivots. These changes improve discoverability and metadata management for configuration items.
  https://learn.microsoft.com/en-us/azure/azure-app-configuration/rest-api-key-value

- **Snapshot**
  Expanded to include v24-09 and v26-04 pivots with version-specific schemas and responses. v26-04 adds a richer snapshot schema (for example, composition_type, retention_period, items_count, size, status) and a dedicated Create snapshot section with validation rules, examples, and constraints. This enables more precise snapshot lifecycle control and clearer API usage across versions.
  https://learn.microsoft.com/en-us/azure/azure-app-configuration/rest-api-snapshot
