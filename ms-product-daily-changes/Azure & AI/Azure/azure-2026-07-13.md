- **Migrate to type-safe serialization in Durable Functions for Python**

  Introduced a how-to guide for adopting type-safe (type-aware) serialization in Durable Functions for Python, including centralized serializers (df_dumps/df_loads) and Durable Functions routing. Explains loose vs. strict modes, prerequisites and package versions, and a phased migration: upgrade packages, enable loose-mode validation with expected_type and trigger input_type, update custom types to be JSON-serializable, then enable strict mode via AZURE_FUNCTIONS_DURABLE_STRICT_TYPING. Provides limitations of strict mode and patterns to handle in-flight legacy payloads, plus versioning and rollout guidance to avoid breaking running orchestrations. Emphasizes security hardening benefits and references related Durable Functions documentation.
