## New Articles

- **Compare the Azure Functions serverless agents runtime with other Microsoft agent options**

  New conceptual guidance contrasts the Azure Functions serverless agents runtime with Foundry prompt/hosted agents, Copilot Studio, and Microsoft Scout. It explains differences in authoring, hosting, cost, and best‑fit scenarios, and includes a side‑by‑side comparison table. The article also highlights shared foundations like Microsoft Agent Framework and MCP to reuse tools and points to related resources, noting preview status.

  https://learn.microsoft.com/en-us/azure/azure-functions/compare-serverless-agents-runtime

- **What is Launch mode for Azure Compute Fleet? (Preview)**

  Introduces Launch mode, optimized for orchestrators to bulk provision up to 10,000 VMs across sizes, pricing (Spot/Standard), and zones with custom naming and tag propagation—at no additional fleet cost. Launch mode asynchronously provisions VMs, then self‑deletes, leaving VMs for direct lifecycle management. The article provides REST examples, guidance to discover/monitor VMs via the Fleet List VMs API (including operationStatus states), and clarifies preview limitations like immutability and upfront quota validation.

  https://learn.microsoft.com/en-us/azure/azure-compute-fleet/launch-mode

- **What is network monitoring and management?**

  Offers an overview of Azure network monitoring and management scenarios and decision factors. It explains how to use Azure Network Watcher, Azure Virtual Network Manager, and Azure Monitor individually and together, with portal hub experience walkthroughs. The article links to next steps for each service to accelerate solution selection.

  https://learn.microsoft.com/en-us/azure/networking/monitoring-management/network-monitoring-management-overview

- **Build a serverless workflow using Durable Functions in Azure Functions**

  A new quickstart shows how to build a fan‑out/fan‑in workflow using Durable Functions on Flex Consumption with Azure Developer CLI. It covers language‑specific prerequisites, template initialization, Bicep‑based provisioning, and local development with Azurite and Functions Core Tools. You’ll learn to run and monitor orchestrations locally, review concurrency patterns, deploy with azd, call secured HTTP endpoints, and clean up resources.

  https://learn.microsoft.com/en-us/azure/azure-functions/scenario-build-serverless-workflow
