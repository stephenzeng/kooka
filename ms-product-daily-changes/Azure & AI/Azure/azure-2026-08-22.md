## New Articles

- **Secure your Azure Blob Storage**

  Introduced a comprehensive best-practices guide for securing Blob Storage and Data Lake Storage. Clarifies networking patterns (for example, fronting with Azure Front Door and avoiding default static websites when not needed) and prioritizes identity-based access with user-delegation SAS and ABAC using blob index tags. Adds prescriptive guidance for encryption scopes, client-side encryption, immutability policies, cross-tenant replication controls, backup and restore features, and extensive logging and monitoring with actionable alerts.

  https://learn.microsoft.com/en-us/azure/storage/blobs/secure-blobs

- **Secure your Azure Files**

  Published a security best-practices guide for Azure Files covering SMB and NFS. Recommends SMB 3.x encryption, strict protocol and cipher choices, Kerberos-first authentication, and avoiding account keys for data access. Provides guidance for authorization, backup and snapshots, monitoring for risky patterns (for example, NTLM use or account-key mounts), and secure Azure File Sync operations with scoped identities.

  https://learn.microsoft.com/en-us/azure/storage/files/secure-files

- **Secure your Azure Queue Storage**

  Added best-practices guidance for securing Queue Storage with Microsoft Entra roles and narrowly scoped SAS. Advises against storing secrets in messages, using application-layer encryption with Key Vault, and setting appropriate TTLs. Recommends diagnostics to Log Analytics, poison-queue handling, and alerts for anomalous dequeue/delete behavior.

  https://learn.microsoft.com/en-us/azure/storage/queues/secure-queues

- **Secure your Azure Storage account**

  Delivered an end-to-end storage account security guide spanning network controls, identity and access management, encryption, monitoring, and compliance. Emphasizes private connectivity, disabling Shared Key and public network access, least-privilege RBAC with ABAC conditions, robust SAS governance, and CMK with Vault/HSM. Covers Defender for Storage, diagnostic logging, governance with Azure Policy, and resilience via redundancy, immutability, and soft delete/versioning.

  https://learn.microsoft.com/en-us/azure/storage/common/secure-storage

- **Secure your Azure Table Storage**

  Published best practices for Table Storage security and when to choose Azure Table Storage vs. Azure Cosmos DB for Table. Recommends Entra-based roles with table-scoped permissions, precise SAS constraints by partition/row keys, and client-side encryption for sensitive properties. Adds monitoring guidance to audit Shared Key usage and detect unusual high-volume updates/deletes.

  https://learn.microsoft.com/en-us/azure/storage/tables/secure-tables

## Major Changes

- **Authentication required error message in Azure Container Registry**

  Overhauled the troubleshooting article with a clear flow separating authentication and repository authorization issues. Adds detailed steps for interactive and workload identities, repository-scoped tokens, and RBAC vs. ABAC permissions with example CLI commands. Includes validation tips, notes on propagation, how to clear stale Docker credentials, and optional log-based diagnostics with Kusto queries.

  https://learn.microsoft.com/en-us/troubleshoot/azure/azure-container-registry/authentication-required

- **Can't delete a virtual network or subnet used by ACI**

  Expanded guidance explains modern vs. legacy ACI networking and how service association links (SAL) and legacy network profiles block deletion. Provides step-by-step workarounds to enumerate and remove container groups, delete the SAL via CLI/PowerShell, and safely remove legacy profiles using portal or CLI with validation steps. Adds cautions about extension resource paths, API version implications, and preventing unintended VNet deletion.

  https://learn.microsoft.com/en-us/troubleshoot/azure/azure-container-instances/connectivity/cannot-delete-vnet-subnet

- **Set up Pacemaker on Red Hat Enterprise Linux in Azure**

  Modernized and restructured the RHEL Pacemaker guide with updated version support and modular, pivoted sections. Adds clearer fencing options, cluster deployment steps, firewall and package guidance, delayed startup configuration, and multi-node considerations. Introduces Azure scheduled events handling via azure-events-az and refreshed fence_kdump guidance with streamlined, validated steps.

  https://learn.microsoft.com/en-us/azure/sap/workloads/high-availability-guide-rhel-pacemaker

- **Set up Pacemaker on SUSE Linux Enterprise Server in Azure**

  Significantly reworked the SLES Pacemaker guide with version support, modular fencing options, and streamlined iSCSI/shared-disk setup. Adds DNS, SSH key exchange, OS tuning, timed startup, and detailed Azure fence agent configuration for managed identity or service principal scenarios. Covers multi-node cluster tuning, scheduled events via azure-events-az with health attributes, and updated validation and next steps.

  https://learn.microsoft.com/en-us/azure/sap/workloads/high-availability-guide-suse-pacemaker

- **Troubleshoot AKS cluster connection issues with the API server**

  Reorganized the article into a staged diagnostic flow: DNS, network connectivity, then authentication/authorization. Provides concrete CLI checks for endpoint type and configuration, DNS validation guidance for public and private clusters, and timed curl-based connectivity tests. Adds targeted paths for private endpoint and authorized IP ranges scenarios, kubeconfig and kubelogin validation, version skew considerations, and kubelet connectivity requirements for node operations.

  https://learn.microsoft.com/en-us/troubleshoot/azure/azure-kubernetes/connectivity/troubleshoot-cluster-connection-issues-api-server

- **Cannot push images or artifacts to Azure Container Registry**

  Major expansion adds a structured approach to distinguish client-side and registry-side failures, with error-to-scenario mapping. Introduces Docker/Podman health checks, az acr check-health, challenge endpoint tests, and comprehensive guidance for auth, timeouts, proxy/TLS trust, and RBAC/ABAC authorization. Covers locks, storage limits, firewall/private endpoints, manifest size limits, CMK errors, rate limiting strategies, soft delete recovery, and a robust support data checklist.

  https://learn.microsoft.com/en-us/troubleshoot/azure/azure-container-registry/troubleshoot-push-error-operation-disallowed-timeout

- **What is Azure Web Application Firewall on Application Gateway for Containers?**

  Expanded to clarify that enabling WAF requires both the Azure SecurityPolicy resource and the Kubernetes WebApplicationFirewallPolicy custom resource. Adds a detailed comparison of responsibilities, scoping behavior via targetRef across gateways, listeners, and routes, and examples to avoid misconfiguration. Provides verification steps with kubectl and log validation, plus refined notes in Limitations.

  https://learn.microsoft.com/en-us/azure/web-application-firewall/ag/waf-application-gateway-for-containers-overview
