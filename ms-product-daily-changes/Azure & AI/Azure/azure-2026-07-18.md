## New Articles

- **Deploy Azure Firewall in dual stack mode (preview)**

  Introduced preview support for Azure Firewall with IPv6 and dual stack (IPv4/IPv6), including deployment via PowerShell/CLI, IPv6 network rules, and DNS proxy. Clarified SNAT behavior for ULA ranges and listed preview limitations (no portal deployment, some regions unsupported, no application/DNAT rules or Threat Intel/IDPS/Explicit Proxy/IP Groups for IPv6, and no revert to IPv4-only). Provided step-by-step procedures to upgrade existing firewalls and to deploy new dual stack firewalls, covering VNet IPv6 configuration, AzureFirewallSubnet IPv6 prefix, IPv6 public IPs, and policy/rule setup.  

  https://learn.microsoft.com/en-us/azure/firewall/deploy-dual-stack-firewall

- **Modern mode for trusted service firewall bypass in Azure Data Factory**

  Announced a new Modern trusted service mode and retirement of Legacy trusted services in August 2027, with guidance to plan migrations. Explained which ADF scenarios are affected (SHIR, Azure-SSIS IR, REST linked service/Web activity to Storage/Key Vault) and how firewall bypass behavior changes. Recommended access patterns for Modern mode (IP allow-listing, Managed VNet with private endpoints, or customer-owned VNets) and advised validating changes in non-production first.  

  https://learn.microsoft.com/en-us/azure/data-factory/modern-trusted-service
