# Azure
**Date created:** 2026-07-26 UTC  
**Tags:** Administration, Automation, Security  

## Moderate Changes

- **Role assignments in Microsoft Discovery**

  Clarified permission requirements when networking resources are deployed in a different resource group than other Discovery resources. The guidance now calls out the Network Contributor and Microsoft Discovery Platform Administrator (Preview) roles on the virtual network’s resource group to avoid deployment failures of the supercomputer resource.

  https://learn.microsoft.com/en-us/azure/microsoft-discovery/concept-role-assignments

- **Manage directories and files in Azure Data Lake Storage by using Azure CLI**

  Updated guidance to explicitly assume hierarchical namespaces and Microsoft Entra authorization with --auth-mode login. Added verification commands after key steps and standardized examples to reduce errors and improve setup reliability.

  https://learn.microsoft.com/en-us/azure/storage/blobs/data-lake-storage-directory-file-acl-cli

- **Quickstart: Start developing with the Azure IoT Operations SDKs**

  Added steps to configure a device registry namespace, including a new DEVICE_REGISTRY_NAMESPACE variable with naming constraints. Updated deployment commands to include the -d parameter and added a step to create the Azure device registry namespace, ensuring deployments target the correct registry.

  https://learn.microsoft.com/en-us/azure/iot-operations/develop-edge-apps/quickstart-get-started-sdks

- **Quickstart: Deploy Microsoft Discovery infrastructure using Bicep**

  Clarified that resources deploy to a single resource group and detailed required permissions when networking resources reside in a separate group, including updating the Bicep template. Introduced guidance to enable the unified Workbench (preview) via tags and noted access requirements when networkIsolation is enabled. Also refined deployment guidance by removing a specific model version and moving NSP Perimeter Joiner role details into prerequisites for easier planning.

  https://learn.microsoft.com/en-us/azure/microsoft-discovery/quickstart-infrastructure-bicep

- **Quickstart: Get started with Microsoft Discovery Infrastructure**

  Expanded guidance for fully isolated deployments by disabling public network access and using private endpoints and NSP. Added a permission note for cross–resource-group networking scenarios and reinforced network isolation steps during workspace creation with links to detailed configuration guidance.

  https://learn.microsoft.com/en-us/azure/microsoft-discovery/quickstart-infrastructure-portal
