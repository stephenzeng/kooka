## New Articles

- **Migrate on-premises SMB file shares to Azure Files using the agentless migration capability in Storage Mover**

  Introduced a preview how-to for migrating on-premises SMB file shares to Azure Files without agents using Azure Storage Mover. Covers prerequisites (private connectivity, Key Vault-stored credentials), preview limits and supported SMB versions, and RBAC requirements. Provides end-to-end steps to create endpoints, configure projects and jobs, choose copy modes, run and monitor jobs, and perform cutover with validation. Includes troubleshooting for permissions, networking (TCP 445), and path validation, with links to related guidance.

  https://learn.microsoft.com/en-us/azure/storage-mover/agentless-on-premises-files-migration

- **Register Azure Migrate appliance by onboarding it to Azure Arc**

  Added an alternative registration method using the Azure Arc agent with managed identity, reducing dependency on tenant-level permissions and certificate handling. Details supported scenarios and limitations, required endpoints, and step-by-step setup for installing the agent, assigning roles, and enabling managed identity via registry. Includes guidance for resource organization, scale-out appliances, and next steps to start discovery.

  https://learn.microsoft.com/en-us/azure/migrate/how-to-register-appliance-using-arc-agent?view=migrate

- **Migrate data from Oracle Cloud Infrastructure to Azure Blob Storage with Azure Storage Mover**

  Published an end-to-end how-to for migrating S3-compatible OCI Object Storage data to Azure Blob using Storage Mover. Explains prerequisites, limits, and how to generate OCI customer secret keys and construct S3-compatible endpoints, with credentials stored in Key Vault. Walks through creating OCI source and Blob target endpoints, assigning RBAC, configuring projects and jobs (including private connections), running and monitoring jobs, and validating results. Provides troubleshooting for common issues.

  https://learn.microsoft.com/en-us/azure/storage-mover/oracle-cloud-azure-blob

## Moderate Changes

- **Azure Accelerated Networking overview**

  Updated the supported Linux distributions table by adding SUSE Linux Enterprise Server 15 SP5 and correcting Rocky Linux from 9.7 to 9.6, keeping kernel details consistent. This ensures accurate compatibility planning and avoids deployment issues caused by mismatched versions.

  https://learn.microsoft.com/en-us/azure/virtual-network/accelerated-networking-overview

- **Private Application Gateway deployment**

  Added an IMPORTANT note that a BGP-learned default route (0.0.0.0/0) can force tunneling and break management-plane connectivity on v2 gateways, leading to provisioning failures. Provides remediation to add a UDR for 0.0.0.0/0 with next hop Internet on the gateway subnet or stop advertising the default route, with a link to troubleshooting guidance.

  https://learn.microsoft.com/en-us/azure/application-gateway/application-gateway-private-deployment

- **Storage hierarchy of Azure NetApp Files**

  Introduced a “Storage endpoints” section explaining automatic endpoint creation in delegated subnets and the resulting provisioning delays. Offers planning guidance to trigger endpoint creation ahead of time (for predictable deployments) and to design automation to accommodate endpoint creation for scale scenarios.

  https://learn.microsoft.com/en-us/azure/azure-netapp-files/azure-netapp-files-understand-storage-hierarchy

- **Azure network round-trip latency statistics**
