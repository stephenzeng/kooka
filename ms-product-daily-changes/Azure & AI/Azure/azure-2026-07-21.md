# Azure
**Date created:** 2026-07-21 UTC  
**Tags:** Administration, Agent, Governance, Other, Programming, Security  

## New Articles

- **Authenticate and connect clients**
  
  Introduced guidance for authenticating Azure Web PubSub Chat clients using either portal-generated client access URLs for quick tests or server-issued tokens for production. Provides Node.js/Express examples for a negotiate endpoint with connection string and managed identity options, including role assignment. Explains setting user IDs securely, token refresh via callbacks, and token lifetime defaults with customization, with links to room management next steps.
  
  https://learn.microsoft.com/en-us/azure/azure-web-pubsub/chat-howto-authenticate

- **Configure storage and enable Azure Web PubSub chat**
  
  Added step-by-step instructions to link an Azure Storage account to a Web PubSub resource using managed identity and enable the Chat feature on a hub. Details required permissions (Contributor) and how to configure a Chat hub to use the linked storage. Clarifies what data is stored (messages, rooms, users, roles/permissions) and that it remains in the customer’s storage, with a quickstart for follow-up.
  
  https://learn.microsoft.com/en-us/azure/azure-web-pubsub/chat-howto-enable-chat

- **Create and manage rooms**
  
  Introduced room management for Azure Web PubSub Chat, including creating rooms with titles and optional members and automatic operator assignment. Explains adding or removing members with proper permissions and how clients receive join/leave events. Covers server-side administration through Chat REST APIs to create, retrieve, delete rooms, and manage membership.
  
  https://learn.microsoft.com/en-us/azure/azure-web-pubsub/chat-howto-manage-rooms

- **Send and read messages**
  
  Added guidance for subscribing to real-time events, sending messages with size limits, and reading message history with pagination and range queries. Explains server-side workflows for reading, editing, and deleting messages via REST APIs using conversation IDs. Links to SDKs and REST references to help implement reliable messaging patterns.
  
  https://learn.microsoft.com/en-us/azure/azure-web-pubsub/chat-howto-messages

- **Configure roles and permissions**
  
  Introduced role- and permission-based access control for Azure Web PubSub Chat via the REST API. Documents user and room permission scopes and built-in roles (user.normal, room.member, room.operator) with guidance for creating custom roles using required prefixes. Notes that client SDKs don’t manage roles directly and points to the REST reference for administration.
  
  https://learn.microsoft.com/en-us/azure/azure-web-pubsub/chat-howto-roles-permissions

- **Azure Web PubSub chat quickstart**
  
  Provided a quickstart to connect to a chat hub, create a room, send messages, and read history using the @azure/web-pubsub-chat-client SDK. Walks through generating a client access URL in the portal and building a Node.js sample. Recommends server-issued tokens for production scenarios.
  
  https://learn.microsoft.com/en-us/azure/azure-web-pubsub/chat-quickstart

- **Azure Web PubSub chat error codes**
  
  Added a reference for error handling, explaining how codes appear in client SDKs and REST responses. Categorizes common errors across general, user, room, conversation, and message domains to speed diagnosis. Includes pointers to SDKs and REST documentation for remediation paths.
  
  https://learn.microsoft.com/en-us/azure/azure-web-pubsub/chat-reference-errors

- **Azure Web PubSub chat SDKs and REST API**
  
  Introduced development options with the JavaScript Chat Client SDK and server-side REST APIs. Summarizes capabilities such as connecting, room management, messaging, and event handling, with code examples and authentication options (keys or Microsoft Entra ID). Links to API specs, samples, and related error references for end-to-end implementation.
  
  https://learn.microsoft.com/en-us/azure/azure-web-pubsub/chat-reference-sdk-and-rest

## Major Changes

- **Connect to IBM MQ servers from workflows in Azure Logic Apps**
  
  Announced deprecation of the MQ managed connector, which will be unavailable starting August 2026. Encourages migration to the MQ built-in connector in Logic Apps Standard, which offers improved capabilities. Teams should plan and execute migrations ahead of the retirement to avoid disruption and benefit from the enhanced feature set.
  
  https://learn.microsoft.com/en-us/azure/connectors/connectors-create-api-mq

- **Azure Private Endpoint private DNS zone values**
  
  Updated Private Link DNS guidance to correct the Azure Cosmos DB resource provider name and expand supported services, including new DNS zones for Power BI, AKS Kubernetes API, and API Management Gateway in US Gov. Clarified that the Azure Web Apps entry also applies to Azure Functions. These changes help ensure accurate DNS zone configuration across clouds and services.
  
  https://learn.microsoft.com/en-us/azure/private-link/private-endpoint-dns

## Moderate Changes

- **Azure Web PubSub chat overview**
  
  Standardized terminology from “chat hub” to “chat” and added sections on reliability and role-based permissions. Highlighted message ordering, persistence, history loading, and provided clearer guidance for rooms and messaging, plus a cleaned-up Next steps list.
  
  https://learn.microsoft.com/en-us/azure/azure-web-pubsub/chat-overview

- **Manage registered servers with Azure File Sync**
  
  Strengthened registration prerequisites, proxy configuration steps, and PowerShell guidance, including keeping the Az module current. Added a troubleshooting step for registration failures using ARM_CLOUD_METADATA_URL and clarified cluster behavior, tiered data recall, and unregistering servers with warnings for destructive actions.
  
  https://learn.microsoft.com/en-us/azure/storage/file-sync/file-sync-server-registration

- **Enable secure settings in Azure IoT Operations**
  
  Simplified prerequisites by using a shared Azure CLI include and removing the requirement to install the azure-iot-ops CLI extension. The connectedk8s extension prerequisite remains unchanged to ensure cluster connectivity.
  
  https://learn.microsoft.com/en-us/azure/iot-operations/secure-iot-ops/howto-enable-secure-settings

- **Prepare your Azure Arc-enabled Kubernetes cluster**
  
  Added a shared include for Azure CLI prerequisites for connected Kubernetes across general and TKG workload scenarios. This streamlines preparation steps for connecting clusters to Azure Arc.
  
  https://learn.microsoft.com/en-us/azure/iot-operations/deploy-iot-ops/howto-prepare-cluster

- **MCP connectors and tools in Azure SRE Agent**
  
  Expanded Streamable-HTTP connector guidance to support OAuth sign-in alongside Bearer tokens and custom headers. Documented authorization code flow with PKCE, dynamic registration, automatic token refresh, and the requirement for a public HTTPS endpoint for OAuth-enabled servers.
  
  https://learn.microsoft.com/en-us/azure/sre-agent/mcp-connectors

- **Support matrix for VMware discovery**
  
  Increased the agentless dependency analysis scale from 1,000 to 3,000 servers per appliance across multiple vCenter Servers. This expands coverage for larger environments and reduces the number of appliances required.
  
  https://learn.microsoft.com/en-us/azure/migrate/migrate-support-matrix-vmware?view=migrate

- **Data flows vs. data flow graphs in Azure IoT Operations**
  
  Updated the comparison to remove OpenTelemetry as a supported source endpoint for data flows, clarifying that MQTT and Kafka are the supported options. This removes ambiguity when selecting source protocols.
  
  https://learn.microsoft.com/en-us/azure/iot-operations/connect-to-cloud/overview-dataflow-comparison

- **Azure Container Apps Sandboxes overview (preview)**
  
  Expanded scale guidance (scale-to-zero without CPU/memory fees when stopped and scale-out to thousands), added lifecycle controls for networking, clarified OCI image options, and introduced an XL tier. Simplified lifecycle states to Running and Stopped with Suspend Mode options, and defined auto-delete timing, with enhanced networking controls and VNet integration.
  
  https://learn.microsoft.com/en-us/azure/container-apps/sandboxes-overview

- **Overview of simplified experience for Azure Migrate (agent-based migration of VMware or physical servers)**
  
  Clarified retirement milestones for the classic experience: replication support ends 31 May 2026 and full retirement is 30 September 2026, after which portal operations are unavailable. Directs users to the modernized agent-based appliance for new or modified replications and to plan final migrations ahead of retirement.
  
  https://learn.microsoft.com/en-us/azure/migrate/simplified-experience-for-azure-migrate?view=migrate

- **Troubleshoot SNAT port exhaustion on Azure Kubernetes Service nodes**
  
  Updated steps to use kubectl node-shell to connect to nodes instead of SSH and clarified using tcptracer after connecting. This simplifies access and aligns with recommended troubleshooting practices.
  
  https://learn.microsoft.com/en-us/troubleshoot/azure/azure-kubernetes/connectivity/snat-port-exhaustion

- **Azure File Share Soft Delete**
  
  Clarified how soft delete works for file shares and updated the “Enable soft delete” guidance. Corrected and improved Azure CLI examples with long-form parameters, multi-line formatting, and proper restore command usage and variables, with minor portal clarifications.
  
  https://learn.microsoft.com/en-us/azure/storage/files/storage-files-prevent-file-share-deletion
