## New Articles

- **Access Event Hubs from a VM using a managed identity**

  Introduced a step-by-step guide to enable a system-assigned managed identity on an Azure VM and grant Event Hubs Data Sender role at the event hub scope.   https://learn.microsoft.com/en-us/azure/event-hubs/authenticate-managed-identity-virtual-machine

  Added portal-based instructions to enable disaster recovery or change the recovery region for an existing namespace. Explains paired vs. flexible recovery region options, what state is replicated (namespace metadata) and what isn’t (registrations), and how Microsoft-managed failover works. Provides verification steps, key considerations by region/platform, and links to reliability best practices.

  https://learn.microsoft.com/en-us/azure/notification-hubs/enable-disaster-recovery-existing-namespace

- **Azure Files management concepts**

  Introduced a comparison of classic Microsoft.Storage file shares and top-level Microsoft.FileShares, explaining architecture, limits, and benefits of each. Highlights how Microsoft.FileShares simplifies management with independent capacity/performance, per-share networking/security, and provisioned v2 billing. Includes regional availability, a feature comparison table, and guidance on when to use SMB vs. NFS across models, with links to planning and creation guides.

  https://learn.microsoft.com/en-us/azure/storage/files/files-management-concepts

  https://learn.microsoft.com/en-us/azure/azure-vmware/license-included-service-retirement
