- **Troubleshoot backend health issues in Application Gateway**

  Clarified HTTPS backend hostname and SNI behavior: avoid IPs for probe or backend hostnames, and use FQDNs that match certificate CN/SAN. Added v2 options to configure backend HTTPS validation (including explicit SNI or skipping subject validation) and hostName overrides, and contrasted with v1 behavior. This helps prevent TLS validation failures and misrouted SNI.

  https://learn.microsoft.com/en-us/troubleshoot/azure/application-gateway/application-gateway-backend-health-troubleshooting

- **Troubleshoot bad gateway (502) errors in Azure Application Gateway**

  Updated probe host handling across SKUs: v1 uses the Host value only for headers while v2 uses it for both headers and SNI. These clarifications reduce 502s caused by TLS and probe misconfiguration.
