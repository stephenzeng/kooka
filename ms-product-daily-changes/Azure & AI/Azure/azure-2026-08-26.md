## New Articles

- **Blob inventory FAQ**

  Introduced a new FAQ explaining inventory run cadence and timing variability. Announced a shift to multiple result files per run for better performance on large accounts, with the manifest listing all outputs. Explained customer impact (faster runs) and the need to update processing logic if previously assuming a single file, plus options to request a temporary revert and provide feedback.

  https://learn.microsoft.com/en-us/azure/storage/blobs/storage-blob-faq#multiple-inventory-file-output

- **Quickstart: Configure a standard service endpoint - Terraform**

  Added a Terraform quickstart for configuring a standard service endpoint for Azure Storage. The guide includes prerequisites, example Terraform files (using azapi for subnet networkIdentifier), and commands to deploy and verify NSP associations and access rules. It highlights Learning mode vs Enforcement, cleanup, and troubleshooting to speed up secure, repeatable network setup.

  https://learn.microsoft.com/en-us/azure/private-link/configure-service-endpoint-standard-terraform

- **Evaluate Azure SRE Agent**

  Launched a 30-day evaluation trial that waives always-on charges for eligible new customers (consumption still applies). The article explains limits (up to three agents, per-agent 30 days), how billing resumes after the trial, and how to get started by connecting code, telemetry, knowledge, and optional VNet access. It also outlines practical evaluation scenarios such as investigations, workflow automation, proactive checks, and integrations.

  https://learn.microsoft.com/en-us/azure/sre-agent/evaluate

- **Lifecycle management policy FAQ**

  Published an FAQ covering activation delays, background execution, and behavior after policy edits (including continued auto-tiering if last access tracking is enabled). It clarifies reasons capacity may not change (soft delete/versioning), how to avoid re-archiving recently rehydrated blobs, and exact prefix-matching rules. The guidance helps admins predict outcomes and troubleshoot runs using logs.

  https://learn.microsoft.com/en-us/azure/storage/blobs/lifecycle-management-policy-faq

- **Live Reports in Azure SRE Agent (preview)**

  Introduced Live Reports that fetch and refresh data via connectors, optionally with model-assisted analysis. The article walks through creating, refreshing, sharing, exporting, and versioning reports, and explains cost behavior for active flows. It also details running actions from reports with policy and approval controls, plus preview limitations and troubleshooting tips.

  https://learn.microsoft.com/en-us/azure/sre-agent/live-reports

- **Metrics and logs FAQ**

  Added an FAQ clarifying where to find disk metrics (Azure Compute), how to interpret dashed lines in Azure Metrics (nulls), and how to track availability via Azure Resource Health alerts. It also explains the hourly nature of blob capacity/count metrics generated by a background process. This helps teams choose the right telemetry and avoid misinterpreting charts.

  https://learn.microsoft.com/en-us/azure/storage/blobs/monitor-blob-storage-faq

- **Quickstart: Create your first Azure Container Apps sandbox using the portal (preview)**

  Published a portal quickstart for Container Apps Sandboxes to create a sandbox group and launch a sandbox session. It shows how to pick an image, open a browser terminal, run basic commands, and clean up. The guide accelerates hands-on experimentation with minimal setup.

  https://learn.microsoft.com/en-us/azure/container-apps/sandboxes-quickstart-portal

- **Static website hosting FAQ**

  Released an FAQ covering static website endpoints, firewall compatibility, and the lack of Microsoft Entra ID for $web (anonymous read only). It explains how to set custom domains and certificates via Azure CDN, add headers/rules, and resolve common 404s and root redirect issues. This helps streamline secure, reliable static hosting.

  https://learn.microsoft.com/en-us/azure/storage/blobs/static-website-hosting-faq
