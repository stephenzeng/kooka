## New Articles

- **Leapp upgrade from RHEL 9.x to RHEL 10.x on SAP-HANA and SAP-APPS pay-as-you-go VMs**

  New end-to-end guidance for in-place Leapp upgrades from RHEL 9.6 to 10.0 on SAP-HANA and SAP-APPS PAYG images. Covers prerequisites, RHUI vs. RHSM considerations, release pinning, stopping SAP processes, and SELinux/Serial Console usage. Provides separate, step-by-step procedures for SAP-HANA (E4S) and SAP-APPS (EUS), including inhibitor resolution and optional auto-reboot. Adds post-upgrade verification and cleanup steps, plus notes on Azure control plane feature availability and HA cluster considerations.

  https://learn.microsoft.com/en-us/troubleshoot/azure/virtual-machines/linux/leapp-upgrade-rhel-9dotx-to-10dotx-saphana-sapapps

- **Azure landing zones for on-premises experts**

  New conceptual guidance to help platform and central IT teams prepare Azure platform landing zones for migrations from on-premises. Details minimum viable platform components, management group and policy design, subscription vending, and hub-and-spoke vs. Virtual WAN choices. Provides network, identity, security, logging/monitoring considerations and a comprehensive readiness validation checklist aligned to Cloud Adoption Framework design areas.

  https://learn.microsoft.com/en-us/azure/migration/migrate-from-on-premises-platform-landing-zone

- **AI agent shared responsibility model - Microsoft Azure**

  New responsibility model tailored to AI agents, explaining agent-specific layers (orchestration, tools/actions, memory/state) and how they differ from standard cloud and LLM scenarios. Clarifies shared responsibilities across SaaS, PaaS, and IaaS, including guardrails, permissions, sandboxing, memory isolation, and auditability. Highlights top agent risks such as prompt injection to actions, excessive agency, and memory poisoning, with mitigation guidance and deployment recommendations.

  https://learn.microsoft.com/en-us/azure/security/fundamentals/shared-responsibility-ai-agent

## Major Changes

- **Upgrade RHEL pay-as-you-go virtual machines using Leapp**

  Expanded the Leapp upgrade guidance to include RHEL 9-to-10 paths for PAYG VMs and refined supported target versions across RHEL 7, 8, and 9. Strengthened preparation steps (release pinning, clearing version locks, network and NSS DB updates) and clarified when to adjust SELinux context and file descriptor limits. Greatly enhanced post-upgrade cleanup and verification, including kernel handling, repository hygiene, and restoring SELinux enforcing mode. Adds cautions and Serial Console usage to reduce upgrade failures and reflect RHUI/PAYG constraints, including SAP exceptions.

  https://learn.microsoft.com/en-us/troubleshoot/azure/virtual-machines/linux/leapp-upgrade-process-rhel-7-and-8

- **Enable Microsoft Entra Kerberos authentication for hybrid and cloud-only identities on Azure Files**

  Updated regional availability to state that Microsoft Entra Kerberos now supports hybrid and cloud-only identities in all regions across Azure Public, Azure US Gov, and Azure China 21Vianet. Removes prior limitations and region lists, simplifying planning and deployment decisions for identity-based SMB access.

  https://learn.microsoft.com/en-us/azure/storage/files/storage-files-identity-auth-hybrid-identities-enable

- **Troubleshoot an app in Azure App Service using Visual Studio**

  Comprehensive rewrite of the Visual Studio troubleshooting guide for Azure App Service. Adds clearer prerequisites, modernized instructions for managing resources via Server Explorer, and improved flows for remote file access and remote debugging (including WebJobs). Significantly expands diagnostics and logging coverage, including application tracing, streaming logs, web server and detailed error logs, failed request tracing, and storage-based logging options. The reorganization improves discoverability, standardizes terminology, and provides actionable, step-by-step procedures with updated images.

  https://learn.microsoft.com/en-us/troubleshoot/azure/app-service/troubleshoot-dotnet-visual-studio
