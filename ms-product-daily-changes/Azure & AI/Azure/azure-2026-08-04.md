## New Articles

- **Troubleshoot slow web app performance in Azure App Service**

  Introduced a comprehensive guide for diagnosing and fixing slow performance in Azure App Service (Windows). Covers platform checks and eight common cause areas, including code inefficiencies, high CPU/memory, database latency, external dependency delays, SNAT port exhaustion, cold starts, and disk space issues. Provides actionable diagnostics and remediation with CLI, KQL, C#, XML, and SQL examples, plus links to related guidance.

  https://learn.microsoft.com/en-us/troubleshoot/azure/app-service/troubleshoot-performance-slow-web-app

## Major Changes

- **Capture real-time system insights from an AKS cluster**

  Added a new recommended installation path using the AKS cluster extension to deploy Inspektor Gadget, including preview notes, prerequisites, and az k8s-extension commands. Documented how to verify provisioning, understand auto-upgrade, configure post-install options, and remove the extension. Retained the kubectl gadget plug-in as an alternative method.

  https://learn.microsoft.com/en-us/troubleshoot/azure/azure-kubernetes/logs/capture-system-insights-from-aks

- **Edit app and host settings for Standard logic apps in single-tenant Azure Logic Apps**

  Updated settings for stopping and deleting workflows to new keys that end with “Prefix,” replaced prior keys, and required uppercase alphabetical characters in values. Revised JSON examples to reflect new key names and value format (colon after each workflow ID and semicolon separators) and corrected the run-cancellation example.

  https://learn.microsoft.com/en-us/azure/logic-apps/edit-app-settings-host-settings

- **Troubleshoot memory saturation in AKS clusters**

  Introduced improved kubectl workflows to list pods by node and analyze memory pressure. Added guidance to distinguish OOMKilled from exit code 137 and to diagnose steady versus growing memory usage. Expanded best practices for right-sizing requests/limits, QoS and priority, scaling (HPA/VPA/KEDA), and workload isolation with dedicated node pools and scheduling controls.

  https://learn.microsoft.com/en-us/troubleshoot/azure/azure-kubernetes/availability-performance/identify-memory-saturation-aks

- **Troubleshoot Azure DNS**

  Significantly expanded troubleshooting coverage across Azure DNS offerings, Private DNS, Private Resolver, forwarding rulesets, and policy-based resolution. Added resolution priority flow and diagram, detailed tools and methodology, and steps to diagnose NSG/Azure Firewall/NVA blocking of UDP/TCP 53. Included new guidance on Private DNS zone groups, limits, and validation with Azure CLI/PowerShell, plus refined procedures for records and delegation checks.

  https://learn.microsoft.com/en-us/troubleshoot/azure/dns/troubleshoot-dns

- **Support matrix for VMware/physical disaster recovery in Azure Site Recovery**

  Removed legacy Windows Server versions from the supported OS list and aligned UEFI boot notes accordingly. This clarifies current support boundaries and eliminates references to deprecated OS versions.

  https://learn.microsoft.com/en-us/azure/site-recovery/vmware-physical-azure-support-matrix
