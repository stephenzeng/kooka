## New Articles

- **Retry resource deployments in Bicep (retryOn)**

  Introduced the @retryOn decorator to automatically retry resource deployments on specified error codes, reducing transient failure impact. The article explains syntax and parameters, including errorCodes and optional retryCount (default 30, capped at 30). It includes examples such as retrying storage account creation and clarifies how retries work with loops and batchSize.

  https://learn.microsoft.com/en-us/azure/azure-resource-manager/bicep/bicep-retryon

- **Configure a perimeter link between network security perimeters**

  Added a step-by-step guide to create and manage perimeter links (cross-perimeter connections) in preview, including prerequisites and feature registration via portal, CLI, and PowerShell. It explains automatic inbound/outbound rule creation, validation scenarios across supported PaaS services, monitoring/diagnostics, troubleshooting, and safe removal. CLI guidance now also advises refreshing the Microsoft.Network provider registration and listing link references before deletion to prevent errors.

  https://learn.microsoft.com/en-us/azure/private-link/configure-perimeter-link

- **Troubleshoot Azure IMDS Certificate Chain Failures**

  Introduced a comprehensive Linux-focused guide to diagnose and fix Azure IMDS attestation certificate chain issues. It explains certificate architecture, Linux trust store behaviors, and how to validate chains, identify OCSP intermediates, and test AIA/CRL/OCSP connectivity. The article provides distro-specific remediation steps to install required certificates and addresses clock skew, expired intermediates, and proxy/firewall constraints.

  https://learn.microsoft.com/en-us/troubleshoot/azure/virtual-machines/linux/linux-vm-imds-certissues

- **Azure VM Instance Metadata Service Verification Tool for Linux**

  Added guidance for using the IMDS Verification Tool on Linux to automatically diagnose reachability, attestation, chain validation, trust store inventory, and endpoint connectivity. It outlines diagnostic phases, supported distributions, and how to run the tool via Azure CLI or locally with optional AutoFix. The article also explains interpreting results and converting/installing certificates where needed.

  https://learn.microsoft.com/en-us/troubleshoot/azure/virtual-machines/linux/linux-vm-imds-tool

- **Perimeter link feature in Network Security Perimeter (Preview)**

  Introduces the perimeter link concept that securely connects resources across different NSPs and automates access rule handling. It details architecture, trust relationships, benefits, supported PaaS services during preview, and managed identity requirements. The article explains behavior on link removal, limitations (for example, link counts and cross-subscription permissions), and how this improves secure connectivity.

  https://learn.microsoft.com/en-us/azure/private-link/perimeter-links-overview

- **Collect esxtop performance data using Run Command**

  Provides a how-to for collecting ESXi host performance data in Azure VMware Solution using the Get-EsxtopData Run Command. It documents parameters, execution steps in the portal, and CSV output schema for analysis. Best practices and safety limits help ensure reliable sampling and storage selection.

  https://learn.microsoft.com/en-us/azure/azure-vmware/run-command-esxtop

- **Troubleshoot hybrid DNS resolution failures with Azure DNS Private Resolver**

  Adds a structured troubleshooting guide to resolve inbound and outbound hybrid DNS resolution issues. It highlights root causes such as incorrect on-premises forwarding targets, missing or misapplied outbound rulesets, upstream resolvers returning referrals, and MTU-related response drops. The article includes diagnostic commands, a decision map, and targeted resolutions to restore end-to-end recursion.

  https://learn.microsoft.com/en-us/troubleshoot/azure/dns/troubleshoot-azure-dns-private-resolver-hybrid-resolution-failure

- **Troubleshoot Azure Bastion connection failures**

  Introduces a diagnostic flow for Bastion connectivity failures due to blocked ports and NSG/firewall rules. It covers subnet and NSG validation, VM-side RDP/SSH allowances, handling custom ports, and client-side HTTPS/TLS reachability to Bastion. Resolution sections guide fixes for missing Bastion subnet rules, VM access rules, custom port enablement, and corporate perimeter TLS interception issues.

  https://learn.microsoft.com/en-us/troubleshoot/azure/bastion/troubleshoot-connection-blocked-ports

- **Troubleshoot Azure VM disk resize errors**

  Provides a detailed guide to diagnose and fix disk resize failures with clear mappings from error codes to causes and actions. It explains live-resize prerequisites and restrictions and offers CLI/PowerShell steps for deallocation/offline resize and safe detachment for data disks. Guidance helps avoid downtime and aligns procedures with VM SKU capabilities and shared disk limitations.

  https://learn.microsoft.com/en-us/troubleshoot/azure/virtual-machines/windows/troubleshoot-disk-resize-errors

- **Start here for troubleshooting Azure VM disk resize issues**

  Adds a landing page that routes platform-level disk resize errors and guest OS volume extension issues to the right articles. It maps common symptoms and error codes to resolutions and notes constraints like unsupported downsizing and partitioning limits (Windows and Linux). This structure reduces time to resolution by directing users to tailored guidance.

  https://learn.microsoft.com/en-us/troubleshoot/azure/virtual-machines/windows/troubleshoot-disk-resize-overview

- **Troubleshoot live resize failure for Azure VM managed disks**

  Introduces targeted troubleshooting for LiveResizeStorageClientFailure during live disk resize. It explains likely causes and provides retry guidance, detachment workflows for data disks, and deallocation procedures for OS disks with validation steps. Scripted examples accelerate consistent remediation.

  https://learn.microsoft.com/en-us/troubleshoot/azure/virtual-machines/windows/troubleshoot-live-resize-failure

- **Troubleshoot Azure private DNS zone deletion failure**

  Adds a comprehensive playbook for resolving zone deletion/migration failures. It covers diagnosing hidden virtual network links, resource locks, record-set quota limits, and portal/control-plane convergence. The guide includes exact CLI and REST steps to remove orphaned links, adjust locks, plan quota usage, and verify successful operations.

  https://learn.microsoft.com/en-us/troubleshoot/azure/dns/troubleshoot-private-dns-zone-deletion-migration-failure

- **Troubleshoot Run Command in Azure VMware Solution**

  Explains how to view and troubleshoot Run Command executions in Azure VMware Solution. It details status views, result tabs (Details, Output, Error, Warning, Information), and methods to cancel or delete jobs. Linked next steps guide users to related administrative tasks.

  https://learn.microsoft.com/en-us/azure/azure-vmware/troubleshoot-run-command
