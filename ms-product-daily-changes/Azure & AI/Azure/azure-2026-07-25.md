## New Articles

- **Manage IoT Devices and Assets as Azure Resources**

  Introduced Azure Device Registry as a unified control plane to model IoT devices and assets as Azure Resource Manager resources. Explains namespaces, device/asset representations, schema registries for Azure IoT Operations, and certificate management for IoT Hub devices (preview). Highlights governance benefits such as RBAC, Azure Policy, tags, and Resource Graph, and clarifies GA vs. preview coverage across IoT offerings.

  https://learn.microsoft.com/en-us/azure/iot/iot-device-registry-overview

- **Linter rule - secure params in parameters file**

  Added a new Bicep linter rule that detects when non-secure parameters in .bicepparam files receive values from secure parameters, which could expose secrets in deployment history. Details configuration, scope (direct, interpolated, and transitive references), and fixes—mark the receiving parameter as secure or avoid passing secure values. Includes compliant and non-compliant examples to guide remediation.

  https://learn.microsoft.com/en-us/azure/azure-resource-manager/bicep/linter-rule-secure-params-in-parameters-file
