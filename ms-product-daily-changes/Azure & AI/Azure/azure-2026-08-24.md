## Moderate Changes

- **Migrate C# apps from the in-process model to the isolated worker model**

  Updated migration guidance to switch from synchronous to asynchronous HTTP request/response stream I/O when using ASP.NET Core integration in the isolated worker model. Replace synchronous calls (e.g., ReadToEnd, Write/WriteString, Flush) with async equivalents, mark functions async, and return Task<T> (e.g., Task<IActionResult>). Explains that ASP.NET Core disables synchronous I/O by default to avoid thread pool starvation; a compatibility option (AllowSynchronousIO) is noted along with JSON serialization guidance.
