# Azure
**Date created:** 2026-08-09 UTC  
**Tags:** Administration, Monitoring, Security  

## New Articles

- **Get operation correlation ID from Activity Log**

  Introduced a how-to guide for Microsoft Discovery on retrieving the operation Correlation ID from the Azure Activity Log. The article outlines prerequisites and step-by-step filters to find a log entry, then shows how to switch to JSON view to locate the Correlation ID. It explains how to include this ID in Azure support requests to speed investigation and resolution. The guide includes screenshots and a link to create a support request.

  https://learn.microsoft.com/en-us/azure/microsoft-discovery/how-to-get-correlation-id

## Moderate Changes

- **Deploy an update by using Azure Device Update for IoT Hub**

  Updated retirement dates for Device Update data plane API migrations: preview APIs move to February 28, 2027, and API version 2022-10-01 moves to August 31, 2029. This helps teams plan upgrade timelines and avoid service disruptions.

  https://learn.microsoft.com/en-us/azure/iot-hub-device-update/deploy-update

- **Understand download security (TLS) for Device Update for IoT Hub**

  Updated retirement dates for Device Update data plane APIs and added guidance for constrained or embedded devices to ensure the device trust store includes the required root CAs. Noted that FreeRTOS samples don’t include these roots by default, causing HTTPS downloads to fail until added; removed duplicate preparatory checklist content. These changes help ensure reliable, secure content delivery and smoother migrations.

  https://learn.microsoft.com/en-us/azure/iot-hub-device-update/device-update-tls-download

- **Enforce content safety checks on LLM requests**

  Clarified that the window-size attribute is configurable only for responses, with prompts always evaluated using a 10,000-character window; updated the default response window to 1,000 characters. This change refines how much response content is evaluated by default and guides admins to adjust policies to meet safety and performance needs.

  https://learn.microsoft.com/en-us/azure/api-management/llm-content-safety-policy

- **Azure Cloud Shell release notes**

  Added an August 2026 entry noting removal of the classic Cloud Shell UI across all regions on August 7, 2026. Also documented a July 2026 preview in Azure Data Manager for Energy enabling point-in-time restore of a single Seismic dataset via a restore API with asynchronous tracking and availability by request. These updates prompt admins to prepare for the UI retirement while enabling energy teams to pilot granular dataset recovery.

  https://learn.microsoft.com/en-us/azure/cloud-shell/release-notes

- **Troubleshooting guide for Azure Service Bus | Microsoft Docs**

  Added guidance for namespaces using private endpoints with public access disabled, including verifying DNS resolution to the private IP from within the virtual network. Highlighted that port checks may still reach the public endpoint, indicating DNS issues, and linked to private endpoint connectivity troubleshooting to expedite resolution.

  https://learn.microsoft.com/en-us/azure/service-bus-messaging/service-bus-troubleshooting-guide
