# Azure
**Date created:** 2026-07-12 UTC  
**Tags:** Administration, Automation, Governance  

## Moderate Changes

- **Create a Cluster**

  Updated the autoscaling parameter to a generalized “Autoscaling limit,” clarifying that caps can be set by cores or nodes depending on the template and node type (for example, Max Cores, Max HPC Cores, or Max Nodes). This improves configuration accuracy and helps prevent capacity misconfiguration across different cluster templates.

  https://learn.microsoft.com/en-us/azure/cyclecloud/how-to/create-cluster?view=cyclecloud-8

- **Deploy Azure File Sync**

  Rewrote remote access guidance for environments where port 445 is blocked, recommending SMB over QUIC on Windows Server Datacenter: Azure Edition to reach server endpoints without VPN or ExpressRoute. This streamlines deployment and directs readers to the networking overview for setup details.

  https://learn.microsoft.com/en-us/azure/storage/file-sync/file-sync-deployment-guide

- **Networking considerations for Azure File Sync**

  Added an SMB over QUIC section explaining the port 443 alternative to VPN/ExpressRoute when port 445 is blocked, including prerequisites and links to setup guidance. This gives administrators a simpler, more secure path for remote access planning.

  https://learn.microsoft.com/en-us/azure/storage/file-sync/file-sync-networking-overview

- **Geo-replication in Azure Event Hubs**

  Overhauled the Private endpoints guidance to clarify client failover behavior, recommend retry policies, and emphasize that private endpoints are regional. Provided detailed DNS recommendations, including using one privatelink.servicebus.windows.net private DNS zone per region, considerations for shared zones and on-premises resolution, and outlined application-only, namespace-only, and regional outage scenarios. Removed outdated instructions to manually switch DNS, aligning guidance with resilient, multi-region deployments.

  https://learn.microsoft.com/en-us/azure/event-hubs/geo-replication

- **Transfer Azure product billing ownership to your Microsoft Partner Agreement (MPA)**

  Clarified eligibility by defining two partner groups (CSP authorized direct-bill partners with Azure Solutions Partner designation or Azure Expert MSP, and CSP authorized distributors with Frontier Distributor designation). Added a new requirement to work with a Partner Technical Consultant via Technical Presales and Deployment benefits to gain tool access, helping partners understand how to qualify and proceed.

  https://learn.microsoft.com/en-us/azure/cost-management-billing/manage/mpa-request-ownership
