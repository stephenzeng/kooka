## New Articles

- **Diagnose and solve problems in Azure Container Apps**

  Introduced a new troubleshooting experience that aggregates detectors across deployment, networking, scaling, configuration, and environment categories to speed diagnosis. Shows how to launch app- and environment‑level detectors and interpret results for common issues like image pull failures, probe errors, SNAT limits, and autoscaling anomalies. Provides best practices and links to deeper guidance so teams can move from symptom to fix faster.

  https://learn.microsoft.com/en-us/azure/container-apps/diagnose-solve

- **Traffic Manager Linked Records overview**

  Introduced Traffic Manager Linked Records (preview) that directly link DNS records to Traffic Manager profiles to return endpoint IPs/FQDNs without a CNAME hop. Explains benefits such as DNSSEC compatibility, apex domain support, TTL inheritance, and stricter endpoint-type enforcement via Strictly Typed Profiles. Compares linked records with alias records and outlines supported record types, limits, and deletion behavior.

  https://learn.microsoft.com/en-us/azure/dns/dns-traffic-manager-linked-records

- **Troubleshoot OpenSSL issues on Linux**

  Added a comprehensive guide for diagnosing TLS/OpenSSL problems on Azure Linux VMs. Covers core commands, capturing handshakes, testing cipher/protocol support, and step‑by‑step fixes for missing CA bundles, legacy TLS constraints, and TLS interception. Includes verification patterns and remediation workflows to restore secure connectivity.

  https://learn.microsoft.com/en-us/troubleshoot/azure/virtual-machines/linux/linux-troubleshooting-openssl

- **Strictly Typed Profiles for Azure Traffic Manager**

  Added a concept article describing Strictly Typed Profiles (preview), which enforce endpoint IP type consistency for profiles linked to DNS records. Details type assignment/locking, validation rules, API support, and deletion safeguards when linked records exist. Explains how STP improves correctness and simplifies policy/governance for DNS resolutions.

  https://learn.microsoft.com/en-us/azure/traffic-manager/traffic-manager-strictly-typed-profiles

- **Troubleshoot common deployment failures in Azure Container Apps**

  Introduced an end‑to‑end guide for diagnosing deployment errors before and after revision creation. Maps symptoms to causes and actions for image/registry auth, container crashes, probe defaults/tuning, identity and Key Vault references, and ingress/traffic routing. Provides portal/CLI workflows, error tables, and Kusto queries to accelerate resolution.

  https://learn.microsoft.com/en-us/azure/container-apps/troubleshoot-deployment-errors

- **Tutorial: Create a Traffic Manager Linked Record - Azure CLI**

  Added a hands‑on tutorial (preview) to create linked DNS records to a Traffic Manager profile using Azure CLI. Walks through building sample infrastructure, configuring a priority profile, creating an apex/subdomain linked A record, and validating failover. Highlights TTL inheritance and preview API requirements.

  https://learn.microsoft.com/en-us/azure/dns/tutorial-traffic-manager-linked-records-cli

- **Tutorial: Create a Traffic Manager Linked Record - Azure portal**

  Added a portal tutorial (preview) for creating linked DNS records that return endpoint IPs without a CNAME hop.
