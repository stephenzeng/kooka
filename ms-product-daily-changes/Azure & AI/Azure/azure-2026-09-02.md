## Major Changes

- **Blob rehydration from the archive tier**

  Expanded rehydration targets to include the cold tier for both Set Blob Tier and copy operations, and updated matrices accordingly. Clarified cross-account copy support (service version 2021-02-12+) and that rehydration must target an online tier (hot, cool, or cold). Added guidance to avoid lifecycle re-archiving, monitor copy completion and Event Grid notifications, refined priority behavior and the 10 GiB/hour account limit, and updated pricing/billing details.

  https://learn.microsoft.com/en-us/azure/storage/blobs/archive-rehydrate-overview

- **What is Connector Namespace? (preview)**

  Added a Pricing section describing a consumption-based model with metering for connector actions, trigger actions, MCP connector tool calls, and data retention per GB. Clarifies that hosted MCP server billing is disabled during preview and that MCP tool-call metering reflects underlying connector actions. Removed outdated “pricing not finalized” considerations and cleaned up obsolete links.

  https://learn.microsoft.com/en-us/azure/connector-namespace/connector-namespace-overview

- **Release notes for Azure File Sync**

  Added version 23.1.0.0 with status “Supported - Flighting,” plus recommended alerts to proactively monitor sync health and agent status. Improves performance (about 25% faster directory enumeration) and responsiveness of local change detection, and adds reliability fixes for database consistency and in-use files. Expanded guidance on prerequisites, supported OS and TLS, installation issues, interoperability (AV/backup, FSRM, sysprep), limitations, server/cloud endpoint constraints, and cloud tiering behavior.

  https://learn.microsoft.com/en-us/azure/storage/file-sync/file-sync-release-notes

- **Add private connectivity to Azure IoT Operations**

  Added a prerequisite and dedicated step to enable the operations experience (web UI) to access Key Vault and Schema Registry storage when private endpoints/firewalls are enabled. Provides region-based IP allow lists, portal/CLI steps for allow-listing and keeping AzureServices bypass enabled, and cautions for Network Security Perimeters or tenant network policies. Includes verification steps and updates to step sequencing and known limitations.

  https://learn.microsoft.com/en-us/azure/iot-operations/manage-layered-network/howto-private-connectivity

- **Configure a WAF policy by using Azure PowerShell**

  Overhauled the PowerShell guidance for Azure Front Door Standard/Premium. Clarifies that custom rules apply to both tiers while Default Rule Set requires Premium, and updates examples to Microsoft_DefaultRuleSet v2.2. Introduces explicit -Sku selection and modern association via Azure Front Door profile security policies (Get/New-AzFrontDoorCdn* cmdlets), replacing legacy linkage steps and adding related content.

  https://learn.microsoft.com/en-us/azure/web-application-firewall/afds/waf-front-door-custom-rules-powershell
