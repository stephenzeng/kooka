## New Articles

- **Plan and Size HPC Clusters**

## Major Changes

- **Copy data from SharePoint Online List by using Azure Data Factory or Azure Synapse Analytics**
  Replaced service principal key authentication with certificate-based authentication and removed the ServicePrincipalKey property. Updated permissions to use Microsoft Entra ID with Microsoft Graph application permissions and shifted token acquisition to the v2.0 OAuth endpoint. The copy workflow now uses Microsoft Graph endpoints for file downloads, and headings/instructions were revised to reflect certificate auth and Graph usage, improving security and alignment with modern APIs.

  https://learn.microsoft.com/en-us/azure/data-factory/connector-sharepoint-online-list

- **Add users and assign access to your Azure subscription**
  Retitled and reframed the article to focus on adding users and assigning access using Azure RBAC within Microsoft Entra ID. Guidance emphasizes choosing the correct scope (management group, subscription, resource group, resource) and understanding role assignment principles, reducing prescriptive steps in favor of core RBAC concepts. Redundant visuals were removed and links added to authoritative Microsoft Entra ID documentation for user management.

  https://learn.microsoft.com/en-us/azure/devtest/offer/how-to-add-users-directory

- **In-place upgrade for supported VMs running Windows in Azure (Windows Client)**
  Added a detailed overview of in-place upgrades, supported methods, and an Azure Virtual Desktop (AVD) support matrix clarifying that OS version upgrades aren’t supported for AVD session hosts or standard VMs. Highlighted mandatory Windows 11 prerequisites (Gen2, Trusted Launch with vTPM, Secure Boot, supported vCPU) and cautions on risk, recommending image-based replacement for AVD. Expanded AVD guidance, including WSUS-based feature updates conditions, and clarified the single-session exception while disallowing multi-session in-place upgrades.

  https://learn.microsoft.com/en-us/troubleshoot/azure/virtual-machines/windows/in-place-system-upgrade

- **Create a site-to-site IPv6 VPN connection in dual stack using Azure CLI**
  Removed all preview enrollment instructions and labels, signaling general availability of dual-stack IPv6 support for site-to-site VPN. The article title and notes were updated to reflect GA status without altering core procedural steps. This clarifies production readiness and simplifies setup.

  https://learn.microsoft.com/en-us/azure/vpn-gateway/site-to-site-ipv6-azure-cli

- **Troubleshoot Application Gateway Ingress Controller Connectivity Issues**
  Overhauled troubleshooting guidance with a clear symptoms inventory and step-by-step diagnostics for AGIC pod health and log analysis. Added validation steps for synchronization between AGIC and Application Gateway, including Activity log verification and common error interpretation. Streamlined the flow for both add-on and Helm deployments, clarified ingress verification, and removed outdated or optional comparisons to focus on actionable resolution.

  https://learn.microsoft.com/en-us/troubleshoot/azure/azure-kubernetes/load-bal-ingress-c/troubleshoot-app-gateway-ingress-controller-connectivity-issues
