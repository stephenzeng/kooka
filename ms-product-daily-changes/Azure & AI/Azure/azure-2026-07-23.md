## Major Changes

- **Create new subnet within an enclave Virtual Network**
  
  Expanded guidance clarifies that Azure Enclave is the authoritative control plane for the enclave VNet. Added subnet delegation instructions, IP reservation considerations, and a strong warning to avoid direct edits (subnets, address space, route/NSG associations, peerings) outside the enclave experience. Only DNS server configuration is supported directly; all other changes must be managed via the enclave to avoid drift and outages.

  https://learn.microsoft.com/en-us/azure/enclave/create-new-enclave-subnet

- **Deploy Azure File Sync**
  
  Updated deployment guidance to support Windows Server 2025 and remove Windows Server 2012 R2, including script changes to detect 2025 and fetch the correct agent. Cleaned up legacy 2012 R2 steps and error messages to reflect the new supported set (2016/2019/2022/2025). Ensures new deployments follow current OS support and installation paths.

  https://learn.microsoft.com/en-us/azure/storage/file-sync/file-sync-deployment-guide

- **Release notes for Azure File Sync**
  
  Added v23 (23.00.0) with extensive updates: recommended alerts, reliability and telemetry improvements, faster directory enumeration, and better handling of in-use files and stale entries. Expanded installation, configuration, interoperability, and limitations, including OS support, memory, TLS, .NET, and required Windows updates. Added detailed guidance for endpoints, cloud detection cadence, cloud tiering, and Robocopy usage to improve operational readiness and stability.

  https://learn.microsoft.com/en-us/azure/storage/file-sync/file-sync-release-notes

- **Deploy ASP.NET Core and Azure SQL Database app**
  
  Removed Azure Cache for Redis from the tutorial and focused on App Service and Azure SQL Database, updating architecture, provisioning steps, and deployment instructions. Adjusted secrets and managed identity guidance to use only the SQL connection string and Key Vault. Updated code and CI paths (including AZD) to make Redis optional and streamline the app setup.

  https://learn.microsoft.com/en-us/azure/app-service/tutorial-dotnetcore-sqldb-app

- **What is an enclave?**
  
  Added guidance establishing Azure Enclave as the authoritative control plane for the enclave VNet and warning against direct VNet edits that can cause configuration drift and break features. Introduced subnet delegation guidance and emphasized managing delegation through the enclave experience to keep state consistent. Helps prevent outages by enforcing a single source of truth for network changes.

  https://learn.microsoft.com/en-us/azure/enclave/what-enclave
