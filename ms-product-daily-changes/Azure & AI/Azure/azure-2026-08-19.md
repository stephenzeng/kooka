## New Articles

- **Create Application Control Supplemental Policy for MABS**

  Introduced a step-by-step guide to create and deploy a Windows Defender Application Control (WDAC) supplemental policy for Microsoft Azure Backup Server on Azure Local. The article provides an XML policy template, shows how to capture signer fingerprints, and details policy versioning and identification updates. It also covers deployment and verification commands and points to guidance on switching WDAC modes, enabling secure agent deployments in enforced environments.

  https://learn.microsoft.com/en-us/azure/backup/backup-server-application-control-supplemental-policy-create

- **Monitor Microsoft Azure Backup Server (MABS)**

  Added comprehensive monitoring guidance across the MABS console, Recovery Services vault, and System Center Operations Manager, enabling end-to-end visibility of alerts, jobs, and protection status. The article includes OAuth 2.0 configuration for Microsoft 365 email notifications, alternative SMTP options, and centralized monitoring via Central Console. This helps administrators modernize notifications and streamline operational oversight.

  https://learn.microsoft.com/en-us/azure/backup/backup-server-monitor

- **Relocate Azure Data Lake Storage to a Another Region**

  Published a migration guide for moving hierarchical namespace-enabled storage to another region using AzCopy, Storage Mover, or account failover for paired regions. It outlines prerequisites, limits (for example, POSIX ACL handling and cross-tenant constraints), and validation steps to ensure configuration, access, and performance are preserved post-move. The guidance helps teams choose the right approach and avoid downtime or security regressions.

  https://learn.microsoft.com/en-us/azure/storage/blobs/data-lake-storage-migrate-data

- **Analyze the impact of feature flags in Azure App Configuration**

  Introduces Metric Scorecards (preview) to assess the impact of feature flag variants using Application Insights telemetry. The article explains how to select allocations, compare variants, and interpret Impacted versus Inconclusive metrics. By quantifying changes against a control variant, teams can quickly spot regressions and make data-driven rollout decisions.

  https://learn.microsoft.com/en-us/azure/azure-app-configuration/howto-metric-scorecards

- **View feature flag events in Azure App Configuration**

  Added a how-to for exploring feature flag telemetry, including filtering events in Application Insights and validating variant assignments and allocations. It provides a Kusto query to correlate feature evaluation with custom application events to compare variant performance. This enables targeted analysis of user impact and behavior changes driven by feature flags.

  https://learn.microsoft.com/en-us/azure/azure-app-configuration/howto-telemetry-review-results

- **Troubleshoot non-zone-redundant quota requests for Azure App Service**

  New troubleshooting guide for regional (non-zone-redundant) quota issues in App Service with self-service quota workflows. It explains common error patterns, how to calculate and request appropriate limits per SKU and region, and how to distinguish quota constraints from regional capacity issues. Practical steps and FAQs help teams unblock scale needs efficiently.

  https://learn.microsoft.com/en-us/troubleshoot/azure/app-service/troubleshoot-non-zone-redundant-quota-requests

- **Use the New-AVSStoragePolicy Run Command in Azure VMware Solution**

  Added detailed guidance for creating vSAN storage policies in AVS via the New-AVSStoragePolicy run command, covering ESA/OSA behaviors and stretched cluster specifics. The article documents all key parameters (tolerance, encryption, reservations, IO limits, tags) and includes validation steps. Extensive troubleshooting addresses name conflicts, parameter validation, and encryption prerequisites to ensure reliable policy deployment.

  https://learn.microsoft.com/en-us/azure/azure-vmware/use-new-avsstoragepolicy-run-command
