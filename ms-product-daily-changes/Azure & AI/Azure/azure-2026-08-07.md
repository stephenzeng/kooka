## Major Changes

- **Azure Automation Runbook Types**

  Added PowerShell 7.6 as a supported runtime and advised using long-term supported versions. Introduced a detailed section on 7.6 limitations and known issues, including module extraction behavior, lack of workflow/signed runbook support, source control considerations, default Az module version, and dependency validation, with practical workarounds and examples. Clarified that PowerShell 7.6/7.4 and Python 3.10 runtimes support both cloud and hybrid jobs in all regions.

  https://learn.microsoft.com/en-us/azure/automation/automation-runbook-types

- **Interoperability in Azure - Control plane analysis**

  Removed extensive conceptual guidance on combining ExpressRoute and site-to-site VPN and on extending connectivity to spokes and branches. Streamlined navigation by updating Next steps to point to the test setup preface and data plane analysis and reorganizing ExpressRoute FAQs. This focuses the article on control plane analysis while directing readers to dedicated resources for scenario specifics.

  https://learn.microsoft.com/en-us/azure/networking/connectivity-interoperability-control-plane

- **Interoperability in Azure - Data plane analysis**

  Corrected the article introduction and replaced references to deprecated Network Performance Monitor with Connection Monitor, including deprecation and migration guidance. Fixed a visibility reference and removed scenario walkthroughs for ExpressRoute/VPN tandem and extended topologies, consolidating them into a simplified Next steps section. The update modernizes monitoring guidance and keeps the content tightly scoped to data plane analysis.

  https://learn.microsoft.com/en-us/azure/networking/connectivity-interoperability-data-plane

- **IoT Hub endpoints**

  Added Microsoft Fabric Eventstreams (preview) as a supported custom routing endpoint. Documented how to route device-to-cloud messages to a Fabric eventstream using Event Hub protocol with Microsoft Entra ID authentication, including managed identity options and current authentication limitations (SAS not supported). Specified CloudEvents schema usage, property naming rules for message enrichment, and noted CLI and Bicep configuration support.

  https://learn.microsoft.com/en-us/azure/iot-hub/iot-hub-devguide-endpoints

- **Azure Container Apps Sandboxes overview (preview)**

  Removed support for building disk images from Dockerfiles in sandbox groups. Only public images and container registry images are now supported sources. This clarifies supported image paths and prevents unsupported build workflows.

  https://learn.microsoft.com/en-us/azure/container-apps/sandboxes-overview

- **Understanding admin VMs in Azure Enclave**

  Substantially expanded guidance on when and how to use admin VMs, emphasizing time-bound administrative access. Added detailed steps for connecting via Azure Bastion and for using Remote Desktop from an admin VM to enclave resources. Included management procedures such as resetting OS passwords, selecting VM sizes for concurrent sessions, and deploying from a custom image by resource ID, with clear separation between admin tools and workload resources.

  https://learn.microsoft.com/en-us/azure/enclave/understand-admin-vm

- **What is Azure Resource Manager?**

  Clarified how to choose a resource group location by distinguishing control plane operations (handled by ARM with regional failover) from data plane access (unaffected by RG location). Explained behavior during regional outages, recommended colocating resources with their resource group, and added resiliency references. Also reflects a comprehensive overhaul of Azure Web PubSub’s overview content, adding capability comparisons, enterprise-grade features, and integration patterns to help teams choose and build real-time solutions at scale.

  https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/overview
