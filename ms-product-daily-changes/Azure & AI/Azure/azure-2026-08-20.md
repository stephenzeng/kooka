## New Articles

- **Choose the right query strategy for Azure Resource Graph**  
  Introduced guidance on when to use Azure Resource Graph (ARG) versus resource provider (RP) APIs. Explains ARG’s eventual consistency and recommends a hybrid approach: query ARG for scale and fall back to RP APIs for freshness or before destructive actions. Provides practical tactics for handling consistency, including verification only before irreversible steps, quota considerations, backoff strategies, and using the ARG Get/List API for high-frequency polling.  
  https://learn.microsoft.com/en-us/azure/governance/resource-graph/choose-query-strategy

- **Protect sensitive data in logs**  
  Added how-to for Azure Front Door Standard/Premium to scrub sensitive data in access logs. Clarifies tier availability and what fields can be masked (request URI, IP addresses, specific query parameters), with Microsoft retaining IPs internally for security. Includes portal steps to enable, configure, and verify scrubbing with clear validation guidance.  
  https://learn.microsoft.com/en-us/azure/frontdoor/sensitive-data-protection

- **Troubleshoot latency issues on Azure NetApp Files volumes**  
  Introduces a prescriptive workflow to diagnose latency across three areas: throughput throttling, cool-tier reads, and client/network factors. Details how to detect QoS ceilings and cool-tier read impact with Azure Monitor metrics and provides targeted remediations (service level or quota adjustments, tier policies). Adds client/network checks and when to open a support case, including what evidence to collect.  
  https://learn.microsoft.com/en-us/azure/azure-netapp-files/troubleshoot-latency-issues
