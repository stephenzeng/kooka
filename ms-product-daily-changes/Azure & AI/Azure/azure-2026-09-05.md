# Azure
**Date created:** 2026-09-05 UTC  
**Tags:** Best Practices, Billing, Configuration, Guidance, Identity, Performance, Security  

## New Articles

- **Remote visualization for high-performance computing on Azure**

  Introduced an end-to-end overview of remote visualization on Azure, clarifying how moving rendering closer to the data improves performance and differs from general VDI. Detailed architecture components, deployment models, and GPU considerations with sizing guidance, along with session technology options and driver requirements. Provided network, storage, and security best practices plus a validation checklist to ensure application support, user experience, capacity, data access, operations, and governance are ready.

  https://learn.microsoft.com/en-us/azure/high-performance-computing/remote-visualization-overview

- **Choose a remote visualization deployment model for Azure HPC**

  Added guidance to select among standalone visualization, scheduler-integrated cluster visualization, and alternative access patterns, comparing workflows, scaling, data access, and cost. Provided planning criteria (users and concurrency, availability, startup time, cost management, data location, and required skills) with a decision framework that emphasizes data locality. Recommended piloting and validation steps and linked to related Azure CycleCloud Workspace and Open OnDemand resources and GPU VM size references.

  https://learn.microsoft.com/en-us/azure/high-performance-computing/remote-visualization-choose-deployment-model

## Major Changes

- **Configure Open OnDemand with CycleCloud**

  Significantly expanded guidance with new sections on user experience, using interactive applications through Slurm, and customizing workspaces via CycleCloud cluster-init. Added recommendations to validate integrations, resource controls, and dependencies across partitions, VM sizes, GPUs, and storage to ensure reliable operations. Enhanced security and networking guidance for certificates, FQDN configuration, and private access patterns, plus clarified authentication steps and expanded reference resources.

  https://learn.microsoft.com/en-us/azure/cyclecloud/how-to/ccws/configure-open-ondemand?view=cyclecloud-8

## Moderate Changes

- **End-user entry point configuration**

  Distinguished administrative remote desktop needs from visualization workloads that require hardware-accelerated OpenGL. Added prescriptive paths for xrdp-based admin access on sign-in nodes and GPU-enabled sessions on NV-family VMs with verification steps for acceleration, and introduced Open OnDemand as a browser-based option when using a scheduler.

  https://learn.microsoft.com/en-us/azure/high-performance-computing/lift-and-shift-step-5-end-user-entry-point

- **Organize your invoice based on your needs - Azure**

  Added a section on viewing supplemental documents, explaining how they relate to purchase orders and provide PO- or invoice section–specific charge views. Included portal steps to access them from an invoice (Cost Management + Billing > Invoices > select invoice > Supplemental docs tab).

  https://learn.microsoft.com/en-us/azure/cost-management-billing/manage/mca-section-invoice

- **Release notes 2026: Azure Health Data Services**

  Enforced SMART-on-FHIR compartment authorization for _include and _revinclude queries, which can limit results to match SMART scopes, and optimized reindex operations for efficiency and resilience. Fixed multiple issues including conditional PATCH with required ETags, intermittent errors from non-thread-safe header access, a background job security provider exception, incorrect HTTP 500s when mixing SMART v1/v2 scopes, and $import status failures when using a processing job ID.

  https://learn.microsoft.com/en-us/azure/healthcare-apis/release-notes-2026
