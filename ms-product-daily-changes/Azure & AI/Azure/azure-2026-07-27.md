## Moderate Changes

- **Azure Backup - Configure backup of Confidential VM using Azure Backup (preview)**

  Updated guidance to configure backups for OS-disk encrypted Confidential VMs using platform-managed or customer-managed keys, including a clear end-to-end flow from validation through monitoring. Clarified prerequisites and strengthened permission guidance for Key Vault and Managed HSM with step-by-step role assignments and a reminder about role propagation delays. Enhanced setup steps to validate key access warnings, monitor the initial backup, and referenced the support matrix as the authoritative source for supported scenarios.
