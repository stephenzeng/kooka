# Azure
**Date created:** 2026-07-19 UTC  
**Tags:** Administration, Programming  

## Moderate Changes

- **Customization at the edge using Azure Front Door edge actions (preview)**

  Updated pricing guidance with an explicit table listing meters and rates, including $0.10 per 1M invocations and $0.00005 per second of overage execution time. Clarified that overage execution time is the cumulative time beyond 1 ms per invocation, and retained the billing example link while simplifying related references. This improves cost transparency and helps customers estimate and manage spend more accurately.

  https://learn.microsoft.com/en-us/azure/frontdoor/edge-actions

- **Azure Functions Flex Consumption plan hosting**

  Added Python 3.14 to the supported language versions for the Flex Consumption plan. This enables developers to use the latest Python runtime and plan upgrades with clearer compatibility guidance.

  https://learn.microsoft.com/en-us/azure/azure-functions/flex-consumption-plan

- **Request a credit for Withholding Tax on your account (Global customers)**

  Simplified the WHT credit request process for credit card payments by removing the requirement for “All other customers” to submit a Withholding Tax Certificate or Receipt. Replaced region-specific submission emails with a single instruction to open a Microsoft support ticket, and removed the regional email table. This streamlines submissions and reduces the documentation burden.

  https://learn.microsoft.com/en-us/azure/cost-management-billing/manage/withholding-tax-credit-india
