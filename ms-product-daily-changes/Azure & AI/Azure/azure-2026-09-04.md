## Major Changes

- **Secure Key Release feature with AKV and Azure Confidential Computing (ACC)**

  Clarified that Secure Key Release (SKR) applies beyond confidential computing and that Azure Key Vault Premium and Managed HSM validate Microsoft Azure Attestation (MAA) tokens regardless of compute type. Added details on using Trusted Launch VM attestation claims (for example, secure boot and vTPM PCRs) in policies. Expanded support guidance to allow tokens from other attestation authorities when they follow the required structure, use OpenID Connect, carry required claims, and chain to a Key Vault–trusted public CA.

  https://learn.microsoft.com/en-us/azure/confidential-computing/concept-skr-attestation

- **Azure Functions hosted skills**

  Reframed the model around “hosted skills” mapped one-to-one with functions via .agent.md files, replacing prior “AI tasks” terminology. Added clear guidance on when to use hosted skills, updated benefits and trigger patterns (one trigger per .agent.md), and overhauled project structure and execution flow without relying on the former Agent Framework description. Expanded tool integration coverage (MCP servers, connectors, reusable skills, custom tools) and introduced a new dynamic workflows section using Durable Functions for durable, multistep plans.

  https://learn.microsoft.com/en-us/azure/azure-functions/functions-hosted-skills

- **Secure your Azure App Service deployment**

  Overhauled security guidance with a Zero Trust statement and a new service-specific section covering protocol hardening, network isolation, and WAF protections. Clarified critical behaviors (for example, HTTPS-only redirect isn’t enabled by default) and strengthened identity, data protection, monitoring, compliance, and backup recommendations with updated references. Emphasized using Key Vault references for secrets, refined RBAC guidance, and reorganized content to surface prescriptive practices earlier.

  https://learn.microsoft.com/en-us/azure/app-service/overview-security

- **Quickstart: Use work item filtering with the Durable Task SDKs**

  Expanded the quickstart to add Python support for Durable Task Scheduler work item filtering. Updated availability notes and added an end-to-end Python flow with examples for enabling filters, configuring auto-generated and explicit filtering, and running local workers side by side.

  https://learn.microsoft.com/en-us/azure/durable-task/scheduler/quickstart-work-item-filtering-durable-task
