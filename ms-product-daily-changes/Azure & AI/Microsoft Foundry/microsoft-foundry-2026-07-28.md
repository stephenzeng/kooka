# Microsoft Foundry
**Date created:** 2026-07-28 UTC  
**Tags:** Administration, AI, Agent, Automation, Governance, Monitoring, Programming, Security  

## Moderate Changes

- **Get started with an AI template**

  Added guidance on using agent templates in the Foundry portal so teams can deploy starter manifests and accelerate agent development. Updated navigation to choose between Solution templates or Agents, and clarified that “Open in GitHub” applies when viewing a solution template to reduce setup confusion.

  https://learn.microsoft.com/en-us/azure/foundry/how-to/develop/ai-template-get-started

- **Manage compliance and security in Microsoft Foundry**

  Updated Microsoft Purview integration guidance with the Azure AI Account Owner role requirement, clearer data flow and policy enforcement details, and an expanded list of governance benefits. Revised portal steps to the Data security and governance tab with subscription selection and the Purview toggle, and added prerequisites and billing notes (including audit-only behavior without PAYG) to ensure correct enablement.

  https://learn.microsoft.com/en-us/azure/foundry/control-plane/how-to-manage-compliance-security

- **Trigger applications, processes, or CI/CD workflows based on Azure Machine Learning events**

  Clarified how to verify Event Grid subscriptions in the workspace and validate email alerts by triggering a qualifying event. Streamlined CLI setup by referencing the eventgrid extension in prerequisites and removing redundant installation commands, improving reliability of alerting and automation workflows.

  https://learn.microsoft.com/en-us/azure/machine-learning/how-to-use-event-grid?view=azureml-api-2

- **Add scoring profiles to boost search scores**

  Corrected the freshness boosting example to use the ISO 8601 duration format P365D, preventing configuration errors. This ensures time-based boosting behaves as intended for more accurate search ranking.

  https://learn.microsoft.com/en-us/azure/search/index-add-scoring-profiles

- **Tutorial: Forecast demand with no-code automated machine learning in the Azure Machine Learning studio**

  Updated deployment to use a managed real-time online endpoint with autogenerated scoring script and environment, simplifying operational setup. Revised steps cover endpoint/deployment naming, VM size, instance count, key-based authentication, and status tracking, with pointers to CLI/Python alternatives and updated cleanup that deletes the endpoint to remove its deployment.

  https://learn.microsoft.com/en-us/azure/machine-learning/tutorial-automated-ml-forecast?view=azureml-api-2
