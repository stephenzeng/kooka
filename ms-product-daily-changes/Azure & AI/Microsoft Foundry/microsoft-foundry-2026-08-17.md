## New Articles

- **Microsoft Foundry Skill example prompts and scenarios**

  Added a comprehensive how-to with curated scenarios and ready-to-use prompts to accelerate common Microsoft Foundry workflows. It guides you through resource provisioning and administration with validation and RBAC, building and deploying hosted Python agents, and creating Prompt Agents with schema checks and conversation continuity. It also covers evaluating and observing agents with smoke tests and Application Insights/KQL, optimizing with Agent Optimizer, and automating CI/CD with a GitHub Actions workflow aligned to azd. Cleanup steps help you remove resources created by quickstarts.

  https://learn.microsoft.com/en-us/azure/foundry/how-to/develop/foundry-skills-scenarios-example-prompts
