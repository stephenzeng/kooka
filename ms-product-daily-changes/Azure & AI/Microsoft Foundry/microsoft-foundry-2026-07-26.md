# Microsoft Foundry
**Date created:** 2026-07-26 UTC  
**Tags:** AI, Agent, Governance  

## Moderate Changes

- **What is Microsoft Foundry Canvas?**

  Renamed the article and updated terminology from “Foundry Agent Canvas” to “Microsoft Foundry Canvas” throughout. Streamlined installation to a single method via GitHub Copilot App Settings > Plugins by searching for “microsoft-foundry,” and added a supporting screenshot. The core concepts remain unchanged, reducing setup friction while preserving capabilities.

  https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/foundry-canvas

- **Use skills in Foundry (preview)**

  Added a prominent caution for using Skills with third-party systems, noting they are subject to external terms. The guidance stresses reviewing data practices, compliance and geography constraints, permissions, and implementing responsible AI mitigations and testing. This helps teams manage risk and meet security, reliability, and trust requirements.

  https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/tools/skills

- **How to use the Voice Live API**

  Introduced MAI-Voice-2-Flash (Preview) with a sample JSON configuration and a link to the MAI voices list. Updated the example voice to en-US-AvaMultilingualNeural. These changes simplify configuration and enable quick adoption of the new voice capability.

  https://learn.microsoft.com/en-us/azure/ai-services/speech-service/voice-live-how-to
