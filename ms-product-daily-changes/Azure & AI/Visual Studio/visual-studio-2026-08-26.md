## Moderate Changes

- **Create a pull request in Visual Studio**

  Updated guidance on reviewing pull requests directly in Visual Studio, including browsing PR details without checking out the branch and clarifying that editor-based comments require a checkout. Expanded instructions for line comments, replies, resolving threads, and using images and Markdown, plus a note on feature differences between GitHub and Azure DevOps. Added steps to enable the pull request list via Preview Features, helping users configure the experience correctly.
