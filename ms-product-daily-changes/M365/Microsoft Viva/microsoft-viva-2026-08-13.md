# Microsoft Viva
**Date created:** 2026-08-13 UTC  
**Tags:** Analytics, Configuration, Guidance, Troubleshooting  

## New Articles

- **Manage AI Skills Navigator**

  Introduced a new admin guide for configuring AI Skills Navigator within Viva Learning. Covers required roles and licenses, how to access settings, and how to enable or disable specific content types such as Credentials and Microsoft YouTube videos. Explains default behaviors, save and refresh timing, and provides steps to remove AI Skills Navigator for the organization to align with governance needs.

  https://learn.microsoft.com/en-us/viva/learning/manage-ai-skills-navigator

## Moderate Changes

- **Advanced analysis FAQ**

  Added guidance to address failed refreshes caused by Copilot Chat metric renames, including how to locate and update metrics in existing Viva Insights queries and connected Power BI reports. Included a mapping table from old to new metric names, clarifying legacy web metrics, consolidated action counts, and standardized prompt categories, with follow-on questions renumbered.

  https://learn.microsoft.com/en-us/viva/insights/advanced/reference/faq

- **Advanced analysis metric descriptions**

  Updated the Important note to clarify consolidation of Copilot Chat (work) and (web) into a single metric and the impact on previously run queries, which may fail on refresh until metrics are updated. Noted that certain asterisked metrics can return zero due to consolidation and refined wording for legacy web references.

  https://learn.microsoft.com/en-us/viva/insights/advanced/reference/metrics
