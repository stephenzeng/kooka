# Microsoft Viva
**Date created:** 2026-08-04 UTC  
**Tags:** Administration, AI, Analytics, Governance  

## Moderate Changes

- **Export AI cost metrics from the Consumption Dashboard (preview)**

  Clarified that AI cost (credit usage) exports are user-level and hashed by default, with an option for administrators to enable identifiable exports. Guidance also separates and clarifies export frequency details to reduce ambiguity. This helps admins balance privacy with operational reporting needs.

  https://learn.microsoft.com/en-us/viva/insights/org-team-insights/export-ai-cost-metrics

- **Export Copilot metrics from the Microsoft Copilot Dashboard (preview)**

  Updated to explain that user-level Microsoft 365 Copilot metrics are anonymized by default, with the option to include identifiable fields when an administrator enables identifiable export. This clarification helps organizations make informed choices about privacy and reporting fidelity.

  https://learn.microsoft.com/en-us/viva/insights/org-team-insights/export-copilot-metrics

- **Identification in Copilot Analytics**

  Added a Feature availability section outlining where identification is supported: Consumption Dashboard data export and insights, Copilot Dashboard data export (Public Preview), and Agent Dashboard data export (Public Preview). This makes it easier to understand when identifiable data can appear across analytics experiences.

  https://learn.microsoft.com/en-us/viva/insights/identification-copilot-analytics

- **Upload and maintain data through the Microsoft 365 admin center**

  Aligned terminology from “Microsoft Organizational Data Service” to “Organizational Data in Microsoft 365” throughout, without changing procedures. Also clarified that files larger than 25 MB must be uploaded via SharePoint, improving guidance for large data uploads.

  https://learn.microsoft.com/en-us/viva/insights/advanced/admin/upload-org-data-admin-center
