# Microsoft Viva
**Date created:** 2026-08-29 UTC  
**Tags:** Licensing  

## Moderate Changes

- **Assign licenses for Viva Insights**

  Updated licensing requirements: data processing now begins with either at least 50 assigned Viva Insights licenses or one assigned Copilot license that includes the Viva Insights service plan. Adjusted processing timelines from 3–5 days to up to seven days, with guidance to export day-level metrics for more recent data. Minor formatting improvements to note callouts.

  https://learn.microsoft.com/en-us/viva/insights/advanced/setup-maint/assign-licenses
