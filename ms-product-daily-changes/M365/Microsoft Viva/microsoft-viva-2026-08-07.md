# Microsoft Viva
**Date created:** 2026-08-07 UTC  
**Tags:** Administration, Analytics  

## New Articles

- **Microsoft 365 Copilot latest usage snapshot report**

  Introduced a preview Power BI template that provides a snapshot of Microsoft 365 Copilot usage, with clear prerequisites and step-by-step setup. The guidance explains how to run a Viva Insights query, connect the template via partition and query IDs, and configure settings such as time period, activity interval, group-by, filters, and active user definitions. It outlines report sections including Adoption overview and a Glossary, and notes data freshness, metric rules, minimum group sizes, and privacy considerations. This helps analysts quickly visualize adoption trends and compare usage across groups, apps, and features.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/templates/copilot-latest-usage

## Moderate Changes

- **Manage settings for the Microsoft Copilot Dashboard, Agent Dashboard, Consumption Dashboard, and Viva Insights web app**

  Corrected a PowerShell example by changing a property name to avoid configuration errors in Agent Dashboard settings. Also removed the previously stated multi-day processing time for exclusion lists, aligning expectations with current behavior.

  https://learn.microsoft.com/en-us/viva/insights/advanced/admin/manage-settings-copilot-dashboard
