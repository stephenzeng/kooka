# Microsoft Viva
**Date created:** 2026-08-06 UTC  
**Tags:** Analytics  

## Moderate Changes

- **Business resilience report**

  Clarified employee filter behavior: when analyzing only behavioral data, the Is Active filter now defaults to false and can be set to true if needed. Added a restriction that Is Active cannot be used when Copilot metrics are included, reducing filter conflicts.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/templates/business-resilience

- **Copilot Business Impact report**

  Updated employee selection guidance by removing the prior instruction to keep the Is Active filter. Clarified that Is Active cannot be used when analyzing Copilot metrics to avoid invalid queries.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/templates/copilot-business-impact

- **Copilot for Sales adoption report**

  Revised filter setup by dropping the direction to retain the Is Active filter. Added a constraint that Is Active is not supported when Copilot metrics are part of the analysis.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/templates/copilot-for-sales-adoption

- **Copilot headlines report**

  Streamlined query configuration by removing the instruction to keep the predefined Is Active filter. Clarified that Is Active cannot be used alongside Copilot metrics to ensure accurate results.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/templates/copilot-headlines

- **Growth, inclusion and engagement Power BI report**

  Clarified that with behavioral-only analysis, Is Active defaults to false and can be set to true if required. Specified that Is Active cannot be used when any Copilot metrics are included, preventing incompatible filter combinations.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/templates/growth-inclusion-engagement

- **Hybrid Workforce Experience Power BI report**

  Updated filter guidance to note that Is Active defaults to false for behavioral-only data and can be set to true if needed. Added a restriction that Is Active cannot be used with Copilot metrics, aligning with current data rules.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/templates/hybrid-workforce-experience

- **Manager effectiveness report**

  Clarified filter behavior so that Is Active defaults to false when using only behavioral data and can be switched to true if desired. Introduced a constraint that Is Active cannot be applied when Copilot metrics are included.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/templates/manager-effectiveness

- **Advanced analysis metric descriptions**

  Marked several Copilot Chat metrics as legacy or no longer tracked by adding an asterisk to their names. Added a footnote explaining that these starred metrics may return zero values, guiding analysts to interpret results correctly.

  https://learn.microsoft.com/en-us/viva/insights/advanced/reference/metrics

- **Microsoft 365 Copilot adoption report**

  Removed the instruction to keep the predefined Is Active filter during employee selection. Added a rule that Is Active cannot be used when analyzing Copilot metrics to prevent invalid filter configurations.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/templates/microsoft-365-copilot-adoption

- **Microsoft 365 Copilot impact report**

  Eliminated the directive to retain the predefined Is Active filter. Clarified that Is Active is incompatible with Copilot metrics to ensure valid query setup.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/templates/microsoft-365-copilot-impact

- **Person query**

  Updated guidance to reflect that for behavioral-only metrics, Is Active defaults to false and can be set to true. Clarified that Is Active cannot be used when combining behavioral and Copilot metrics and removed references to a predefined Is Active condition.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/person-query

- **Wellbeing - balance and flexibility report**

  Clarified that when analyzing only behavioral data, Is Active defaults to false and can be set to true as needed. Specified that Is Active cannot be used when Copilot metrics are part of the report.

  https://learn.microsoft.com/en-us/viva/insights/advanced/analyst/templates/wellbeing
