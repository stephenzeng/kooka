# Microsoft Viva
**Date created:** 2026-07-25 UTC  
**Tags:** AI, Analytics, Monitoring  

## Major Changes

- **Use Viva Glint's Comments report**
  
  Expanded guidance on how topics are assigned to comments, covering both standard NLP-based assignment and Copilot-enhanced topic assignment, with clear expectations on when each appears and how results may differ from prior cycles. Added details on data processing boundaries, confidentiality, storage, accuracy considerations, and limitations for Copilot-enhanced topic assignment, along with deeper explanations of Topics, Keywords, and related comment views. Clarified translation behavior, export results (including handling of N/A topics and multilingual exports), mixed sentiment interpretation, and strengthened redaction and quarantine instructions. Included best practices and a comprehensive FAQ on enablement, configuration, and why topics may change, while removing earlier claims about organization-specific topic support to better align expectations.
  
  https://learn.microsoft.com/en-us/viva/glint/reports/comments-report

- **Advanced analysis metric descriptions**
  
  Restructured and expanded metric documentation to introduce clear groupings for Copilot adoption and licensing, enablement, usage and engagement, Copilot Chat summaries, per‑app Microsoft 365 Copilot metrics (Microsoft 365 app, Teams, Outlook, Word, PowerPoint, Excel, plus OneNote and Loop activity days), GitHub Copilot, agents, credits/consumption, and Copilot for Sales. Added and clarified metrics such as Returning users (Copilot users), Total Copilot actions in Copilot Chat, and multiple per‑app prompt metrics (including legacy web variants), and consolidated consumption and GitHub Copilot metrics into dedicated sections. Included minor naming refinements (e.g., Outlook drafting) to improve consistency. These changes make it easier to find, interpret, and compare Copilot‑related metrics across apps and scenarios.
  
  https://learn.microsoft.com/en-us/viva/insights/advanced/reference/metrics
