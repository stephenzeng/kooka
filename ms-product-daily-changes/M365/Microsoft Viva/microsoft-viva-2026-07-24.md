# Microsoft Viva
**Date created:** 2026-07-24 UTC  
**Tags:** Administration  

## Moderate Changes

- **Configure manager settings**

  Updated guidance clarifies team size calculations: direct and indirect reports no longer need a Viva Insights service plan to be counted. It also specifies that the minimum team size requirement applies to all employees under a manager, not just licensed users. This helps admins configure manager settings accurately and ensures consistent reporting thresholds.

  https://learn.microsoft.com/en-us/viva/insights/advanced/setup-maint/manager-settings
