# Microsoft Viva
**Date created:** 2026-07-21 UTC  
**Tags:** Administration, AI, Analytics  

## Major Changes

- **How to use the Consumption Dashboard in Insights**
  Reorganized the Consumption Dashboard into Microsoft 365 services and GitHub tabs to make navigation clearer. Introduced a new GitHub page (public preview) with deep insights into GitHub Copilot credit consumption and usage, including trends with drilldowns, user segment intensity, feature-level usage metrics, chat requests, code completions, and acceptance rates—broken down by model, language, and chat mode. Added notes on data coverage and known under-reporting prior to July 10, 2026, plus updated guidance on page-specific filters with new illustrative images to help admins interpret and act on the data.
  https://learn.microsoft.com/en-us/viva/insights/org-team-insights/ai-cost-dashboard

- **Advanced analysis metric descriptions**
  Renamed and refocused the “Total Copilot Credits used (consumption insights)” metric to “Total AI credits usage” with a GitHub Copilot scope for clearer attribution. Added an app-specific section with detailed GitHub Copilot metrics, including active users, agent adoption, chat requests, suggested and accepted completions, acceptance rates, and usage by model, language, and chat mode. These additions provide richer analytics for monitoring Copilot adoption, efficiency, and model/language usage patterns.
  https://learn.microsoft.com/en-us/viva/insights/advanced/reference/metrics

## Moderate Changes

- **Manage settings for the Microsoft Copilot Dashboard, Agent Dashboard, Consumption Dashboard, and Viva Insights web app**
  Expanded the document to include the Consumption Dashboard alongside existing dashboards, updating the title and references to reflect the broader scope. Aligned settings and the unified exclusion list so admins can manage governance consistently across all dashboards and Viva Insights.
  https://learn.microsoft.com/en-us/viva/insights/advanced/admin/manage-settings-copilot-dashboard
