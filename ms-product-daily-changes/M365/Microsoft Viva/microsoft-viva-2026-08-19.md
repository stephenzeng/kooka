# Microsoft Viva
**Date created:** 2026-08-19 UTC  
**Tags:** Analytics, Guidance, Troubleshooting  

## Major Changes

- **Connect to the Microsoft Copilot Dashboard for Microsoft 365 customers**

  Expanded sentiment insights across readiness, adoption, and impact pages, with previews of employee-level survey results. Added support for multiple survey sources (Viva Glint, Viva Pulse, CSV) and a Survey toggle to select input. Enabled launching new Viva Pulse surveys directly from the dashboard, including guidance on using Recommendations. Introduced a “Survey questions deep dive” page with filters by license, scope, organization, and job function, plus a heat map for rating questions with normalized scoring across different scales. Updated screenshots and restructured sections to reflect the new experience.

  https://learn.microsoft.com/en-us/viva/insights/org-team-insights/copilot-dashboard

## Moderate Changes

- **How to fix validation errors and warnings when importing data**

  Expanded the list of reserved attribute names that must not be uploaded as custom fields, reducing preventable import errors. This clarification helps admins maintain clean schemas and ensures smooth data ingestion into Viva Insights.

  https://learn.microsoft.com/en-us/viva/validation-errors-warnings
