# Microsoft Viva
**Date created:** 2026-07-18 UTC  
**Tags:** Administration, Governance  

## Moderate Changes

- **Configure manager settings**
  
  Updated guidance removes the license requirement for managers; access is now based solely on the Minimum team size setting. Definitions, UI text, and troubleshooting were revised to eliminate licensing references, including removal of the “unlicensed manager” CSV error. This clarifies eligibility and reduces setup confusion for admins and managers.  
  https://learn.microsoft.com/en-us/viva/insights/advanced/setup-maint/manager-settings
