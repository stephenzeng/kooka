# Microsoft Teams
**Date created:** 2026-07-31 UTC  
**Tags:** Administration, Agent, Analytics, Monitoring, Security  

## New Articles

- **Security detections report in Microsoft Teams**

  Introduced a new article covering the Security detections report in the Teams admin center, used to investigate security detections in Teams communications. It explains how to access and run the report with date range selection and describes the chart (detection counts) and table (detection details). Guidance includes export behavior for charts and tables, highlighting additional investigation fields available only in CSV (for example, Sender MRI, Recipient email/ID, Thread ID). The article also clarifies key columns such as Detection date, sender/recipient details, detection types (Impersonation, Malicious URL, Weaponizable File), and how to interpret recipient actions for impersonation detections.

  https://learn.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/security-detections-report

## Moderate Changes

- **Setup - Authorized Users**

  Expanded the scope to include Teams Phone Agent, allowing authorized users to manage these agents in addition to Auto Attendant and Call Queue. Updated the title and definitions to clarify that authorized users can perform configuration changes for Teams Phone Agents, improving role clarity for administrators.

  https://learn.microsoft.com/en-us/microsoftteams/aa-cq-setup-authorized-users

- **New VDI solution for Teams**

  Updated VM-side screensharing guidance to add Amazon alongside Omnissa and Mac scenarios, and clarified preview notes. Added instructions for identifying outgoing screensharing sessions in Teams Admin Center and in CQD, improving monitoring and troubleshooting. Revised Amazon WorkSpaces support to indicate app sharing is now supported, while Share System Audio and screen sharing from chat remain unsupported.

  https://learn.microsoft.com/en-us/microsoftteams/vdi-2
