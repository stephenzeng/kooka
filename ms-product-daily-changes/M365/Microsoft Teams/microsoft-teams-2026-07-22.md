# Microsoft Teams
**Date created:** 2026-07-22 UTC  
**Tags:** Administration, Analytics  

## New Articles

- **Reporting - Historical Table Field Definitions**

  Introduced a comprehensive reference defining historical reporting fields for Teams Phone Agents, Auto Attendants, and Call Queues. Covers detailed tables for Auto Attendant Analytics, Cloud Call Queue Analytics (including target types and outcomes), CallQueueFinalStateAction, and Agent Timeline/Summary. Highlights identifiers, slicers, time fields (local/UTC), and legend codes to improve data interpretation and troubleshooting. Includes planning/licensing pointers and links to related real-time metrics and management guidance.

  https://learn.microsoft.com/en-us/microsoftteams/aa-cq-report-historical-table-field-definitions

## Major Changes

- **Reporting - Teams Phone Agent, Auto Attendant, and Call Queue historical reports**

  Released version 3.3.1 with preview support for Teams Phone Agent reporting and an option to display agent names instead of usernames in the desktop report. Added setup guidance to register an Entra ID app and update Power BI queries to show representative names, and standardized terminology to “representatives (agents).” Expanded analytics guidance for Teams Phone Agent (including locales and Per Call-only support), enhanced access control and data latency notes, and moved extensive field definitions to a dedicated reference article. Updated install steps and download references from V3.3.0 to V3.3.1 to streamline deployment.

  https://learn.microsoft.com/en-us/microsoftteams/aa-cq-report-historical

- **End of availability for classic Teams client**

  Updated the end-of-support date for the classic Teams client from July 1, 2025 to July 1, 2024. This accelerates the timeline for organizations to complete migration to the new Teams client. Administrators should expedite transition plans and support communications to avoid disruptions and ensure users remain on supported experiences.

  https://learn.microsoft.com/en-us/microsoftteams/teams-classic-client-end-of-availability

## Moderate Changes

- **Teams Rooms on Android certified devices**
