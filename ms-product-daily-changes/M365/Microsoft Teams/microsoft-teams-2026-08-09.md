# Microsoft Teams
**Date created:** 2026-08-09 UTC  
**Tags:** Administration  

## Moderate Changes

- **Overview of April 2026 licensing changes to Teams events**

  Clarified licensing for the Hide attendee names capability in Teams events, noting it isn’t available to Microsoft 365 Business or Frontline customers who purchased Teams Premium after March 31, 2026. Added footnotes and references in feature lists and tables to make the requirement for Microsoft 365 Enterprise explicit. This helps admins plan licensing to retain or enable this privacy feature.

  https://learn.microsoft.com/en-us/microsoftteams/events-features

- **Meetings and events feature and capacity comparison**

  Removed the Join verification check row from the comparison table to reflect current capabilities. The comparison now focuses on supported features, helping admins make accurate planning decisions.

  https://learn.microsoft.com/en-us/microsoftteams/meetings-events-feature-comparison

- **Plan for Teams events**

  Removed guidance for the Join verification check from the admin versus organizer controls table. Planning recommendations now reflect the current set of verification and access controls admins can use for events.

  https://learn.microsoft.com/en-us/microsoftteams/plan-events

- **Plan for Teams meetings**

  Removed the Join verification check entry from meeting policies and organizer controls. The planning guidance now emphasizes existing admission and verification options for anonymous participants.

  https://learn.microsoft.com/en-us/microsoftteams/plan-meetings
