# Microsoft Teams
**Date created:** 2026-07-18 UTC  
**Tags:** Administration  

## Moderate Changes

- **Teams Rooms certified systems and peripherals**

  Updated the certified hardware list to remove several Crestron Flex Intel NUC-based models and list them under End of Service/Life. This clarifies current certification status so admins can avoid new deployments on retired devices and plan hardware refreshes accordingly.

  https://learn.microsoft.com/en-us/microsoftteams/rooms/certified-hardware

- **Export options for switching from Microsoft Teams**

  Added export coverage for targeted messages and retained targeted messages, including corresponding file outputs and Microsoft Graph API endpoints (userTeamwork: getAllTargetedMessages and getAllRetainedTargetedMessages). This expands data portability and supports compliance and migration workflows.

  https://learn.microsoft.com/en-us/microsoftteams/migration-from-teams

- **New VDI solution for Teams**

  Added sizing guidelines for VM-side screen sharing, detailing CPU and memory impacts across 4K and 2K displays at different frame rates. Clarified the MaxFPS registry key to help control CPU usage. This guidance helps right-size VMs and optimize performance without GPUs.

  https://learn.microsoft.com/en-us/microsoftteams/vdi-2
