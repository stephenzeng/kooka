# Microsoft Teams
**Date created:** 2026-09-05 UTC  
**Tags:** Compliance, Configuration, Deprecation, Guidance, Licensing, Security  

## Moderate Changes

- **Reference - Supported Configurations**

  Updated supported configuration limits to cap Automatic Recording templates in specific sections and to define caps for Automatic and Compliance Recording templates elsewhere. Clarifies the maximum allowed template counts so admins can design compliant and predictable recording setups.

  https://learn.microsoft.com/en-us/microsoftteams/aa-cq-reference-limits-supported-configurations

- **Reference - Voice applications prerequisites and licensing**

  Added licensing sections for Automatic Recording (Teams Phone Agent and Call Queue) clarifying no additional Teams Phone licensing is required and pointing to the SharePoint service description. Introduced a Compliance Recording for Call Queue section highlighting third‑party licensing and linking to Teams third‑party compliance recording guidance. Reorganized content for clarity and removed a duplicate requirement reference.

  https://learn.microsoft.com/en-us/microsoftteams/aa-cq-reference-prerequisites-licensing

- **Teams Rooms certified systems and peripherals**

  Reclassified the DTEN D7X AI Board 55" from the Windows Core devices table to the Windows Touchboard Devices certified list. This aligns the device with its correct certification category and helps buyers find it in the appropriate list.

  https://learn.microsoft.com/en-us/microsoftteams/rooms/certified-hardware

- **What's new for Direct Routing**

  Added guidance noting the discontinuation of the testing endpoint for upcoming certificate changes and confirming production rollout of certificates from the new CA at the end of July 2026. Directs administrators to stop using the test endpoint and validate SBC TLS configurations against the production certificate chain.

  https://learn.microsoft.com/en-us/microsoftteams/direct-routing-whats-new
