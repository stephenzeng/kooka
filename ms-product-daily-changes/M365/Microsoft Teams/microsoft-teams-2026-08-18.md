# Microsoft Teams
**Date created:** 2026-08-18 UTC  
**Tags:** Automation, Best Practices, Configuration, Deprecation, Guidance  

## Major Changes

- **Manage Microsoft 365 with the Admin app in Microsoft Teams**
  
  Announced that the Admin app in Teams will be retired and unavailable starting October 2026. Guidance now directs admins to use Microsoft Admin Center, Teams Admin Center, and the M365 Admin Agent for administration. Content about prepinned behavior, rollout notes, and pin/unpin instructions was removed to reflect the deprecation and steer organizations to supported management tools.
  
  https://learn.microsoft.com/en-us/microsoftteams/manage-admin-app

- **Set up calendar syncing between Google Workspace and Microsoft Teams for your business**
  
  Announced deprecation of Google Workspace–Teams calendar syncing effective October 2026. The article now explains what’s changing and how admins should prepare, including notifying users, collecting account matching details, and adopting the Microsoft Teams Meeting add-on for Google Calendar. It also clarifies that custom domain management continues in Microsoft Admin Center and removes legacy setup, maintenance, troubleshooting, and FAQ guidance for the retired sync.
  
  https://learn.microsoft.com/en-us/microsoftteams/setup-calendar-syncing-with-google-workspace

## Moderate Changes

- **Setup - Call Queue**
  
  Updated the setup flow by introducing a dedicated Templates step and moving template assignment there, improving clarity and task separation. The sequence is renumbered, with Authorized users moved to the next step, and procedural guidance and What’s new notes were adjusted to match the new order.
  
  https://learn.microsoft.com/en-us/microsoftteams/aa-cq-setup-call-queue

- **Configure digital signage on Teams Rooms**
  
  Clarified requirements for custom web URLs used with digital signage: sites must allow iframe embedding, and content should be designed for the display size. Direct image links render at original dimensions, so admins should ensure assets are sized appropriately to avoid layout issues.
  
  https://learn.microsoft.com/en-us/microsoftteams/rooms/digital-signage

- **Microsoft Teams PowerShell Release Notes**
  
  Added the August 2026 7.9.1-preview entry with new parameters for appointment booking flows and auto attendant call flows, plus enhanced options for direct routing number upload orders. Introduced new cmdlets to manage spam detection templates for mainline attendants, expanding automation and configuration flexibility.
  
  https://learn.microsoft.com/en-us/microsoftteams/teams-powershell-release-notes

- **Teams Voice Agents integration**
  
  Standardized wording to “voice agents” throughout and updated the certification program name to “Teams Unify Integration Model for voice agents,” removing “coming soon” to reflect general availability. Introductory and support boundary text now aligns with the new program name and consistent terminology.
  
  https://learn.microsoft.com/en-us/microsoftteams/teams-voice-agents
