# Microsoft Teams
**Date created:** 2026-09-02 UTC  
**Tags:** Configuration, Guidance, Licensing  

## Major Changes

- **Country and region availability for Audio Conferencing and Calling Plans**
  
  Expanded documented availability for Teams Calling and Audio Conferencing to many additional countries and regions, while removing a small number of markets. This broadens service reach for customers planning new deployments and migrations. Administrators should review country eligibility, number procurement options, and licensing impacts based on the updated list. Organizations in removed markets should assess alternatives or adjust their telephony strategy.

  https://learn.microsoft.com/en-us/microsoftteams/calling-plan-overview

## Moderate Changes

- **Setup - Teams Phone Agent**
  
  Added guidance for integrating Appointments with Microsoft Bookings, including creating a shared booking page and a PowerShell example to enable the connection. Removed the AI disclaimer customization section and related PowerShell steps to streamline setup guidance and reflect current capabilities.

  https://learn.microsoft.com/en-us/microsoftteams/aa-cq-setup-teams-phone-agent

- **Setup - Teams Phone Agent Appointment tools**
  
  Expanded instructions for building Appointment tools using Microsoft Bookings, clarifying prerequisites and noting that configuration is currently PowerShell-only (with Teams admin center support coming). Introduced a separate path to create a custom Appointment tool, helping admins choose between Bookings-based and custom configurations.

  https://learn.microsoft.com/en-us/microsoftteams/aa-cq-setup-teams-phone-agent-tools-appointments

- **Teams Rooms on Android certified devices**
  
  Added GCCH-certified entries for Audiocodes RXV81, RX-Pad, and RXV200 with updated firmware and app version requirements. This helps government cloud deployments validate supported hardware and align device images to the required versions.

  https://learn.microsoft.com/en-us/microsoftteams/devices/certified-hardware-android
