**Date created:** 2026-08-21 UTC  
**Tags:** Configuration  

## Moderate Changes

- **OneDrive Sync Release Notes**

  Added self-service file exclusions for users with work or school accounts, giving users more control over what syncs. Introduced new admin policies—DisableChangesToODIgnoreList, DisableDefaultODIgnoreList, and EnableODIgnoreFolders—to manage user controls, opt out of the default exclusion list, and exclude specific folders, improving governance and flexibility. Clarified eligibility for Copilot Actions and Local Network Access Support to explicitly reflect work or school accounts and Microsoft 365 Copilot licensing.
