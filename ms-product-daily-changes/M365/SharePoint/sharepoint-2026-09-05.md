## Moderate Changes

- **Change a specific user's OneDrive storage space**

  Added an important clarification that tenants with Microsoft 365 OneDrive Storage enabled can set an individual user’s OneDrive quota above the license-included amount, with a link to acquire additional storage. This helps admins confidently configure higher limits when capacity is available and understand how to obtain it. Other edits were formatting only.

  https://learn.microsoft.com/en-us/sharepoint/change-user-storage
