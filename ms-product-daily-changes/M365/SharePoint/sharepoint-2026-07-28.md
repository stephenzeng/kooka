- **OneDrive Sync Release Notes**

  Updated guidance to note that the OneDrive sync app will only receive updates on Windows 10 22H2 or Windows 11. Clarifies that devices on earlier Windows 10 versions will stop receiving new releases after August 15, 2026, prompting admins to plan OS upgrades to maintain feature and security updates. Adds a reference to the OneDrive system requirements for detailed compatibility information.
