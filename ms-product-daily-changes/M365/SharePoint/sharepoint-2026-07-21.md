# SharePoint
**Date created:** 2026-07-21 UTC  
**Tags:** Administration, Security  

## Moderate Changes

- **Restrict SharePoint site access with Microsoft 365 groups and Microsoft Entra security groups**
  Clarified that restricted access control (RAC) set on team-connected sites does not carry over to shared or private channel sites and must be configured separately. Updated guidance explains that external participants in shared channel sites are not evaluated against RAC and remain governed by Teams/channel permissions, details default RAC behavior for Microsoft 365 group–connected sites, and notes that nested security groups are supported when the opt-in sharing restriction is enabled. Terminology was standardized to consistently refer to the feature as restricted access control.
  https://learn.microsoft.com/en-us/sharepoint/restricted-access-control

- **OneDrive for Business Storage Quota Bug Fixes FAQ**
  Updated education licensing guidance to remove the prior reference to up to 25 TB and confirm a 5 TB OneDrive limit for licenses that include the SharePoint (Plan 2) for Education service plan. Admins can still assign lower per-user quotas as needed.
  https://learn.microsoft.com/en-us/sharepoint/site-storage-overquota-enforcement-faq
