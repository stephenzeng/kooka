# Microsoft 365
**Date created:** 2026-07-18 UTC  
**Tags:** Administration, Agent  

## Moderate Changes

- **Set up Microsoft 365 Backup**

  Updated billing setup with a new pay-as-you-go onboarding path for customers after April 1, 2026, plus a guided migration for existing tenants from Org Settings to the new Billing experience without service interruption. Added recommendations for Departmental Billing to allocate consumption across multiple Azure subscriptions with budget alerts and streamlined creation of subscriptions/resource groups; terminology updated to Departmental Billing Experience and an outdated GCC note was removed.

  https://learn.microsoft.com/en-us/microsoft-365/backup/backup-setup?view=o365-worldwide

- **Set up Frontline Agent for frontline workers**

  Expanded guidance to highlight answers from standard operating procedures, voice-driven site walkthroughs, and manager-led information gathering. Clarified availability for users with a Microsoft 365 Copilot license. Added scenarios for manager follow-ups with automated reminders and summaries, and for completing checklists by voice with options to share results.

  https://learn.microsoft.com/en-us/microsoft-365/frontline/setupfrontlineagent?view=o365-worldwide
