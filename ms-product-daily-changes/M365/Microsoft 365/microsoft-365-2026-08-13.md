# Microsoft 365
**Date created:** 2026-08-13 UTC  
**Tags:** Configuration, Guidance, Governance, Identity, Security  

## Major Changes

- **Understand Microsoft 365 support case creation and data access**

  Updated guidance clarifies end-to-end support case flow and required permissions. Introduced a requirement to create a cross-tenant access policy between the customer tenant and the Microsoft Support tenant, with creation limited to Global Administrator, Security Administrator, or Teams Administrator roles. Clarified that the policy is scoped to the Microsoft Support tenant and the Microsoft 365 Support Engineer role, and detailed how related events appear in Microsoft Entra audit logs. Restructured role guidance to distinguish roles that can create both the support case and the cross-tenant policy from roles that can only open a case, improving governance and auditability.

  https://learn.microsoft.com/en-us/microsoft-365/admin/support-diagnostic-information-collection?view=o365-worldwide

## Moderate Changes

- **Manage and monitor priority accounts**

  Added guidance on “Priority feedback in Copilot Chat” to ensure feedback from priority users is triaged faster. Recommended enabling policies that allow feedback submission with logs and content samples to improve diagnostics and response quality.

  https://learn.microsoft.com/en-us/microsoft-365/admin/security-and-compliance/priority-accounts?view=o365-worldwide
