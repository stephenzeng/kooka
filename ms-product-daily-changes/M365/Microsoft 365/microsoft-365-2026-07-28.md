# Microsoft 365
**Date created:** 2026-07-28 UTC  
**Tags:** AI, Administration, Agent  

## Major Changes

- **Online service activation for Open programs (volume licensing)**

  Overhauled activation guidance to streamline the end-to-end process for Open program keys. Clarified roles and responsibilities for Primary/Notices contacts and Global/Billing admins, including volume licensing role requirements. Updated admin center steps to validate prepopulated product key, product name, and quantity, and introduced clear redemption options: extend an existing subscription by 12 months, add licenses without changing the end date, or create a new subscription. Added detailed procedures for each path, including handling payment flow for prepaid keys and finalizing redemption steps. Introduced instructions for activating services on a new tenant using the setupbusiness flow, while retaining notes on license availability timing.

  https://learn.microsoft.com/en-us/microsoft-365/commerce/licenses/online-service-activation-open-programs?view=o365-worldwide

## Moderate Changes

- **Get started with the Microsoft Copilot Frontier Program**

  Added a clarification on agent availability: starting March 29, 2026, newly published Frontier agents are limited to users enrolled in the Frontier program. Agents published before this date remain accessible to users with a Microsoft 365 Copilot license. This helps admins set expectations for access and plan enrollment accordingly.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/get-started-frontier?view=o365-worldwide
