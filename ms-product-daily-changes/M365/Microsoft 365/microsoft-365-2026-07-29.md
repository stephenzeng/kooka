# Microsoft 365
**Date created:** 2026-07-29 UTC  
**Tags:** AI, Administration, Agent, Analytics, Governance, Monitoring  

## Moderate Changes

- **Add more OneDrive and SharePoint storage to your Microsoft 365 subscription**

  Updated availability details for the Microsoft 365 OneDrive Storage public preview: it’s now limited to commercial customers and not available to education, GCC, or Microsoft 365 operated by 21Vianet in China. This helps admins set correct expectations and avoid pursuing unsupported scenarios.

  https://learn.microsoft.com/en-us/microsoft-365/commerce/add-storage-space?view=o365-worldwide

- **Place a mailbox on litigation hold**

  Revised the Recoverable Items folder quota guidance under litigation hold: 100 GB by default, or 110 GB when auto-expanding archiving is enabled (previously a fixed 110 GB). This clarifies capacity planning and ensures compliance configurations reflect current limits.

  https://learn.microsoft.com/en-us/microsoft-365/admin/misc/create-litigation-hold-mac?view=o365-worldwide

- **Microsoft 365 Copilot Agent usage report**

  Marked the original Microsoft 365 Copilot Agent usage report as deprecated and directed admins to the newer agent report. Removed outdated notes about future data sources and prior availability messaging, helping readers transition to the current reporting experience.

  https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-365-copilot-agents?view=o365-worldwide

- **Microsoft 365 Copilot Agents usage report**

  Removed preview status and related notes to reflect general availability and updated terminology for consistency (for example, “Third-party” and “Your Users”). Clarified that “Responses sent to users” is measured per-user, per-agent and added an FAQ stating Cowork usage is excluded and covered in a separate report. These changes make metrics easier to interpret and guide admins to the right report for Cowork insights.

  https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-365-copilot-agents-new?view=o365-worldwide

- **Set up and manage pay-as-you-go billing in the Billing node of the Microsoft 365 admin center**

  Added Microsoft 365 OneDrive Storage to the list of services that support pay-as-you-go billing. This enables more flexible cost management for storage consumption.

  https://learn.microsoft.com/en-us/microsoft-365/commerce/services/pay-as-you-go-setup-billing-node?view=o365-worldwide
