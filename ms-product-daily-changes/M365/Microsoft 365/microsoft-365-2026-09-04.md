# Microsoft 365
**Date created:** 2026-09-04 UTC  
**Tags:** Compliance, Configuration, Governance, Security  

## New Articles

- **Data Residency for Microsoft 365 Copilot Offerings**

  Introduced comprehensive guidance on where Microsoft 365 Copilot and Copilot Chat interaction data is stored at rest. Clarifies Product Terms eligibility by tenant region, ADR prerequisites and commitments, and how Multi-Geo with Preferred Data Location determines storage geography. Explains migration behaviors and user experience impacts as interaction history aligns with ADR and Teams guidance. Provides steps for admins to verify actual data location in the Microsoft 365 admin center.

  https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-service-copilot-offerings?view=o365-worldwide

## Major Changes

- **Data Residency for Microsoft 365 Copilot (including Cowork)**

  Rewrote and retitled the article to focus on Microsoft 365 Copilot (including Cowork) with a clear, scoped alignment to the Product Terms. Added a dedicated section for Copilot Cowork that commits interaction content at rest for tenants with Default Geography in specified countries/regions, improving clarity on data location promises. Clarified that workspace files and custom skills are stored under OneDrive/SharePoint Embedded commitments and that the guidance applies to all tenants, including those with ADR and Multi-Geo. Streamlines the document by removing legacy sections, making it easier for admins to understand residency commitments and plan governance.

  https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-service-copilot?view=o365-worldwide

## Moderate Changes

- **Agent settings in Microsoft 365 admin center**

  Added a new governance action, “Apply a template to agents,” enabling bulk application of security policies to existing registry agents. Clarifies scope (not for agent blueprints or AI teammates) and that the action runs as a one-time operation, with updated UI guidance and criteria selection steps.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-settings?view=o365-worldwide
