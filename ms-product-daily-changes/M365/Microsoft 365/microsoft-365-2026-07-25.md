# Microsoft 365
**Date created:** 2026-07-25 UTC  
**Tags:** Administration, Governance  

## Major Changes

- **Deploy the Microsoft 365 LTI® app in Canvas**

  Added comprehensive guidance for bulk course migrations using the OneDrive Migration Tool, including CSV-based uploads of Canvas Course IDs, verification steps, viewing results, and a limit of 50 courses per run. Clarified required roles and permissions for both single and bulk migrations, including LTI Management Add/Delete and eligible roles such as Canvas admins, Teachers, Designers, and TAs with LTI Instructor access. Expanded tool description to cover LMS admin usage and CSV-driven workflows, helping institutions streamline large-scale transitions. Noted the retirement alignment of the migration tool with the classic OneDrive LTI on September 17, 2026, so organizations can plan timelines accordingly.

  https://learn.microsoft.com/en-us/microsoft-365/lti/microsoft-365-lti-canvas?view=o365-worldwide

## Moderate Changes

- **Agent Requests in Microsoft 365 Admin Center**

  Updated guidance on how admins process installation requests for Microsoft-built agents blocked by policy, including where these requests appear and how to filter for items in the “Allow user to install” state. Clarified how to review requesters under “Requested from” and the steps required to unblock an agent before approving or rejecting, improving oversight and approval workflows.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-requests?view=o365-worldwide

- **Overview of Product Terms Data Residency**

  Clarified data residency commitments and scope for Office 365 services by specifying SharePoint Online and OneDrive (work/school), and confirming inclusion of Microsoft Stream (Classic) (on SharePoint) meeting recordings. Added a carve-out referencing data residency for Microsoft 365 Copilot and Copilot Chat, helping customers understand coverage and exceptions for compliance planning.

  https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-product-terms-dr?view=o365-worldwide
