# Microsoft 365
**Date created:** 2026-08-09 UTC  
**Tags:** Administration, Governance, Monitoring, Security  

## Major Changes

- **Review and sign a signature request in eSignature**
  
  Updated signing guidance to support both typed and drawn signatures, including font selection and ink color options. Clarified that email notifications are sent by the provider when requests originate from Adobe Acrobat Sign or DocuSign integrations. Revised storage behavior so signed documents are automatically copied back to the original folder with the provider name, “signed,” and timestamp appended; if a copy-back isn’t possible, files are saved to a provider-specific Apps/Signed documents/provider path in SharePoint. These changes improve signers’ experience, strengthen traceability, and clarify where finalized documents are stored while maintaining existing retention policy inheritance.

  https://learn.microsoft.com/en-us/microsoft-365/documentprocessing/esignature-review-sign-requests?view=o365-worldwide

## Moderate Changes

- **Overview of eSignature**
  
  Updated the Purview Audit activities to reflect current events: removed “Request has expired” and “Signed document link was sent to the recipient,” added “Link to the signed document has expired,” and refined download wording to “Document was downloaded by recipient.” These adjustments improve audit accuracy and help admins build reliable queries and alerts based on consistent event names.

  https://learn.microsoft.com/en-us/microsoft-365/documentprocessing/esignature-overview?view=o365-worldwide

- **Special considerations for Teams events in VPN environments**
  
  Updated DNS host patterns required for Teams Town hall and live events, adding new Commercial hosts and replacing legacy government cdn patterns with new government domains and notes. Adjusted the Get-TeamsEventsConfiguration PowerShell function to return the new government domains and expanded the default include list. These changes help ensure reliable connectivity and correct configuration for live events behind VPNs.

  https://learn.microsoft.com/en-us/microsoft-365/enterprise/microsoft-365-vpn-stream-and-live-events?view=o365-worldwide
