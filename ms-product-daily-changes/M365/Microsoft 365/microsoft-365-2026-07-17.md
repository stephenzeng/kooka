# Microsoft 365
**Date created:** 2026-07-17 UTC  
**Tags:** Administration, Analytics  

## Moderate Changes

- **Frequently asked questions about Microsoft 365 Archive**
  Updated the FAQ to reflect general availability of file-level archive, now enabled by default when Microsoft 365 Archive is on, with an admin opt-out via PowerShell. Removed preview prerequisites and timelines, and clarified that file-level archive remains SharePoint-only and doesn’t reduce site or tenant storage usage.
  https://learn.microsoft.com/en-us/microsoft-365/archive/archive-faq?view=o365-worldwide

- **Manage Microsoft 365 Archive**
  Updated management guidance to reflect general availability by removing “preview” references and aligning steps with default-on file-level archiving for SharePoint when Microsoft 365 Archive is enabled. Adjusted procedures for archiving and reactivating files to match the new default behavior.
  https://learn.microsoft.com/en-us/microsoft-365/archive/archive-manage?view=o365-worldwide

- **Factory reset protection (FRP) enforcement behavior for Android Enterprise**
  Revised COPE behavior to clarify that FRP isn’t enforced when a device is reset via Settings > Factory data reset as of July 2026. Enforcement remains for recovery/bootloader resets, and Intune wipe continues to be not enforced.
  https://learn.microsoft.com/en-us/troubleshoot/mem/intune/device-configuration/factory-reset-protection-emails-not-enforced

- **Microsoft 365 Copilot Chat usage report**
  Clarified that Copilot activity data typically appears within 48 hours after the end of the day (UTC). Updated the reporting period option from 30 days to 28 days in the filter.
  https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-copilot-usage?view=o365-worldwide
