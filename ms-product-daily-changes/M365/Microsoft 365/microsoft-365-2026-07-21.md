# Microsoft 365
**Date created:** 2026-07-21 UTC  
**Tags:** Administration, Analytics  

## Moderate Changes

- **Organizational messages in the Microsoft 365 admin center**

  Updated guidance to reflect the removal of email open tracking for Organizational Messages worldwide. New open count metrics will no longer be generated, so admins should adjust reporting and measurement practices accordingly. Previously collected open count data remains available for reference.

  https://learn.microsoft.com/en-us/microsoft-365/admin/misc/organizational-messages-microsoft-365?view=o365-worldwide
