# Microsoft 365
**Date created:** 2026-08-07 UTC  
**Tags:** Administration, Agent, Governance  

## Major Changes

- **Agent settings in Microsoft 365 admin center**

  Added Agent feedback sharing and centralized Tags management to Agent settings. Feedback sharing now supports configurable scopes (No agents, All agents, Selected agents) with step-by-step setup to control visibility of user feedback. Tags can be created, described, filtered, and deleted centrally with a limit of 50, improving consistency and governance. Guidance across Agent management rules, allowed types, sharing, and user access was refined for clearer administration without changing existing functionality.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-settings?view=o365-worldwide

## Moderate Changes

- **Understand agent details in Microsoft 365 admin center**

  Added guidance on tagging agents directly from the agent details pane to improve organization and discovery. Tags now appear on the agent page and list with filtering support, and available tag options are governed centrally in Agent settings.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-details?view=o365-worldwide
