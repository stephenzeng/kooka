# Microsoft 365
**Change date:** 2026-08-07 UTC  
**Tags:** Administration  

## Moderate Changes

- **Microsoft 365 admin center usage reports overview**

  Updated the Reports settings guidance to instruct admins to uncheck “Conceal user, group, and site names in all reports” to reveal identities in usage reports. This clarifies the control’s behavior and reduces confusion, helping admins quickly display the necessary details for monitoring and auditing.

  https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/activity-reports?view=o365-worldwide

- **Enriching and customizing your organization's profile cards**

  Revised placement information for configured profile card properties from the Contact tab to the Profile tab. Expanded supported surfaces to include Outlook on the web, Outlook for Windows, Teams, the Microsoft 365 Copilot app, and the People Companion app, increasing visibility where users work.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/customize-profile-cards?view=o365-worldwide
