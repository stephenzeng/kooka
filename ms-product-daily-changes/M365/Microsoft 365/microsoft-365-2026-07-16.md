# Microsoft 365
**Date created:** 2026-07-16 UTC  
**Tags:** Administration, Agent, Analytics, Governance, Security  

## New Articles

- **Understand Local Agents in Microsoft 365 admin center**

  Introduced a new preview experience to discover, monitor, and govern unmanaged developer-focused AI agents within the admin center. The article outlines prerequisites (Microsoft 365 E3, required admin roles, Intune enrollment, Frontier preview opt-in, and optional Global Secure Access for richer telemetry). It details how to access the Local Agents page, view agent details and telemetry (first accessed, detections, activity, traffic), and see detected devices with model, OS, and last seen. It also lists detectable agents during preview, including desktop tools and VS Code extensions, and links to related Shadow AI guidance.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-local?view=o365-worldwide

- **Cowork usage report**

  Added documentation for the Cowork usage report, explaining where to find it in the admin center and how to use the Overview and Usage tabs. The article defines key metrics (Active Cowork users, Total tasks, Average tasks, Retained users) and provides guidance for monitoring grace periods for usage-based billing and managing actionable items such as access requests and plugins. It covers adoption charts, user-level columns for detailed analysis, and how to export usage data as CSV for further reporting.

  https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/cowork-usage-report?view=o365-worldwide

## Major Changes

- **Shadow AI in Microsoft 365 admin center (Preview)**

  Expanded capabilities and clarified requirements for Shadow AI, including an updated licensing prerequisite to Microsoft 365 E5 and a requirement to enable Global Secure Access to populate usage metadata. Detection now spans multiple agents (for example, ChatGPT Desktop, Ollama Desktop, Poe Desktop, Claw variants, OpenCode, Claude Desktop), with blocking currently limited to OpenClaw on Intune-managed Windows devices. Navigation and workflows were streamlined, and the agent details pane was significantly enhanced with new tiles, fields, and traffic metrics. These changes help admins improve visibility, standardize policy application, and focus on higher-risk unmanaged agents.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-shadow-ai?view=o365-worldwide

- **Create, view, and edit backup policies in Microsoft 365 Backup**

  Introduced Full Workload Backup for SharePoint, Exchange, and OneDrive to automatically protect all eligible items not already covered by other policies. The update adds selection options to back up all items per workload, explains policy precedence and 24-hour checks for new items, and provides guidance to enable or turn off Full Workload Backup. It also documents exclusion management, including CSV-based bulk exclusions for up to 10,000 units, and clarifies behavior when items are removed from custom or Full Workload policies. Marked as a preview, this expansion simplifies protection at scale and reduces coverage gaps.

  https://learn.microsoft.com/en-us/microsoft-365/backup/backup-view-edit-policies?view=o365-worldwide

- **Microsoft 365 Copilot usage report**

  Removed all agent-related content, including the Active agent users metric, the Agent adoption section and charts, and agent feature interaction tables, aligning the report with current Copilot measurement scope. Data latency was improved from 72 to 48 hours to accelerate insights. Timeframe filters were updated to 7, 28, 90, and 180 days, and the “Last activity date of any agent (UTC)” field was removed, streamlining available fields and focusing on core Copilot usage.

  https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-365-copilot-usage?view=o365-worldwide

## Moderate Changes

- **Microsoft 365 admin center usage reports overview**

  Added a new entry for the Cowork usage report to the available reports table, indicating availability (Yes for WW Commercial; No for other environments). This helps admins quickly discover and access the new Cowork insights from the reports catalog.

  https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/activity-reports?view=o365-worldwide

- **Enable room discovery capability with newly supported attributes (Private Preview)**

  Clarified that the Private Preview focuses on GAL-based cross-tenant room discovery and expanded terminology to spell out Global Address List. Updated setup guidance to synchronize room objects (not users) from the MTO admin portal, improving accuracy for cross-tenant room visibility.

  https://learn.microsoft.com/en-us/microsoft-365/enterprise/enable-cross-tenant-room-discovery-for-mto?view=o365-worldwide
