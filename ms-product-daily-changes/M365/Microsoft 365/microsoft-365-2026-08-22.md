# Microsoft 365
**Date created:** 2026-08-22 UTC  
**Tags:** Billing, Compliance, Configuration, Deprecation, Governance, Guidance, Licensing, Security, Troubleshooting  

## Major Changes

- **Offboarding in Microsoft 365 Backup**

  Clarified that backup retention is defined as a configurable recovery window governed by backup policy, defaulting to one year instead of a fixed, nonvariable period. This update standardizes terminology and highlights administrators’ ability to set the window to meet business or regulatory needs. The change helps align offboarding expectations with policy-driven recovery behavior.

  https://learn.microsoft.com/en-us/microsoft-365/backup/backup-offboarding?view=o365-worldwide

- **Create, view, and edit backup policies in Microsoft 365 Backup**

  Introduced a configurable Recovery window (3 months, 6 months, 1 year, or 2 years) replacing fixed retention references. Added guidance on increasing the window immediately, reducing it with a 30-day grace period, and preserving the last applied window for removed items. Clarified that backup frequency remains non-modifiable and updated examples across Exchange and OneDrive to use the new terminology. Streamlined Exchange mailbox selection steps by removing unnecessary notes and sub-steps to simplify policy setup.

  https://learn.microsoft.com/en-us/microsoft-365/backup/backup-view-edit-policies?view=o365-worldwide

- **Contact volume licensing support**

  Updated steps to explicitly include the VL agreement number when opening a support request and added an IMPORTANT note for cases where “Product” and “Problem Type” appear in another language. Removed Japan-specific phone support details and announced that starting August 2026 all VL support requests must be submitted online, with phone numbers discontinued. The change emphasizes improved security and AI-driven support capabilities and sets clear expectations for future contact methods.

  https://learn.microsoft.com/en-us/microsoft-365/commerce/licenses/contact-vl-support?view=o365-worldwide

## Moderate Changes

- **Overview of Microsoft 365 Backup**

  Replaced “Retention period” with a configurable “Recovery window” (3 months, 6 months, 1 year, or 2 years), with existing policies defaulting to one year. Updated OneDrive and SharePoint recovery points to a 10-minute RPO for two weeks and weekly snapshots for weeks 2–52. Clarified that Purview retention or deletion policies don’t affect the backup recovery window, reinforcing isolation from live-data governance.

  https://learn.microsoft.com/en-us/microsoft-365/backup/backup-overview?view=o365-worldwide

- **Privacy, security, and compliance in Microsoft 365 Backup**

  Clarified that backups are governed by a configurable recovery window set in the backup policy, defaulting to one year. Reaffirmed that once data is restored to live workloads, it remains subject to applicable retention or deletion policies.

  https://learn.microsoft.com/en-us/microsoft-365/backup/backup-privacy-security?view=o365-worldwide

- **Restore data in Microsoft 365 Backup**

  Updated terminology from “retention period” to “recovery window” across restore scenarios and removed fixed “365-day” language. Added guidance for restoring users deleted within the past 30 days via the Microsoft 365 admin center; once restored, the user reappears in the Backup restore experience and the flow continues normally.

  https://learn.microsoft.com/en-us/microsoft-365/backup/backup-restore-data?view=o365-worldwide

- **Known issues for Windows 365 Business Cloud PC**

  Added a known issue: Administrator protection isn’t supported on Windows 365 Business Cloud PCs, which can cause extra prompts or elevation failures. Recommended setting “User Account Control: Configure type of Admin Approval Mode” to “Legacy Admin Approval Mode” and restarting the Cloud PC, with guidance for adjusting admin rights in the Microsoft 365 admin center. If enrolled in Intune, use an assignment filter to exclude these Cloud PCs from policies enabling Administrator protection.

  https://learn.microsoft.com/en-us/troubleshoot/windows-365/known-issues

- **Online service activation for Open programs (volume licensing)**

  Expanded prerequisites to allow Billing Admins, in addition to Global Admins, to activate OSA keys, and clarified that a VL role is required to view keys. Updated UI references from “Manage activation” to “Start activation” to match the current experience.

  https://learn.microsoft.com/en-us/microsoft-365/commerce/licenses/online-service-activation-open-programs?view=o365-worldwide

- **Resize a Windows 365 Business Cloud PC**

  Added a note explaining that the Resize action may be unavailable if the assigned Windows 365 license is in a warning or grace state. Because resizing temporarily unassigns and reassigns licenses, an active license is required; restore the license to an active state (renew/replace the subscription or assign a healthy license of the current size) before retrying.

  https://learn.microsoft.com/en-us/troubleshoot/windows-365/resize-windows-365-business-cloud-pc
