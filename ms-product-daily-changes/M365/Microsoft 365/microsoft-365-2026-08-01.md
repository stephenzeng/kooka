# Microsoft 365
**Date created:** 2026-08-01 UTC  
**Tags:** Analytics, Governance  

## Moderate Changes

- **Microsoft 365 admin center usage reports overview**

  Updated the availability matrix so Microsoft 365 Copilot usage is now available in GCC and GCC High, and Microsoft 365 Copilot Chat usage is now available in Enterprise, GCC, and GCC High; both remain unavailable in DoD. This enables admins in newly supported clouds to track Copilot adoption and usage trends to guide rollout and governance plans.

  https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/activity-reports?view=o365-worldwide

- **Advanced Data Residency in Microsoft 365**

  Expanded ADR eligibility by adding Microsoft 365 A3 and A5, and Office 365 A1, A3, and A5 to the supported licenses. More organizations can now qualify for ADR, helping them meet data residency and compliance requirements.

  https://learn.microsoft.com/en-us/microsoft-365/enterprise/advanced-data-residency?view=o365-worldwide
