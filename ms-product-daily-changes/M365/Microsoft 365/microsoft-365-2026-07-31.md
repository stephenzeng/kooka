# Microsoft 365
**Date created:** 2026-07-31 UTC  
**Tags:** Administration, Agent, Governance, Monitoring  

## Major Changes

- **Manage tools for agents in Microsoft 365 admin center**

  Added capabilities to upload and manage plugins and skills in the Microsoft 365 admin center using manifest packages. Management actions are unified across plugins and skills (install, uninstall, block, unblock) with a new delete option and detailed admin workflows for each. Introduced visibility into Power Platform connector usage by agents, with navigation to the Power Platform admin center for policy governance. Editorial refinements improve clarity and consistency.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/manage-tools-for-agent?view=o365-worldwide

## Moderate Changes

- **Overview of Microsoft 365 Backup**

  Clarified recovery point options by introducing “express” restore points for OneDrive and SharePoint, including typical cadence and when to use them; confirmed Exchange Online does not use express points. Updated performance guidance to median-based expectations with dependencies on item count and data size, overhauled the table, and specified mailbox throughput ranges. Guidance now recommends express points for small site restores, removes preview labels from granular restores, and sets clearer expectations for large-scale recoveries.

  https://learn.microsoft.com/en-us/microsoft-365/backup/backup-overview?view=o365-worldwide

- **Restore a deleted Microsoft 365 group**

  Added an operational note to wait at least one hour after restoring a Microsoft 365 group before emailing it to avoid NDR 550 5.1.10 errors. Consolidated the full-restore timeline (up to 24 hours) into a single note near the PowerShell section to streamline guidance.

  https://learn.microsoft.com/en-us/microsoft-365/admin/create-groups/restore-deleted-group?view=o365-worldwide

- **SharePoint Site usage report**

  Replaced the prior request process with a new aka.ms link to enable site URL display when BYOK or Customer Lockbox is enabled, with fallback instructions to open a support ticket. Removed the previous timeline note; PowerShell alternative remains unchanged.

  https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/sharepoint-site-usage-ww?view=o365-worldwide
