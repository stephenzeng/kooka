# Microsoft 365
**Date created:** 2026-09-02 UTC  
**Tags:** Analytics, Compliance, Configuration, Guidance, Identity, Monitoring  

## New Articles

- **Microsoft Planner usage reports - Microsoft 365**

  Introduced a new article that explains how to access and interpret the Microsoft Planner usage report in the admin center, including supported time periods and key metrics. Clarifies what counts as active usage across Planner experiences and which background or service actions are excluded, helping admins measure meaningful engagement. Details the per-user table behavior (active days scoped by the selected period and last activity date, listing users active in the last 180 days), along with options to export data to CSV and choose columns. Provides steps to anonymize user data and notes that coverage is for commercial accounts, with Planner Agent usage reflected in the Microsoft 365 Copilot Agents report.

  https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/planner-activity?view=o365-worldwide

## Moderate Changes

- **Microsoft 365 admin center usage reports overview**

  Added Planner activity to the availability table, clarifying where the report is supported across environments. This helps admins confirm reporting coverage and plan adoption and monitoring accordingly.

  https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/activity-reports?view=o365-worldwide

- **Compliance features in Microsoft 365 Archive**

  Clarified how archived files interact with the Preservation Hold Library under retention settings: archived items move to PHL per policy, remain archived while in PHL, and can be reactivated. This ensures admins understand preservation behavior and continue to meet retention requirements without losing archive status.

  https://learn.microsoft.com/en-us/microsoft-365/archive/archive-compliance?view=o365-worldwide

- **Prepare for directory synchronization to Microsoft 365**

  Updated userPrincipalName character rules by marking the “#” character as invalid and adjusting the allowed/invalid lists. Admins should remove or avoid “#” in UPNs to prevent synchronization issues and ensure compliant identity configuration.

  https://learn.microsoft.com/en-us/microsoft-365/enterprise/prepare-for-directory-synchronization?view=o365-worldwide
