# Microsoft 365
**Date created:** 2026-08-06 UTC  
**Tags:** Administration, Governance  

## New Articles

- **Use eDiscovery with Copilot Pages**

  Introduced step-by-step guidance for using Microsoft Purview eDiscovery with Copilot Pages, including how .page files are stored and shared across SharePoint, OneDrive, and SharePoint Embedded. Provides procedures to locate a user’s SharePoint Embedded container, add it as a data source to a case, search and collect content, and review or export Pages (including HTML export and Graph format conversion). Clarifies how version history, holds, sensitivity labels, and encryption (including RMS Decrypt role) affect discovery and review. Explains how Copilot interactions are captured and surfaced across Purview solutions to support investigations and compliance.

  https://learn.microsoft.com/en-us/microsoft-365/loop/copilot-pages-ediscovery?view=o365-worldwide

## Major Changes

- **Virtual Appointments with Teams - Integration into Epic EHR**

  Removed the SMS notifications configuration and the statement that patients can join via SMS, along with related steps, certificates, and navigation references. Updated the guidance to clearly indicate that new customer onboarding is currently paused, with a contact email provided in key locations for inquiries. These changes set expectations about supported join methods and help admins avoid relying on deprecated SMS workflows.

  https://learn.microsoft.com/en-us/microsoft-365/frontline/ehr-admin-epic?view=o365-worldwide

## Moderate Changes

- **Adoption Score Organizational Messages in Microsoft 365**

  Updated delivery surfaces to remove Windows endpoints, focusing message delivery on Outlook, Excel, PowerPoint, Word, and Teams. This helps admins plan campaigns where users are most likely to see messages and avoid relying on Windows notifications.

  https://learn.microsoft.com/en-us/microsoft-365/admin/adoption/organizational-messages?view=o365-worldwide

- **Set up and manage pay-as-you-go billing in the Copilot node of the Microsoft 365 admin center**

  Updated navigation to direct admins to Copilot > Cost management and to access Classic Billing & usage from the banner, reflecting the current admin center layout. Temporarily hid the how-to video while the UI relocates, ensuring steps remain accurate during the transition.

  https://learn.microsoft.com/en-us/microsoft-365/commerce/services/pay-as-you-go-setup-copilot?view=o365-worldwide
