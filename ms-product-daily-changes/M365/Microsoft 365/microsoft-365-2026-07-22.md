# Microsoft 365
**Date created:** 2026-07-22 UTC  
**Tags:** Administration  

## Moderate Changes

- **Engagements in Enhanced Engagements**

  Updated guidance introduces a Nudge Status section that tracks nudges through clear stages (Initiated, Acknowledged, Actioned). It adds visibility into who last nudged and when, improving transparency and accountability for follow-through.

  https://learn.microsoft.com/en-us/microsoft-365/enterprise/microsoft-365-admin-engagements?view=o365-worldwide

- **Windows 365 Boot known issues**

  Streamlined the camera permissions troubleshooting steps by removing the need to uninstall Windows 365 Boot. Users can now enable camera access for Azure Virtual Desktop (HostApp) directly and then re-add Windows 365 Boot, reducing disruption and speeding resolution.

  https://learn.microsoft.com/en-us/troubleshoot/windows-365/windows-365-boot-known-issues
