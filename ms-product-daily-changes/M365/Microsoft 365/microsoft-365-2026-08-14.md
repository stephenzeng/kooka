# Microsoft 365
**Date created:** 2026-08-14 UTC  
**Tags:** Billing, Configuration, Deprecation, Guidance, Monitoring, Security  

## Major Changes

- **Manage and monitor priority accounts**
  Added a comprehensive benefits section that maps priority account features (including Defender for Office 365 filters, priority protection, Exchange Online monitoring, Premium Mail Flow Monitoring, and priority feedback in Copilot Chat) to their requirements. Expanded management guidance with clear, step-by-step workflows for both the Microsoft 365 admin center and the Microsoft Defender portal, and clarified removal and import processes. Consolidated duplicate content and strengthened least-privilege guidance to reduce admin risk. Clarified monitoring prerequisites such as licensing and monthly active user thresholds and explained the resulting monitoring capabilities and scenarios.
  https://learn.microsoft.com/en-us/microsoft-365/admin/security-and-compliance/priority-accounts?view=o365-worldwide

## Moderate Changes

- **Requirements for Loop components and Loop workspaces**
  Updated the availability matrix to separate Sovereign cloud coverage into Bleu and Delos and refined product-specific availability, including OneNote (Win32 and web). Added a deprecation note that Word for the web no longer renders Loop components as of September 1, 2025; existing components display as read-only placeholders that link to open externally.
  https://learn.microsoft.com/en-us/microsoft-365/loop/loop-requirements?view=o365-worldwide

- **Manage ownerless Microsoft 365 groups and teams**
  Added guided methods to identify and remediate ownerless groups directly in the Microsoft 365 admin center and the Exchange admin center, with step-by-step instructions and visuals. Retained and reorganized the Microsoft Purview audit log approach to provide an additional option.
  https://learn.microsoft.com/en-us/microsoft-365/admin/create-groups/ownerless-groups-teams?view=o365-worldwide

- **What's new with pay-as-you-go services in Microsoft 365**
  Introduced an August 2026 update that enables migrating Microsoft 365 Backup billing to the Billing > Pay-as-you-go node, unlocking capabilities like departmental billing, budget alerts, and creating Azure subscriptions or resource groups from the admin center. Announced Microsoft 365 Archive for SharePoint sites availability in GCC with guidance to configure pay-as-you-go billing and enable the feature in Settings.
  https://learn.microsoft.com/en-us/microsoft-365/commerce/services/pay-as-you-go-whats-new?view=o365-worldwide
