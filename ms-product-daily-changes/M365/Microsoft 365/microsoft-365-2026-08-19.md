# Microsoft 365
**Date created:** 2026-08-19 UTC  
**Tags:** Compliance, Configuration, Deprecation, Governance, Guidance, Security  

## Moderate Changes

- **Requirements for Loop components and Loop workspaces**

  Updated availability to specify Loop components in OneNote are supported only in the Windows desktop app, not the web. Expanded deprecation timelines: insertion in Word for the web ended Sep 1, 2025, and OneNote for the web begins retiring mid‑Sep 2026. Clarified post‑retirement behavior so admins and users can plan: web apps won’t support live components (existing items become links), while the full experience remains in OneNote for Windows.

  https://learn.microsoft.com/en-us/microsoft-365/loop/loop-requirements?view=o365-worldwide

- **Data Residency for Microsoft Copilot and Copilot Chat**

  Aligned terminology by renaming “Microsoft 365 Copilot” to “Microsoft Copilot” across the page, including titles, headings, and anchors. This improves consistency and navigation without changing features or guidance.

  https://learn.microsoft.com/en-us/microsoft-365/enterprise/m365-dr-service-copilot?view=o365-worldwide

- **Running the migration**

  Clarified that migration commands must be run from the target tenant by Microsoft 365 Migration Administrators or Global Administrators. Added an explicit Microsoft Graph connection step using Connect-MgGraph with the CrossTenantContentMigration.ReadWrite.All scope and reinforced least‑privilege guidance. These updates help ensure correct tenant context, stronger security practices, and fewer execution errors.

  https://learn.microsoft.com/en-us/microsoft-365/migration/migration-orchestrator-5-running-migration?view=o365-worldwide
