# Microsoft 365
**Date created:** 2026-08-28 UTC  
**Tags:** Analytics, Guidance, Monitoring, Security  

## Major Changes

- **Engagements in Enhanced Engagements**

  Added guidance to view nudge history and submit follow-up nudges from a service request’s details, including how to read key fields (status, counts, timestamps) and interpret the nudge timeline events. Clarified that re-nudging doesn’t change the current status but updates counts and restarts a cycle after resolution. Expanded the Benefits section to help admins decide when additional follow-up is warranted. Minor content reordering improves readability around status visuals.

  https://learn.microsoft.com/en-us/microsoft-365/enterprise/microsoft-365-admin-engagements?view=o365-worldwide

## Moderate Changes

- **Manage agent registry in Microsoft 365 admin center**

  Updated export guidance and renamed the section to “Export to Excel for users and agents” to reflect broader scenarios. Introduced the ability to export a 30-day list of active users with key activity fields (such as UPN, total agents used, sessions, and last activity date) to support usage analysis and governance.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-registry?view=o365-worldwide

- **Shadow AI in Microsoft 365 admin center (Preview)**

  Added a prerequisite to enable Microsoft Defender for Endpoint on devices to support shadow AI agent detection, with a link to local agent discovery guidance. Reorganized the prerequisites for clarity; role requirements remain unchanged, improving readiness and security posture before onboarding.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-shadow-ai?view=o365-worldwide

- **What's new in the Microsoft 365 admin center**

  Added an “August 2026” entry highlighting Enhanced engagements updates: admins can track service request progress via Nudge status and review a detailed nudge timeline/history with timestamps and follow-up nudges. This improves transparency and helps teams manage next steps more effectively.

  https://learn.microsoft.com/en-us/microsoft-365/admin/whats-new-in-preview?view=o365-worldwide
