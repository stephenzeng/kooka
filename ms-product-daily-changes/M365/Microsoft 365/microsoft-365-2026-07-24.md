# Microsoft 365
**Date created:** 2026-07-24 UTC  
**Tags:** Administration, AI  

## New Articles

- **Overview of people relationships in Microsoft 365**

  Introduced a new article that defines people relationship types—such as Manager, Assistant, Dotted-line manager (with alternative labels like People Lead or Capability Manager), and custom relationships like Mentor or Business Partner. It explains where these relationships appear across Microsoft 365 experiences including Profile cards, Org explorer, and Microsoft Copilot. The guidance covers how organizations can bring relationship data into Microsoft 365 using Copilot connectors for people data. This helps admins model relationships more accurately so users and Copilot see richer organizational context.

  https://learn.microsoft.com/en-us/microsoft-365/admin/people-relationships-m365?view=o365-worldwide

## Moderate Changes

- **Online service activation for Open programs (volume licensing)**

  Updated activation steps for Azure OSA keys by removing the “Start Activation” action and directing users straight to the page to activate a new subscription or add credits; step numbering was adjusted accordingly. This streamlines the process and reduces potential confusion during activation.

  https://learn.microsoft.com/en-us/microsoft-365/commerce/licenses/online-service-activation-open-programs?view=o365-worldwide

- **Organizational messages in the Microsoft 365 admin center**

  Clarified device requirements to state that both Microsoft Entra ID–joined and Microsoft Entra hybrid joined devices are supported. This expands eligibility and simplifies deployment for organizations with mixed device join states.

  https://learn.microsoft.com/en-us/microsoft-365/admin/misc/organizational-messages-microsoft-365?view=o365-worldwide
