**Date created:** 2026-08-27 UTC  
**Tags:** Configuration, Guidance  

## Moderate Changes

- **Microsoft 365 LTI First-Time Configuration**

  Removed preview-specific notices and outdated migration/testing recommendations to reflect current, generally available guidance. Updated Teams synchronization guidance to keep “create Team” disabled when an LMS sync is already in place, and to turn off other LMS Teams integrations if enabling Team creation in Microsoft 365 LTI. These changes help prevent duplicate team creation and integration conflicts, streamlining setup for production environments.
