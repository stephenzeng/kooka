## New Articles

- **Use the Microsoft AI at Work Roadmap**

  Introduced a new guide to the Microsoft AI at Work Roadmap, including how to search and filter by product, status, release phase, platform, cloud instance, and whether items are new or updated. Explained how to read feature cards and share items via email, RSS, and direct links. Added guidance on getting AI-powered change insights through the Microsoft Release Communications MCP Server and downloading roadmap data as CSV. Included related links for change management and release channel configuration to help admins operationalize updates.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/roadmap?view=o365-worldwide

- **Pay-as-you-go pricing for document processing for Microsoft 365**

  Added a new pay-as-you-go meter for Microsoft 365 OneDrive Storage. The meter measures GB usage beyond each account’s licensed storage entitlement and bills $0.20/GB/month ($0.00667/GB/day), providing clearer cost visibility for overage.

  https://learn.microsoft.com/en-us/microsoft-365/documentprocessing/syntex-pay-as-you-go-services?view=o365-worldwide
