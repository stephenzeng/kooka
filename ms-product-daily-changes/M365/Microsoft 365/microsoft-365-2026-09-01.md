# Microsoft 365
**Date created:** 2026-09-01 UTC  
**Tags:** Best Practices, Compliance, Configuration, Guidance, Governance, Performance  

## Moderate Changes

- **Governance and Lifecycle actions for agents available in Microsoft 365 admin center**
  
  Added owner management actions for Agent Builder agents, including the ability to add and remove owners with step-by-step procedures for assigning multiple owners. Clarified requirements and limitations (individual users only, equal rights for owners) and noted that the last remaining owner cannot be removed, with changes reflected across Microsoft Agent 365 and Agent Builder. These updates improve continuity and accountability in agent governance.
  
  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-actions?view=o365-worldwide

- **Agent settings in Microsoft 365 admin center**
  
  Introduced new rule-based bulk actions to block ownerless, unused agents and to reject publish requests older than a specified number of days. Updated the supported actions list and added guided configuration details with visuals. These controls streamline governance and reduce risk from stale or unmanaged agents.
  
  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-settings?view=o365-worldwide

- **Microsoft 365 network connectivity principles**
  
  Updated guidance to prioritize domain-based endpoint identification and the use of the published endpoint data at https://aka.ms/m365endpoints for allow-listing and optimization. Clarified when IP prefix data is available for scenarios like custom routing, split tunneling, or proxy bypass, and that many cloud endpoints are dynamic and domain-only. This helps align network policies with how Microsoft 365 publishes and evolves its endpoints.
  
  https://learn.microsoft.com/en-us/microsoft-365/enterprise/microsoft-365-network-connectivity-principles?view=o365-worldwide
