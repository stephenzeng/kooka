# Microsoft 365
**Date created:** 2026-08-21 UTC  
**Tags:** Configuration, Governance, Guidance, Licensing, Security  

## Moderate Changes

- **Manage agents across multiple tenants in the Microsoft 365 admin center (preview)**

  Updated licensing guidance to clarify that viewing and managing agents across connected tenants does not require additional licenses, while accessing agent risk and activity requires a Microsoft Agent 365 license assigned to the end user. Clarified that risk details are visible in the Security area and refined terminology for Partner Center and Microsoft Entra Tenant Governance to improve consistency.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-multi-tenant?view=o365-worldwide

- **Deploy and manage Office Add-ins through the integrated apps portal**

  Expanded admin guidance for deploying and managing Office Add-ins in the integrated apps portal, with clearer step-by-step procedures for deployment, consent, user assignments, updates, and removal. Added security-focused callouts to reinforce least-privilege practices and that only Global Administrators can grant consent, and clarified Exchange Online OAuth verification using Test-OAuthConnectivity.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/office-addins?view=o365-worldwide
