# Microsoft 365
**Date created:** 2026-09-03 UTC  
**Tags:** Compliance, Security  

## Moderate Changes

- **Restore data in Microsoft 365 Backup**

  Updated limitations to clarify that granular restore for SharePoint does not support content from IRM-enabled document libraries or locked sites. This helps administrators avoid failed or partial restores and plan alternatives for protected or locked content. Review IRM and site lock settings before attempting granular restores.

  https://learn.microsoft.com/en-us/microsoft-365/backup/backup-restore-data?view=o365-worldwide
