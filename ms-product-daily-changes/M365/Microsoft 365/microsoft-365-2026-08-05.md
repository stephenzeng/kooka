# Microsoft 365
**Date created:** 2026-08-05 UTC  
**Tags:** Administration, Agent, Governance, Security  

## New Articles

- **Manage agents across multiple tenants in the Microsoft 365 admin center**

  Introduces a public preview for centrally managing agents across multiple tenants in the Microsoft 365 admin center. Provides prerequisites, supported relationships (GDAP and Microsoft Entra Tenant Governance), roles and permissions, and how to use the tenant switcher with the consolidated multi-tenant Agents experience. Explains how to inventory and install custom or Microsoft agents across all or selected governed tenants, block agents, investigate risky agents (including licensing implications), and review or export activity. Includes example partner and enterprise scenarios and key preview considerations to guide adoption.

  https://learn.microsoft.com/en-us/microsoft-365/admin/manage/agent-multi-tenant?view=o365-worldwide

## Moderate Changes

- **An overview of tenant-to-tenant migration with orchestrator in Microsoft 365**

  Updated licensing guidance to state that a per-user license covers migrating all content supported by orchestration, replacing prior workload-specific wording. Removed the preview note about additional Teams meetings and chats licenses, simplifying prerequisites for planning migrations.

  https://learn.microsoft.com/en-us/microsoft-365/migration/migration-orchestrator-1-overview?view=o365-worldwide
