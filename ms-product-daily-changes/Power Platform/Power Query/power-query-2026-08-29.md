# Power Query
**Date created:** 2026-08-29 UTC  
**Tags:** Configuration, Guidance, Identity, Security  

## Moderate Changes

- **Power Query Azure Analysis Services database connector**

  Updated guidance to specify that Azure Analysis Services supports only Organizational account (OAuth 2.0) authentication. Clarified that Basic, Windows, and Microsoft account options are for SQL Server Analysis Services and aren’t supported for Azure Analysis Services, directing users to select Organizational account.

  https://learn.microsoft.com/en-us/power-query/connectors/azure-analysis-services
