# Power Platform
**Date created:** 2026-08-11 UTC  
**Tags:** Automation, Guidance  

## Moderate Changes

- **Automate deployments with Dataverse Git integration and pipelines in Power Platform**

  Updated ALM guidance to move away from using a custom pipeline host and Source Control deployment type for promoting solutions. Now recommends syncing changes from the main branch back to the primary development environment and using Power Platform pipelines to promote to test. This streamlines deployments and aligns processes with built-in, supported capabilities.
