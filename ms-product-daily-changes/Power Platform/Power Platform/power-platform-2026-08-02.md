# Power Platform
**Date created:** 2026-08-02 UTC  
**Tags:** Administration  

## Major Changes

- **Power Automate licensing FAQ**

  Updated guidance introduces flow groups, allowing a single Process license to share 250,000 actions/day across up to 25 solution-aware parent and child cloud flows, with explicit group membership required and no automatic inheritance. Clarifies that assigning a Process license to a parent flow does not cover child flows; child flows must be licensed directly or added to the same flow group. Defines stacking rules—up to 10 Process licenses can be stacked on an individual flow, while stacking is not available for flow groups—and emphasizes that flow groups and capacity assignments are per-environment and must be set up in each environment. Refines distinctions between Process capacity and user-license context and expands examples for high-action scenarios and parent-child flows using premium connectors to help admins license complex processes accurately.
