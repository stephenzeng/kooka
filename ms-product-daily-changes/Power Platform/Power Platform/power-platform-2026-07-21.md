# Power Platform
**Date created:** 2026-07-21 UTC  
**Tags:** Administration, Automation, Governance  

## Moderate Changes

- **Deep dive on specific licenses**

  Updated guidance to allow assigning a Process license to a flow group, sharing 250,000 actions per day across up to 25 cloud flows (child flows must be explicitly added). Clarified that capacity doesn’t inherit from parent to child flows; each flow must be directly licensed or included in a flow group. This helps administrators plan capacity and compliance more accurately.

  https://learn.microsoft.com/en-us/power-platform/admin/power-automate-licensing/deep-dive-on-specific-license

- **Types of Power Automate licenses**

  Updated license guidance to support assigning Process licenses to flow groups that share 250,000 actions per day across up to 25 cloud flows. Clarified stacking rules: stacking isn’t available for flow groups, while up to 10 licenses can still be stacked for a single cloud flow. These changes help organizations choose the right licensing strategy for scale and cost control.

  https://learn.microsoft.com/en-us/power-platform/admin/power-automate-licensing/types
