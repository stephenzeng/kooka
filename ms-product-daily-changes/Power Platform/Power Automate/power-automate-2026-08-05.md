# Power Automate
**Date created:** 2026-08-05 UTC  
**Tags:** AI, Automation  

## Major Changes

- **Record with Copilot for desktop flows (deprecated)**

  Announced the deprecation and removal of Record with Copilot (AI Recorder) for Power Automate for desktop; the feature is no longer available. Previous walkthroughs, prerequisites, FAQs, limitations, privacy details, and demo content were removed in favor of a concise deprecation notice. Guidance now directs users to alternatives, including creating flows with natural language in Copilot and using Microsoft Copilot Studio with computer use. Customers should transition to these options to maintain automation workflows and update any internal references to the retired capability.

  https://learn.microsoft.com/en-us/power-automate/desktop-flows/create-flow-using-ai-recorder
