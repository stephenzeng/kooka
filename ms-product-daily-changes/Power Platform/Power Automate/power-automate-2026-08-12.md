## Moderate Changes

- **Troubleshoot common problems with Power Automate triggers**
  
  Updated guidance on HTTP and Teams webhook trigger callback URLs effective June 2, 2026. URLs now include the scale unit identifier in the path (for example, /direct/cu/20/workflows/...), and adopting this format can improve performance while legacy URLs remain supported.
