# Power Automate
**Date created:** 2026-07-18 UTC  
**Tags:** Automation  

## Moderate Changes

- **Explore the cloud flows designer**
  Added a Layout toolbar control that lets makers switch between inline and panel configurations, with clearer guidance on where action properties appear in each mode. Expanded canvas guidance and refined tips for shortcuts, undo/redo, solution-aware drafting/publishing, and known issues, including identifying non-OpenAPI actions via a method parameter and re-adding actions to adopt new schemas. These updates help makers work faster and avoid common pitfalls in the designer.
  https://learn.microsoft.com/en-us/power-automate/flows-designer

- **Run desktop flows in picture-in-picture**
  Updated licensing guidance by removing the requirement for a Premium plan or pay-as-you-go environment to run desktop flows in PiP. This simplifies prerequisites so more users can run PiP without additional licensing barriers.
  https://learn.microsoft.com/en-us/power-automate/desktop-flows/run-desktop-flows-pip

- **SAP automation actions**
  Added a known limitation that UI/Web Automation and SAP actions don't work on SAP Web Dynpro forms embedded in SAP GUI, with a workaround to open the page in a standalone browser and use Web Automation actions. Clarified connection modes, multiple logon options, and improved parameter and behavior descriptions across key SAP actions to set correct expectations and reduce configuration errors.
  https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/sap
