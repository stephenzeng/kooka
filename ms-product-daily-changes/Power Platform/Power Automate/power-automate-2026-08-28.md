# Power Automate
**Date created:** 2026-08-28 UTC  
**Tags:** Automation, Configuration, Guidance, Security  

## New Articles

- **Create a User-credential Mapping**

  Introduced a preview feature for mapping users to application credentials for desktop flows, enabling centralized, per-user credential selection at runtime. Outlines prerequisites and availability, including required component versions and exclusions for US Government Clouds and China regions. Provides step-by-step wizard instructions, guidance for using mappings in desktop flows, and notes on sharing and permissions. Highlights limitations such as the need to reconfigure user-to-credential mappings after import, while allowing export/import of a default credential.

  https://learn.microsoft.com/en-us/power-automate/desktop-flows/create-user-mapping

## Major Changes

- **AI Builder actions (preview)**

  Expanded the AI Builder actions reference to include preview actions for sentiment analysis, language detection, and text translation, with detailed inputs, outputs, and exception behavior. Updated responsible-use guidance for the GPT action, requiring a user confirmation step (for example, a Display input dialog or Display message) before using generated content. Clarified rollout and throttling considerations and refined instructions for the setup wizard to improve usability.

  https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/aibuilder
