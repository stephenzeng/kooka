# Power Automate
**Date created:** 2026-09-02 UTC  
**Tags:** Configuration, Get Started, Governance, Guidance  

## Moderate Changes

- **Create flows by using the Power Apps app in Microsoft Teams**

  Updated guidance to reflect the new Cloud flow entry point and a required step to name the flow and choose a trigger before creation. Clarifies available flow types (Instant, Scheduled, Automated) and refines connector guidance and step descriptions for accuracy in Teams.

  https://learn.microsoft.com/en-us/power-automate/teams/create-flows-power-apps-app

- **Share/export a desktop flow**

  Clarifies that owners and co-owners can share or move desktop flows in an organization’s environment subject to environment permissions and governance. Updates export guidance to align with ALM best practices, linking to detailed topics (ALM for desktop flows, solutions, connection references, ALM v2 schema) to strengthen lifecycle management.

  https://learn.microsoft.com/en-us/power-automate/desktop-flows/how-to/share-export-desktop-flows

- **Work queues actions**

  Corrects parameter types for WorkQueueItem and fixes default handling for requeue delays. Removes a duplicated exceptions subsection and standardizes state terminology to “Paused,” improving accuracy and consistency in the actions reference.

  https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/workqueues
