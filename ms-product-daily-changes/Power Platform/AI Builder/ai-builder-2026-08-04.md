# AI Builder
**Date created:** 2026-08-04 UTC  
**Tags:** Administration  

## Moderate Changes

- **Overview of licensing**

  Clarified that AI Builder actions, including the business card reader, are premium connectors—making any flow that uses them a premium flow requiring Power Automate premium licensing. Added guidance on pay-as-you-go: each run is charged via the cloud flow run meter and is separate from AI Builder credit consumption, which may be zero for some actions.

  https://learn.microsoft.com/en-us/ai-builder/administer-licensing
