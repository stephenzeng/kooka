## Moderate Changes

- **Work with Microsoft Entra ID group teams (Dataverse)| Microsoft Docs**

  Added guidance on automatically synchronizing Dataverse group team membership with the linked Microsoft Entra group using a scheduled Power Automate cloud flow that calls the SyncGroupMembersToTeam action. This keeps team membership current by adding new members and removing those no longer in the Entra group, reducing manual maintenance and improving access accuracy.

  https://learn.microsoft.com/en-us/power-apps/developer/data-platform/aad-group-team

  Corrected the npm global installation command to use the @microsoft/power-apps-cli package, preventing setup errors and aligning instructions with the current CLI. Other dependency steps remain unchanged.

  https://learn.microsoft.com/en-us/power-apps/developer/code-apps/how-to/npm-quickstart
