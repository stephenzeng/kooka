## Moderate Changes

- **Query data**

  Updated SQL querying guidance to direct developers to the Python SDK client.query.sql method and the Dataverse Web API ?sql= parameter. Centralized SQL limitations using a shared include and added clear error-handling behavior for unsupported and server-rejected queries. Introduced a Supported SQL section and reorganized content to flow into practical examples.

  https://learn.microsoft.com/en-us/power-apps/developer/data-platform/sdk-python/query

- **Use SQL to query data by using the Dataverse Web API**

  Replaced scattered limitation notes with a dedicated Supported SQL section that references a shared include, providing a single, authoritative source for constraints. This streamlines the guidance and improves consistency across SQL-related documentation.

  https://learn.microsoft.com/en-us/power-apps/developer/data-platform/webapi/query/sql
