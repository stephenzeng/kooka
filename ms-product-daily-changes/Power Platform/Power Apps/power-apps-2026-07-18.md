**Date created:** 2026-07-18 UTC  
**Tags:** Programming  

## Moderate Changes

- **Supported customizations for Microsoft Dataverse**

  Updated guidance on supported .NET Framework versions for Dataverse plug-ins and custom workflow activities, narrowing support to 4.6.2 through 4.8. Recommend targeting .NET Framework 4.8 for plug-in and workflow projects, and 4.8 or later for application code to align with support and improve compatibility.

  https://learn.microsoft.com/en-us/power-apps/developer/data-platform/supported-customizations
