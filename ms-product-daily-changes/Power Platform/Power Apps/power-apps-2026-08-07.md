# Power Apps
**Change date:** 2026-08-07 UTC  
**Tags:** Administration  

## Moderate Changes

- **Create or edit model-driven app quick create forms in Power Apps**

  Updated guidance to match the latest UI, replacing “Add form” with “New form.” Added clear steps to enter a form name and description before creating, and clarified that you should open the table before accessing the Forms area. These refinements reduce confusion and streamline form setup for makers.

  https://learn.microsoft.com/en-us/power-apps/maker/model-driven-apps/create-edit-quick-create-forms

- **Tables in Microsoft Dataverse**

  Clarified that makers can create custom tables or customize standard tables and manage them both in Power Apps (make.powerapps.com) and in the model-driven app designer. This makes the available options and entry points for table management more obvious, helping makers choose the right workflow.

  https://learn.microsoft.com/en-us/power-apps/maker/data-platform/entity-overview
