# Power Apps
**Date created:** 2026-07-31 UTC  
**Tags:** Administration  

## Moderate Changes

- **Types of tables**

  Updated guidance clarifies that activity records—not just email—can be associated with multiple business records using the “related” activity party column, and will appear in each linked record’s timeline. It also specifies that this capability is supported across activity tables except Task, and updates customization steps to add the “related” column on the activity main form. These changes help makers model many-to-many activity relationships consistently.
