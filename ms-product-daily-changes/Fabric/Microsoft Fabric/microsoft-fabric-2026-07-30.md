**Date created:** 2026-07-30 UTC

## New Articles

- **Variable library integration with Apache Airflow jobs**

  Introduced guidance for integrating Microsoft Fabric Variable libraries with Apache Airflow jobs in Data Factory. Explains how to create a Variable library, attach variables in the job’s Environment configuration, and access them in DAGs using Airflow’s Variable API. Clarifies that variable changes aren’t auto-synced and require manual synchronization via “Sync Library variables,” and links to the Variable library overview for deeper context.

  https://learn.microsoft.com/en-us/fabric/data-factory/apache-airflow-jobs-variable-library-integration

- **AWS Glue catalog mirroring in Microsoft Fabric**

  Added an overview of mirroring AWS Glue catalogs in Fabric without data movement using S3 shortcuts and Iceberg tables. Describes the created mirrored catalog and autogenerated SQL analytics endpoint, and how to query with T‑SQL, Direct Lake for Power BI, and other workloads. Covers authentication with AWS IAM access keys, required permissions, Lake Formation considerations, and how metadata sync works, with links to a tutorial and limitations.

  https://learn.microsoft.com/en-us/fabric/mirroring/catalog-mirroring/aws-glue

- **Limitations in Microsoft Fabric catalog mirroring for AWS Glue**

  Documented key constraints for AWS Glue catalog mirroring: Iceberg-only support, conversion to Delta Lake in OneLake with caveats, and a public internet requirement for the Iceberg REST catalog and table storage. Notes a 500‑table limit per mirroring operation, read‑only access in Fabric, and that Lake Formation fine‑grained permissions aren’t enforced—use OneLake security instead. Emphasizes that metadata sync depends on valid IAM credentials.

  https://learn.microsoft.com/en-us/fabric/mirroring/catalog-mirroring/aws-glue-limitations

- **Tutorial: Configure mirrored AWS Glue catalog**

  Published a step‑by‑step tutorial to set up a mirrored AWS Glue catalog, including prerequisites (Iceberg tables, public endpoint reachability, IAM credentials, capacity, and tenant settings). Provides least‑privilege IAM policy guidance, connection details (REST endpoint format, catalog ID as warehouse, access key auth), table selection, and enabling automatic metadata sync. Shows how to preview/query via the SQL analytics endpoint and create Lakehouse shortcuts for Spark/notebooks, with links to overview and limitations.

  https://learn.microsoft.com/en-us/fabric/mirroring/catalog-mirroring/aws-glue-tutorial

- **Fiscal Year Setup for Planning and Reporting**

  Introduced a concept article on configuring fiscal‑year‑based planning and reporting. Explains fiscal vs. calendar years, building a fiscal date table with numeric sort columns, and the recommended hierarchy (Year → Quarter → Month). Details settings for Fiscal Year Start Month and Convention, how they influence forecasting windows, and includes worked examples, best practices, troubleshooting, FAQs, and a validation checklist.

  https://learn.microsoft.com/en-us/fabric/iq/plan/planning-concept-fiscal-year-setup

- **Python notebook runtime and kernel lifecycle in Fabric**

  Added detailed lifecycle guidance for Fabric Python notebook kernels, including supported versions (3.10, 3.11, 3.12), stage definitions, and end‑of‑life timelines. Clarifies how notebook kernels differ from Spark runtimes and announces Python 3.10 deprecation with migration steps to 3.11/3.12. Includes FAQs covering impacts, scheduled runs, identifying kernels, code changes, and support expectations.

  https://learn.microsoft.com/en-us/fabric/data-engineering/python-notebook-runtime-lifecycle
