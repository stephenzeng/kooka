# Microsoft Fabric
**Date created:** 2026-07-17 UTC  
**Tags:** Analytics, Programming, Security  

## New Articles

- **Append Queries**

  Introduces a how-to guide for using Append Query in Infobridge to combine rows from multiple queries with matching schemas. Walks through an example that merges department bonus and regional sales data. Provides step-by-step instructions for selecting sources, validating schemas, and reviewing the resulting appended query. Includes visuals to help users verify selections and performed steps.

  https://learn.microsoft.com/en-us/fabric/iq/plan/infobridge-transform-queries/how-to-append-query

## Moderate Changes

- **Anomaly Detection in Real-Time Intelligence**

  Added guidance to review existing anomaly detection configurations from a data source’s menu, explore detected anomalies, and open configurations in full screen. Includes steps to create a new configuration when needed and adds illustrative images to clarify the workflow.

  https://learn.microsoft.com/en-us/fabric/real-time-intelligence/anomaly-detection

- **GQL language guide for graph in Microsoft Fabric**

  Corrected and refined example queries and explanations to align with demonstrated patterns, including person/company filters and RETURN outputs. Updated sample data (for example, “Alice”) and date filters to improve clarity and accuracy when writing GQL queries.

  https://learn.microsoft.com/en-us/fabric/graph/gql-language-guide

- **Set up and use tenant-level private links**

  Added a step-by-step procedure to fully clean up tenant-level Private Link before tenant migration. Guidance covers enabling public internet access, removing Azure private endpoints and private DNS zones, deleting the Power BI Private Link service, and then disabling tenant-level Private Link to avoid migration issues.

  https://learn.microsoft.com/en-us/fabric/security/security-private-links-use

- **What's new? archive**

  Updated the archive with entries for Livy REST API GA and mirroring improvements for CSV uploads. Highlights include submitting Spark code via REST without notebooks and simplified CSV mirroring with optional primary keys and automatic inserts.

  https://learn.microsoft.com/en-us/fabric/fundamentals/whats-new-archive
