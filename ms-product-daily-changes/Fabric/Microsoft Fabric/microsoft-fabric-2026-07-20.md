# Microsoft Fabric
**Date created:** 2026-07-20 UTC  
**Tags:** Analytics  

## New Articles

- **Explore, Organize and Summarize Data in PowerTable Sheet**

  Introduced a comprehensive guide to exploring and organizing data in PowerTable. It covers searching across pages, sorting with the option to clear sorts, reordering, showing/hiding, and pinning columns to customize your view. The article explains column-level Insights and Column Profile to surface key stats like sums, averages, unique counts, and data completeness. It also details Data Cleanup actions to remove duplicates or empty values, helping improve data quality and speed up analysis.

  https://learn.microsoft.com/en-us/fabric/iq/plan/powertable-how-to-explore-organize-data

- **Filter Data in PowerTable Sheet**

  Added a how-to article on filtering data with basic selections, advanced text and numeric conditions, and sliders for ranges. It introduces an Advanced Filter builder with grouped AND/OR logic, Top N filters based on a related numeric field, and global filters that span multiple sheets via shared dimensions. The guidance streamlines precise slicing of large datasets and makes cross-sheet filtering consistent and easy to reset.

  https://learn.microsoft.com/en-us/fabric/iq/plan/powertable-how-to-filter-data

- **Group Rows in PowerTable Sheet**

  Published a guide to grouping rows by any column, including expanding/collapsing groups, creating nested subgroups, and removing grouping. The article explains how grouped data automatically aggregates numeric fields and details supported operations on grouped datasets such as editing, bulk updates, formatting, sorting, and find/replace. This helps readers quickly summarize large datasets while retaining the flexibility to refine and edit grouped data.

  https://learn.microsoft.com/en-us/fabric/iq/plan/powertable-how-to-group-rows
