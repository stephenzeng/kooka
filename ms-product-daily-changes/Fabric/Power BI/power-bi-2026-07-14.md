# Power BI
**Date created:** 2026-07-14 UTC  
**Tags:** Administration, Analytics  

## New Articles

- **Configure semantic model options in the Power BI service**

  Introduced a new guide for configuring semantic model options directly in the Power BI service. It explains prerequisites, how to open the Model Options dialog, and the full set of configurable settings, including type detection, relationships, time intelligence, parallel loading, regional settings, DirectQuery behavior, and connection limits. The article clarifies when changes take effect, how service and Desktop settings interact, and what happens when downloading or republishing PBIX files. It also includes troubleshooting for missing options and save errors, plus links to related topics.

  https://learn.microsoft.com/en-us/power-bi/transform-model/service-model-options

## Major Changes

- **Create a card visual in Power BI**

  Reworked the tutorial to use a comprehensive TMDL-based sample model with calculated data, measures, and a reusable DAX function to render SVG trend lines. Updated the workflow to rely on prebuilt icon measures, refreshed layout guidance (including the change from Autogrid to Fit to space), and removed the previous category image background approach. Added new steps for conditional formatting to highlight cards based on data and clarified preview and format behaviors. These changes provide a more realistic, reusable pattern for building rich, trend-aware card visuals.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-card

## Moderate Changes

- **Publish semantic models and reports from Power BI Desktop**

  Clarified that the “Publish dialogs support folder selection” feature is not enabled by default and must be turned on in Options and settings > Options > Preview features. This ensures users explicitly opt in before using folder selection in publish dialogs.

  https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-upload-desktop-files

- **Apps in Power BI**

  Expanded guidance on notifications: users get an email when first granted access to an app or a new audience, while republishing or updating an app applies changes automatically without sending notifications. Added a tip about related notifications in Microsoft Teams and clarified that data in app items stays current via scheduled refreshes.

  https://learn.microsoft.com/en-us/power-bi/explore-reports/end-user-apps

- **Email subscriptions for reports and dashboards in the Power BI service**

  Clarified that subscriptions expire at 12:00 AM UTC on the selected end date and may require selecting the following day to continue receiving emails through a specific date. Updated wording on expiration behavior and re-enabling subscriptions after expiry.

  https://learn.microsoft.com/en-us/power-bi/collaborate-share/end-user-subscribe

- **Get started with org apps**

  Added an “Apps page limitations” section outlining current UI gaps: App type may show “Org app (preview),” the page filter may list org apps under that label, and gallery view currently displays the default org app icon. This helps set user expectations while the UI evolves.

  https://learn.microsoft.com/en-us/power-bi/explore-reports/org-app-items

- **Edit semantic models in the Power BI service**

  Updated limitations and notes to reflect that key model options (such as type detection, relationship auto-detection, auto date/time, parallel loading, regional settings, and DirectQuery restrictions) are now available in the Model Options dialog. Added a resource link to the new article covering model options in the service.

  https://learn.microsoft.com/en-us/power-bi/transform-model/service-edit-data-models
