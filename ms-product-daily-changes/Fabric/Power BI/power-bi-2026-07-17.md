# Power BI
**Date created:** 2026-07-17 UTC  
**Tags:** Analytics  

## Moderate Changes

- **Matrix visual considerations and limitations**

  Added a new limitation that matrix visuals can display up to 100 columns at a time, including totals and subtotals. Clarified that conditional formatting and dynamic text aren’t supported for row or column headers and recommended using field parameters to control visible headers. Expanded guidance to note that only the lowest hierarchy level can be formatted individually; upper levels inherit general header settings.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-matrix-visual-considerations
