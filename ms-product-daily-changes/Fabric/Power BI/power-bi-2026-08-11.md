# Power BI
**Date created:** 2026-08-11 UTC  
**Tags:** Automation, Configuration, Guidance, Governance, Performance  

## Major Changes

- **Export paginated report to file**

  Updated concurrency limits reduce the maximum simultaneous paginated report renders for exportToFile, tightening the ceiling to improve service reliability under load. New throttling guidance specifies request-per-minute caps based on authentication context, helping teams calibrate batch export throughput. These changes clarify when 429 responses occur and how to adjust retry logic and capacity planning to avoid disruptions.

  https://learn.microsoft.com/en-us/power-bi/developer/embedded/export-paginated-report

- **Move your Power BI tenant to a different region**

  Added scripted automation using Fabric Toolbox PowerShell to streamline pre-remap cleanup and administration, including workspace discovery, capacity reassignment, admin access, and safe, confirmed deletion of active and soft-deleted artifacts. Introduced a self-serve tenant remap option in the Power BI Admin Portal with clear steps to select a target region, authorize, and execute, along with expectations for up to 30 minutes of downtime and about an hour for propagation. This guidance helps admins plan, execute, and validate tenant moves with less manual effort and predictable service impact.

  https://learn.microsoft.com/en-us/power-bi/support/service-admin-region-move
