# Power BI
**Date created:** 2026-08-15 UTC  
**Tags:** Configuration, Governance, Guidance, Troubleshooting  

## Moderate Changes

- **Export paginated report to file**
  Clarified prerequisites for exporting paginated reports that connect via the public XMLA endpoint or are exported by a service principal. Requires enabling the capacity-level XMLA Endpoint (Read or Read Write) and the tenant setting “Allow XMLA endpoints and Analyze in Excel with on-premises semantic models”; exports fail with a connection error if either is disabled. Included a link to guidance on semantic model connectivity via XMLA.
  https://learn.microsoft.com/en-us/power-bi/developer/embedded/export-paginated-report

- **Edit semantic models in the Power BI service**
  Updated the refresh experience with a new dropdown (refresh schema and data, schema only, or data only) and added table-level refresh controls, along with notes on cancellation behavior. Documented limitations for DirectQuery (no refresh enhancements) and Direct Lake (table-level refresh not supported), and clarified that write permission is required to edit models while Build permission is needed to create reports; added screenshots for clarity.
  https://learn.microsoft.com/en-us/power-bi/transform-model/service-edit-data-models

- **Get started with goals in Power BI**
  Removed the preview label for Compact view, indicating general availability. Added a new limitation: a scorecard can contain a maximum of 1,000 goals.
  https://learn.microsoft.com/en-us/power-bi/create-reports/service-goals-introduction

- **Fabric and Power BI planned maintenance guide**
  Clarified that usage data collected before a maintenance window resets and should be backed up. Added guidance that equivalent activity logs are available in Microsoft Purview for up to 180 days post-migration, and refined wording in related sections without changing procedures.
  https://learn.microsoft.com/en-us/power-bi/support/service-planned-maintenance
