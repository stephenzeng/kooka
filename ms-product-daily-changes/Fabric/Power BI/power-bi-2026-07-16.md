# Power BI
**Date created:** 2026-07-16 UTC  
**Tags:** Agent, Analytics, Programming  

## New Articles

- **Add and Edit Visual Calculations**

  New step-by-step guidance for creating and editing visual calculations in Power BI Desktop. It explains prerequisites, how to launch and use the visual calculation editor (visual preview, formula bar, visual matrix), and how row-by-row evaluation behaves similarly to calculated columns. A worked example shows using an IF-based DAX expression to return hex color codes, setting data type/format to Text, hiding the calculation, and applying it for conditional formatting. The article also covers editing from the Visualizations pane and links to templates and related concepts.

  https://learn.microsoft.com/en-us/power-bi/transform-model/desktop-visual-calculations-create

- **End-to-end: From raw data to a shared Power BI app**

  Introduces a comprehensive, phased tutorial that takes users from data ingestion through modeling, report building, publishing, and app distribution. It provides full Power Query M scripts for sample tables and an optional TMDL script to quickly instantiate the semantic model, along with clear guidance on relationships, date tables, measures, and visual configuration. The tutorial covers workspace publishing, refresh and endorsement settings, app audiences and permissions, plus troubleshooting and cleanup steps. It also outlines optional AI capabilities such as Copilot features and agentic workflows to accelerate analysis.

  https://learn.microsoft.com/en-us/power-bi/create-reports/tutorial-end-to-end-power-bi

## Major Changes

- **Visual Calculations Overview**

  Substantially rewritten to shift from step-by-step instructions to a conceptual overview of visual calculations, how they behave in the visual matrix, and how they differ from measures and calculated columns. It documents available DAX functions and introduces visual-calculation-specific functions like RUNNINGSUM, MOVINGAVERAGE, COLLAPSE/EXPAND, FIRST/LAST, and LOOKUP/LOOKUPWITHTOTALS. Parameter guidance is expanded for Axis, Reset (with absolute and relative modes), OrderBy, and PartitionBy, including parameter pickers. Guidance on hiding fields, formatting results, and related resources is consolidated, while procedural creation/editing steps are moved to a dedicated article.

  https://learn.microsoft.com/en-us/power-bi/transform-model/desktop-visual-calculations-overview

- **What is the Power BI Desktop Bridge? (Preview)**

  Major expansion clarifying the bridge’s purpose, secure local API enablement, and IPC architecture (named pipes, JSON-RPC 2.0, framing, concurrency, and per-window isolation) with local-only access. Adds a CLI-first approach with a catalog of commands (for status, manifest, open, reload, and screenshots) and detailed API method documentation, including parameters, return schemas, and model reload behavior. The update trims low-level connection walkthroughs and lengthy PowerShell samples to streamline discovery and adoption, and clarifies integration with the Report Authoring Skill.

  https://learn.microsoft.com/en-us/power-bi/developer/agentic/power-bi-desktop-bridge-overview

## Moderate Changes
