# Power BI
**Date created:** 2026-07-15 UTC  
**Tags:** Administration, Analytics  

## Moderate Changes

- **Troubleshoot Access and Excel XLS import issues in Power BI Desktop**

  Updated troubleshooting to reflect that Power BI Desktop is 64-bit only and requires the 64-bit Access Database Engine. Removed obsolete 32-bit download steps and clarified guidance for Office bitness mismatches. This streamlines setup and helps prevent import failures.

  https://learn.microsoft.com/en-us/power-bi/connect-data/desktop-access-database-errors

- **Quickstart: Connect to data in Power BI Desktop**

  Updated authentication prerequisites to require Microsoft Edge WebView2 instead of Internet Explorer, noting that WebView2 typically installs automatically with Power BI Desktop. This ensures users meet the modern sign-in and connectivity requirements.

  https://learn.microsoft.com/en-us/power-bi/connect-data/desktop-quickstart-connect-to-data

- **Sort One Column by Another Column in Power BI**

  Added troubleshooting for common “Sort by column” issues and clarified the steps in both Desktop and the Power BI service. Emphasized granularity alignment, data type consistency, and uniqueness requirements to avoid errors and unexpected grouping. This helps authors resolve sorting problems more quickly.

  https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-sort-by-column

- **What are paginated reports in Power BI?**

  Refreshed the export options to add PowerPoint and accessible PDF, and remove HTML and TIFF, with an updated ordering of supported formats. Clarified that SSRS-style data-driven subscriptions aren’t available and pointed users to dynamic per-recipient subscriptions as an alternative. This aligns expectations with current capabilities and provides a supported path for tailored delivery.

  https://learn.microsoft.com/en-us/power-bi/paginated-reports/paginated-reports-report-builder-power-bi

- **Download a report from the Power BI service to Power BI Desktop**

  Added a limitation noting that renaming or rebinding a model after authoring can cause downloaded live connection PBIX files to point to a stale model. To reconnect properly, users should recreate or re-download a fresh live connection report. This prevents confusion and broken live connections.

  https://learn.microsoft.com/en-us/power-bi/create-reports/service-export-to-pbix
