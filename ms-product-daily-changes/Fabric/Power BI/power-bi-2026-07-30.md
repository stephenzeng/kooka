# Power BI
**Date created:** 2026-07-30 UTC  
**Tags:** Administration, Analytics  

## Major Changes

- **Supported data sources for Power BI paginated reports**

  Removed the entire section on Access and Excel data sources to streamline content. Guidance on using the ACE OLE DB provider was taken out, along with the note that Power BI Report Server (September 2026) doesn’t install ACE and requires separate installation. This change reduces redundancy and clarifies where to look for current setup requirements. Administrators should confirm ACE availability independently when connecting paginated reports to Access or Excel sources.

  https://learn.microsoft.com/en-us/power-bi/paginated-reports/paginated-reports-data-sources

## Moderate Changes

- **Paginated report data sources in Power BI Report Server**

  Added coverage for Access and Excel data sources, noting their reliance on the Microsoft Access Database Engine (ACE) OLE DB provider. Clarified that starting with the September 2026 release of Power BI Report Server, ACE isn’t installed by setup and must be added separately to use these sources. The introduction was refined to summarize supported sources and Power BI Report Server specifics.

  https://learn.microsoft.com/en-us/power-bi/report-server/connect-data-sources

- **Power BI report data sources in Power BI Report Server**

  Removed the section on Access and Excel data sources, including references to the ACE OLE DB provider. The prior note about ACE not being installed by default starting September 2026 was also removed, reducing duplication and focusing the page on current, relevant guidance.

  https://learn.microsoft.com/en-us/power-bi/report-server/data-sources
