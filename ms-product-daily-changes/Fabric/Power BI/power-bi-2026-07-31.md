# Power BI
**Date created:** 2026-07-31 UTC  
**Tags:** Security  

## Moderate Changes

- **Troubleshoot sign-in for Power BI Desktop**

  Expanded troubleshooting to cover sign-in failures caused by using the default web browser in older Power BI Desktop versions, and added clear guidance for the error "The application requested an unsupported mode 'query'..." including when it appears and how to resolve it (update Desktop or temporarily disable “Use my default web browser”). Added steps for data source sign-in issues recommending “Use updated sign-in experience for data sources” and reconnecting. Clarified instructions and scenarios to help users resolve sign-in and refresh problems faster.

  https://learn.microsoft.com/en-us/power-bi/connect-data/desktop-troubleshooting-sign-in
