# Power BI
**Date created:** 2026-08-06 UTC  
**Tags:** Analytics  

## Moderate Changes

- **Connect paginated reports to data sources by using Power Query in Power BI Report Builder**

  Updated end-to-end guidance for connecting and building datasets with Power Query in Report Builder, including entry points, credentials, transformations, and dataset creation. Clarified how to edit RDL datasets via Edit Mashup and map Get data parameters to Report Builder parameters, added a required Report Builder version, and documented how to update credentials after publishing using Manage connections and gateways. Expanded considerations on one RDL dataset per M query, parameter requirements when uploading reports (including via service principal), and the current lack of SSO support.

  https://learn.microsoft.com/en-us/power-bi/paginated-reports/report-builder/connect-snowflake-databricks-power-query-online

- **DirectQuery model guidance in Power BI Desktop**

  Added performance guidance for DirectQuery models with Fabric Data Warehouse and the SQL analytics endpoint. Recommends clustering frequently filtered large fact tables, maintaining statistics on key columns, and optimizing/compacting Delta tables to improve query efficiency and reliability.

  https://learn.microsoft.com/en-us/power-bi/guidance/directquery-model-guidance
