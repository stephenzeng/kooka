## New Articles

- **Power BI Premium P SKU to Fabric F SKU Migration Decision Guide**

  Provides a structured decision framework for migrating from P SKUs to Fabric F SKUs, including retirement timelines and key milestones. Explains P-to-F capacity mapping, right-sizing with Fabric Capacity Metrics and Autoscale considerations, and region strategy trade-offs. Highlights major differences between P and F SKUs, billing and cost management practices, and user licensing implications. Concludes with an actionable decision summary and related references.

  https://learn.microsoft.com/en-us/power-bi/support/premium-migration-decision-guide

- **Power BI Premium to Microsoft Fabric Migration FAQ**

  Answers common migration questions, covering timelines, required purchase/reassignment steps, capacity sizing, and cost/licensing differences. Clarifies viewer licensing thresholds, feature parity and gaps, expected downtime impacts (especially cross-region and large models), and governance carryover. Links to planning resources and tooling to help teams proceed with confidence.

  https://learn.microsoft.com/en-us/power-bi/support/premium-migration-faq

- **Migrate Workspaces From Power BI Premium to Microsoft Fabric**

  Delivers an end-to-end how-to for moving workspaces from P to F SKUs, including prerequisites, piloting, and two reassignment methods (admin portal and migration notebook). Details validation, monitoring, and decommissioning steps to minimize disruption. Provides special handling for cross-region moves, multigeo, and common troubleshooting scenarios.

  https://learn.microsoft.com/en-us/power-bi/support/premium-migration-how-to

- **Power BI Premium to Microsoft Fabric Migration Overview**

  Sets context for the P-to-F transition, outlining benefits of Fabric capacities and what changes versus stays the same. Describes the migration journey stages with recommended tools and options. Covers key scenarios (same region, cross-region, multigeo, cross-tenant) and offers post-migration guidance for cost, performance, and governance operations.

  https://learn.microsoft.com/en-us/power-bi/support/premium-migration-overview

## Major Changes

- **Previous monthly updates to Power BI Desktop and the Power BI service**

  Introduces the June 2026 update with broad enhancements across reporting, modeling, and visualization. Adds previews for Fabric Apps on semantic models and Copilot in web modeling, plus GA of Shape map and a new Date picker for slicers. Delivers modeling improvements like GA for DAX user-defined functions and result grid enhancements in DAX query view, along with new visuals and platform updates. These changes streamline authoring, expand analytical capabilities, and improve integration with enterprise workflows.

  https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-latest-update-archive

- **Conditional formatting in Power BI visuals**

  Expands conditional formatting to more visuals and legend scenarios, enabling consistent category colors and richer line chart styling. Adds practical DAX techniques to standardize color schemes across visuals and to ensure readable text based on background luminance. Removes prior limitations, giving report authors more control and consistency in data storytelling.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-conditional-formatting

- **Customize Power BI Visualization Titles**

  Reorients the article from procedural steps to a concise, configuration-focused guide for titles, subtitles, and spacing. Introduces a dedicated Divider and spacing area and documents July 2026 spacing behavior changes and automatic adjustments. Streamlines background and legend settings and encourages using theme defaults for consistency across reports.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-customize-title-background-and-legend

- **See What's New in the July 2026 Power BI Update**

  Refreshes the monthly summary with new features across reporting, modeling, mobile, embedded, and visualizations. Highlights Modern Visual Defaults (preview), legend/line chart conditional formatting, and a change to .pbix downloads from semantic models. Covers org app audience GA and related platform improvements, plus modeling updates like measure descriptions and service-side model options. This consolidation helps teams quickly identify impactful changes and adjust governance and development practices.

  https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new

- **Visual defaults in Power BI reports**

  Adds comprehensive guidance for customizing theme-level defaults, including colors, text, visual properties, page settings, and filter pane/card options. Clarifies how defaults apply across existing and new visuals and how visual-level changes take precedence. Includes exporting custom themes as JSON to promote reuse and governance of design standards.

  https://learn.microsoft.com/en-us/power-bi/create-reports/power-bi-reports-visual-defaults

- **CI/CD for org apps in Fabric**

  Updates CI/CD guidance to model org apps as artifact sets with audience support and a new Git representation. Documents the versioned schema (2.0.0) and audience artifacts, including structure, constraints, and full examples. These changes enable more robust automation, clearer governance, and repeatable deployments for org apps and their audiences.

  https://learn.microsoft.com/en-us/power-bi/developer/embedded/org-app-cicd

## Moderate Changes

- **Work with DAX query view**

  Added support for documenting measures using triple-slash (///) comments that persist to the model. Descriptions surface in tooltips across DAX query view, Model Explorer, and the Data pane, and carry into quick queries.

  https://learn.microsoft.com/en-us/power-bi/transform-model/dax-query-view

- **Download Power BI Desktop**

  Added guidance to match specific Desktop versions for scenarios like Report Server deployments and team alignment via the monthly archive. Includes steps to check the installed version to ensure parity with the service.

  https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-get-the-desktop

- **Publish semantic models and reports from Power BI Desktop**

  Clarified publishing to workspace folders and removed outdated “preview” wording while retaining how to enable the feature in Preview settings. Improves accuracy and reduces confusion during deployment.

  https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-upload-desktop-files

- **Use on-object interaction with visuals in your report (preview)**

  Explained UI differences when on-object interaction is enabled and how to toggle the preview feature. Helps users understand where controls moved and how to manage the setting.

  https://learn.microsoft.com/en-us/power-bi/create-reports/power-bi-on-object-interaction

- **Create a card visual in Power BI**

  Added steps to show full numbers by setting Display units to None in Callout values. Clarifies that K/M/B suffixes can come from automatic scaling and links to relevant troubleshooting.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-card

- **Export data from a Power BI visualization**

  Clarified export limitations for custom and R visuals, including tenant policy impacts and runtime constraints. Noted that programmatic export via the JavaScript API doesn’t support custom or R visuals.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-export-data

- **Tutorial: Get started creating in the Power BI service**

  Updated licensing guidance: free users can create in My workspace, while Pro or PPU is required to share or publish to shared workspaces. Aligns sign-up and sharing guidance to current licensing behavior.

  https://learn.microsoft.com/en-us/power-bi/fundamentals/service-get-started
