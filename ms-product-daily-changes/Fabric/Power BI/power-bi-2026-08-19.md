## New Articles

- **Edit Power BI Desktop project files in Visual Studio Code**

  Introduced a how-to for editing Power BI Desktop project (PBIP) files in Visual Studio Code and reloading changes back into Power BI Desktop. Covers prerequisites (August Desktop or later, enabling PBIP save, and installing VS Code) and how to open the PBIP folder from Desktop. Explains save behavior, detection of external edits with an “Apply external changes” banner and overwrite warnings, and an option to reload via the Power BI Desktop Bridge. Details key limitations and considerations, including Bridge preview status, PBIP-only scope (not PBIX), full reload behavior, unsupported files, cache/UI resets, and handling unapplied changes. Includes links to related project and Bridge documentation.

  https://learn.microsoft.com/en-us/power-bi/developer/projects/projects-external-editing

## Moderate Changes

- **Compare Power BI Report Server and the Power BI service**

  Updated the Deployment row to clarify that Power BI Report Server can be deployed in Azure VMs (hosted cloud) and to centralize licensing details in the licensing section. This streamlines guidance by removing explicit prerequisites and helps readers quickly understand deployment options and where to confirm licensing requirements.

  https://learn.microsoft.com/en-us/power-bi/report-server/compare-report-server-service

- **Move your Power BI tenant to a different region**

  Expanded post-remap steps to verify the new home region using the “Find the default region for your organization” article and clarified that propagation can take up to one hour. Removed the expectation that support will confirm migration completion; tenant restoration requirements are unchanged, improving self-service verification and setting accurate timelines.

  https://learn.microsoft.com/en-us/power-bi/support/service-admin-region-move
