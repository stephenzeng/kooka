# Power BI
**Date created:** 2026-09-04 UTC  
**Tags:** Governance, Guidance, Security  

## Major Changes

- **Manage semantic model access permissions**

  Elevated the permissions experience from two tabs to three by introducing Access via related items, refining Direct access, and renaming Shared report links to Links. Clarified how effective access is derived (workspace roles, app audiences) and which permissions can be granted or edited (Reshare, Build, Write, Access), with updated steps to reach the Manage permissions page from OneLake or the model’s details page. Provided explicit guidance for managing app-granted permissions through the app’s Audience tab, including what happens after republishing and how to clean up residual permissions. Expanded descriptions for the Links tab (what’s shown and the effect of deleting links) and added instructions to review and remove access granted through related items like org apps.

  https://learn.microsoft.com/en-us/power-bi/connect-data/service-datasets-manage-access-permissions

## Moderate Changes

- **Explore reports in the Power BI mobile apps**

  Updated footer actions guidance: Rotate view now appears in the footer, works even when device orientation lock is on, and the footer shifts to the side when rotated. Clarified action availability and counts by orientation, streamlined page navigation tips, removed the comments pane action, and noted that Rotate view only shows if at least one visible page isn’t mobile-optimized.

  https://learn.microsoft.com/en-us/power-bi/explore-reports/mobile/mobile-reports-in-the-mobile-apps

- **What's new in the mobile apps for Power BI**

  Added an August 2026 entry announcing that Rotate view moved from the actions menu to the report footer, enabling one-tap switching between portrait and landscape even with orientation lock enabled. The update improves usability especially for reports without mobile-optimized layouts and links to detailed footer action guidance.

  https://learn.microsoft.com/en-us/power-bi/explore-reports/mobile/mobile-whats-new-in-the-mobile-apps
