# Power BI
**Date created:** 2026-08-10 UTC  
**Tags:** Analytics  

## Major Changes

- **Embed a report web part in SharePoint Online**

  Added support for embedding individual visuals in addition to full reports within SharePoint Online, enabling more granular sharing scenarios. Updated the web part workflow to let users browse workspaces and reports or paste a URL, and to select a specific report page and a single visual. Introduced new web part settings, including Show Action Bar and Show in mobile or email view, to tailor the viewing experience. Expanded troubleshooting for load failures (including when content is deleted) and clarified permission and licensing guidance to cover all embedded Power BI content.

  https://learn.microsoft.com/en-us/power-bi/collaborate-share/office-integration/service-embed-report-spo
