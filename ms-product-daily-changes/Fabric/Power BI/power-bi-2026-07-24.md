# Power BI
**Date created:** 2026-07-24 UTC  
**Tags:** Administration, Analytics, Other  

## Major Changes

- **Power BI report data sources in Power BI Report Server**

  Added guidance explaining that Access and Excel data sources rely on the Microsoft Access Database Engine (ACE) OLE DB provider for reading .accdb/.mdb and .xls/.xlsx, including scheduled refresh on the report server. Announced that starting with the Power BI Report Server September 2026 release, ACE is no longer installed by setup and must be installed separately by administrators. Clarified that this requirement also applies to paginated (.rdl) reports using OLE DB, helping admins plan deployments and avoid refresh or connectivity failures.

  https://learn.microsoft.com/en-us/power-bi/report-server/data-sources
