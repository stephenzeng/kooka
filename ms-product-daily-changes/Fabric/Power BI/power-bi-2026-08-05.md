# Power BI
**Date created:** 2026-08-05 UTC  
**Tags:** Analytics  

## New Articles

- **Apply conditional formatting to chart lines and legends in Power BI**

  Introduced comprehensive guidance for applying conditional formatting to chart lines, segments, markers, and legend categories. The article includes a ready-to-run TMDL script and step-by-step scenarios such as fading prior-year lines, using value-based gradients on segments and shaded areas, highlighting min/max markers via DAX, and syncing legend colors across visuals. It also shows how to keep measure colors consistent with field parameters and a color column, and documents key limitations. This helps creators produce clearer, on-brand visuals and emphasize insights directly in charts.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-conditional-formatting-chart-line-legends

## Moderate Changes

- **View Power BI Reports Optimized for Your Phone**

  Added guidance on exporting data from supported visuals to Excel in the Power BI mobile apps, including export steps, file behavior, and data limits (up to 150,000 intersections for tables/matrices or 150,000 rows for summarized data). The export honors the same permissions, tenant settings, sensitivity labels, and RLS as the Power BI service, with tips to ensure the export option is available and successful.

  https://learn.microsoft.com/en-us/power-bi/explore-reports/mobile/mobile-apps-view-phone-report

- **What's new in the mobile apps for Power BI**

  Added an August 2026 entry announcing Excel export from supported report visuals in the mobile apps. Exports are static snapshots and follow the same governance, security, and export limits as the Power BI service, enabling controlled data sharing on the go.

  https://learn.microsoft.com/en-us/power-bi/explore-reports/mobile/mobile-whats-new-in-the-mobile-apps

- **Line charts in Power BI**

  Updated documentation to reflect that line charts now support conditional formatting for line colors, shaded areas, and markers, with a link to how-to guidance. This enables richer visual emphasis and consistent styling directly within line charts.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-line-chart
