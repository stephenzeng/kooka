# Power BI
**Date created:** 2026-07-22 UTC  
**Tags:** AI, Analytics  

## Moderate Changes

- **Optimize your semantic model for Copilot in Power BI**

  Added guidance that in the Power BI service’s web modeling experience, Copilot can propose and apply schema updates such as renaming tables/columns, creating relationships, and generating DAX measures. Clarified that clear naming and a well-structured model improve Copilot’s recommendations and results.

  https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-evaluate-data

- **Use Copilot with semantic models**

  Introduced a section on Copilot in the Power BI service Model view that analyzes semantic models, flags issues, and suggests best-practice improvements. Users can apply schema updates directly (renames, relationships, measures), with accepted changes affecting the active model; optimizing models enhances suggestion quality.

  https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-semantic-models

- **Use field parameters to let report readers change visuals**

  Clarified how to place column-based parameters in axis wells and measure-based parameters in values, including support for multiple measures when visuals allow. Added slicer guidance to toggle between field names and values via the Build pane, noted hierarchy slicer behavior, and explained that showing values applies only to column-based parameters.

  https://learn.microsoft.com/en-us/power-bi/create-reports/power-bi-field-parameters

- **Data refresh in Power BI**

  Expanded refresh guidance to cover both Desktop and the Service, explaining that refresh begins with schema sync followed by data refresh. Added a “Refresh schema and data” option, documented table-level control for schema/data refresh, and updated visuals and descriptions to match the new menu.

  https://learn.microsoft.com/en-us/power-bi/connect-data/refresh-data

- **Download a report from the Power BI service to Power BI Desktop**

  Updated guidance to clarify that downloading from a semantic model provides a report. Removed the outdated note about downloads producing an empty report.

  https://learn.microsoft.com/en-us/power-bi/create-reports/service-export-to-pbix
