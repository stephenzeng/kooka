# Power BI
**Date created:** 2026-08-26 UTC  
**Tags:** Analytics, Configuration, Guidance  

## Moderate Changes

- **Using calculated columns in Power BI Desktop**

  Updated guidance to note that Direct Lake on OneLake now supports unmaterialized calculated columns in User Context (preview). The preview evaluates columns at query time, supports user-context functions, and disallows using these columns in relationships. Expressions that don’t reference user-aware functions or secured columns behave like standard DAX calculated columns.

  https://learn.microsoft.com/en-us/power-bi/transform-model/desktop-calculated-columns

- **Slicers overview in Power BI**

  Added a section that explains how to enable the “Select all” option and clarifies its behavior. Selecting “Select all” results in no filter, and clearing items after that applies an inverted “is not” filter, including values affected by other slicers and new values added on refresh. The same inverted selection logic applies to the Filters pane with Basic filtering, with a link to troubleshooting.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-slicers

- **What's new in Power BI? August 2026 update**

  Introduced the Direct Lake calculated columns (Preview) feature in What’s New. You can define DAX calculated columns in web modeling and Power BI Desktop for Direct Lake OneLake semantic models without changing storage mode, with columns evaluated at query time. The update highlights support for user-context functions and links to the detailed documentation.

  https://learn.microsoft.com/en-us/power-bi/fundamentals/whats-new
