# Power BI
**Date created:** 2026-08-14 UTC  
**Tags:** Configuration, Guidance, Governance, Identity, Security  

## Major Changes

- **Microsoft Entra SSO**

  Added detailed guidance for enabling Microsoft Entra SSO with the virtual network (VNet) data gateway, including tenant-level steps in the Fabric admin portal. Clarified that the enforcement setting is evaluated during create or update operations rather than at query runtime, helping admins plan safe rollouts. Replaced the prior public preview note with a clear support statement and expanded explanation of identity flow and authorization. Also improved wording and setting names for enabling Entra SSO on on-premises data gateways and reinforced least-privilege recommendations.

  https://learn.microsoft.com/en-us/power-bi/connect-data/service-gateway-azure-active-directory-sso

## Moderate Changes

- **Understand translytical task flows**

  Documented a new limitation: data function buttons don’t automatically rebind when reports move across workspaces, because they retain explicit references to their original workspace, function set, and data function. Updated guidance instructs teams to re-point the button’s data function in the target report after deployment, with references to related deployment pipeline and cross-workspace binding guidance.

  https://learn.microsoft.com/en-us/power-bi/create-reports/translytical-task-flow-overview
