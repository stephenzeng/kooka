## New Articles

- **Share live visuals in Outlook (preview)**

  Introduced a preview capability to share live, interactive Power BI visuals in Outlook on the web and Microsoft Loop via Loop components. Covers prerequisites, tenant configuration for admins to enable sharing of visuals as Loop components, and the user workflow to generate a link (with optional current view) that renders as a live component. Highlights access requirements for recipients and key limitations such as Outlook on the web support, up to five visuals per email/page, potential rendering delays, unsupported narrative visuals, lack of rendering in Loop tables, and no support for visual-specific custom backgrounds.

  https://learn.microsoft.com/en-us/power-bi/collaborate-share/office-integration/share-live-visuals-outlook-loop

## Moderate Changes

- **Share access to a semantic model**

  Updated guidance on sharing semantic models, adding a prerequisites section that calls out the need for Reshare permission and clearer steps to open the Share dialog from OneLake or the model details page. Clarified permission options by mapping checkboxes to permission sets (including default Read when all are cleared) and noted that access is granted immediately after selecting Grant access. Screenshots and UI descriptions were refreshed to match the current experience.

  https://learn.microsoft.com/en-us/power-bi/connect-data/service-datasets-share
