# Power BI
**Date created:** 2026-08-22 UTC  
**Tags:** Configuration, Guidance, Security  

## Moderate Changes

- **Summarize a report with Copilot**

  Updated guidance explains that Copilot can reference visuals that are initially hidden but revealed through display-only report bookmarks, maintaining report state, honoring RLS/OLS, and citing the correct visual. Added a limitations section clarifying that only display-only bookmarks are supported, they must be accessible via a bookmark button or navigator, personal bookmarks aren’t supported, and visuals on hidden pages are excluded unless made visible by a report bookmark. Clarified availability for the Copilot button, requiring an eligible workspace on paid dedicated Fabric capacity.

  https://learn.microsoft.com/en-us/power-bi/explore-reports/copilot-pane-summarize-content
