# Power BI
**Date created:** 2026-08-07 UTC  
**Tags:** Analytics  

## Moderate Changes

- **Bookmarks in the Power BI service**
  
  Updated guidance on personal bookmarks: added a global cap of 2,000 across all reports (while keeping the 20-per-report limit) and introduced a six-month expiration policy. Clarified that creating or updating personal bookmarks is only supported when viewing a report. Revised export guidance to use a report bookmark so hidden visuals remain hidden in exports.
  
  https://learn.microsoft.com/en-us/power-bi/explore-reports/end-user-bookmarks
