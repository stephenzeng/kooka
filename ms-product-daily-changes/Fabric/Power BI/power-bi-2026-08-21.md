## New Articles

- **Use OneLake image and map files in Power BI reports**

  Introduced a how-to guide for storing image and shape map files in OneLake and using their authenticated URLs across Power BI visuals. Explains prerequisites, how to upload to a Fabric lakehouse, copy OneLake HTTPS URLs, and reference them via format pane settings, Image URL fields, or DAX. Details supported scenarios (image and card visuals, table/matrix/slicer images and icons, Azure Maps SVG markers, and Shape Map custom maps) and how to grant viewer access with Microsoft Entra permissions. Highlights considerations such as supported image types, the impact of moving or renaming files on URLs, performance tradeoffs for large images, limits for anonymous embeds, and deployment pipeline behavior.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-onelake-files

## Major Changes

- **Previous monthly updates to Power BI Desktop and the Power BI service**

  Added the July 2026 update entry with broad enhancements across reporting, modeling, org apps, and APIs. Highlights include modern visual defaults customization, GA for conditional formatting in charts and legends, improved navigation, and org app audiences/bookmarks/Storytelling with CRUD APIs. Modeling adds measure description improvements, new service-side model options, and a semantic model settings pane. Also notes SharePoint Online embedding improvements and mobile support for app audiences.

  https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-latest-update-archive

- **Use report themes in Power BI**

  Revamped built-in themes, removing legacy entries and adding new options like “Reset to default” and “Copilot default,” with organizational control over the default theme. Rewrote guidance to use the Theme pane in Desktop and Service for selecting, updating, importing, and exporting themes. Clarified that applying a built-in or custom theme replaces existing customizations and pointed to Visual defaults for deeper configuration.

  https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-report-themes

- **Visual defaults in Power BI reports**

  Updated guidance to make Fluent 2 the default base theme and removed preview instructions. Shifted all customization to the Theme pane, covering theme settings, colors, text, visual properties, and page defaults. Clarified canvas and background defaults and simplified related sections, including export steps from the Theme pane.

  https://learn.microsoft.com/en-us/power-bi/create-reports/power-bi-reports-visual-defaults

- **Matrix visual format settings**

  Substantially expanded and reorganized the formatting guide with practical tips and clearer layout controls. Introduced freeze options and new column width behaviors (Fit to content, Grow to fit, Fixed width) with default and per-column settings. Added customization for +/- icons, restructured text/options across headers and values, streamlined URL icon guidance, and enhanced cell elements with custom icons including OneLake URLs. Added a comprehensive Sparklines section covering chart types, colors, widths, and markers.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-matrix-visual-format-settings

- **Slicer visual in Power BI**

  Promoted the Date picker to general availability and added a Single date option for stricter selection control. Introduced richer formatting, including selection icon color, hierarchy icon customization with conditional formatting, and expanded dropdown styling (borders, corners, open icon, and an accent bar). Updated structure and references to align with the new capabilities.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-slicer-visual

- **See What's New in the August 2026 Power BI Update**

  Overhauled the monthly update with new Copilot/AI guidance, including permissions updates and bookmark-aware Copilot behavior. Reporting highlights include GA for modern visual defaults, slicer date picker improvements, donut center values, matrix enhancements, OneLake image URLs across visuals and maps, outer padding controls, Azure Maps performance, and richer dropdown/hierarchy styling. ## Moderate Changes

- **Summarize a report with Copilot**

  Clarified how Copilot summaries account for visuals shown via display-only bookmarks without changing the bookmark state. Reinforced that RLS and OLS permissions continue to govern what Copilot can access.

- **Apply conditional formatting in tables and matrices**

  Added guidance for displaying custom icons using the Field value style with image URLs, including support for OneLake file links and anonymously accessible web URLs. Listed supported image formats and provided an example OneLake URL pattern to speed adoption.

  https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-conditional-table-formatting

- **Create a relative date slicer and filter in Power BI**

  Updated to reflect the Date picker slicer’s general availability and removed preview-only instructions and limitations. Core how-to guidance remains unchanged for calendar/slider selection and anchor options.

  https://learn.microsoft.com/en-us/power-bi/visuals/desktop-slicer-filter-date-range

- **Display images in a table, matrix, or slicer in a report**

  Added steps for using OneLake-hosted image URLs in Image URL fields and updated considerations to allow OneDrive for home embed codes and OneLake links as authenticated exceptions. Clarified that other authenticated hosts aren’t supported and noted that mobile now displays OneLake file links.

  https://learn.microsoft.com/en-us/power-bi/create-reports/power-bi-images-tables

- **Create a card visual in Power BI**

  Updated to reflect general availability of the new card visual and clarified ongoing behavior/formatting refinements. Noted Fluent 2 as the default base theme and added support for image URLs including OneLake-hosted files.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-card

- **Customize x-axis and y-axis properties**

  Renamed and broadened layout guidance to cover more chart types and added detailed controls for outer padding and spacing between categories/series. Included tips for filling the plot area and clarified that “Overlap series” applies to bar and column charts.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-customize-x-axis-and-y-axis

- **Export Data From a Power BI Visualization**

  Added instructions for exporting visual data from the Power BI mobile apps, using focus mode or the More options menu. Exports use the supported Excel format and honor current filters, slicers, drill state, and RLS, with device sharing options for opening or distributing the file.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-export-data

- **Create an image visual in Power BI**

  Expanded the Enter URL option to support OneLake file links alongside anonymously accessible web URLs, with Power BI handling authentication. Clarified that you can replace the image without recreating the visual.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-image-visual

- **Create a matrix visual in Power BI**

  Enhanced expand/collapse guidance to include row and column headers, with options to customize +/- icon color and size. Added auto-expand controls and clarified default freeze behavior via the Layout > Freeze toggle and how transient freeze works during viewing.

- **Create and use pie and donut charts in Power BI**

  Introduced the donut chart center value, which updates with filtering, highlighting, and drilling, and supports custom measures. Added formatting options for value display, labels, fonts, and backgrounds, plus considerations for when the center value appears.

  https://learn.microsoft.com/en-us/power-bi/visuals/power-bi-visualization-pie-donut-chart

- **Visualizations overview in Power BI**
