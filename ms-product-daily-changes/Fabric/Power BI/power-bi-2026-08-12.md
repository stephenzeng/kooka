# Power BI
**Date created:** 2026-08-12 UTC  
**Tags:** Configuration, Monitoring  

## Moderate Changes

- **Data refresh in Power BI**

  Updated guidance clarifies how to configure refresh failure notifications, including adding individual recipients and noting that mobile push notifications don’t support group aliases. It also states that on-demand and programmatically triggered refreshes (such as via Power Automate) don’t send email alerts, helping admins set accurate expectations and monitoring.

  https://learn.microsoft.com/en-us/power-bi/connect-data/refresh-data
