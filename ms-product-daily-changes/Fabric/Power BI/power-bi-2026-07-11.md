# Power BI
**Date created:** 2026-07-11 UTC  
**Tags:** AI, Administration  

## Moderate Changes

- **Enable Fabric Copilot for Power BI**

  Updated guidance to emphasize that Copilot enablement is tenant-wide across all Fabric workloads, while this article covers Power BI-specific configuration. The Copilot setting is now enabled by default and can be disabled or scoped to specific users, replacing prior “toggle on” instructions. This helps admins streamline governance while targeting access where needed.

  https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-enable-power-bi

- **Use Copilot with semantic models**

  Revised capacity requirements: Power BI Desktop must connect to a workspace in paid Fabric capacity (F2+) or Power BI Premium (P1+), while Copilot remains usable with semantic models in Pro or PPU workspaces. The requirement applies regardless of where the semantic model itself is hosted, clarifying setup for mixed-capacity environments.

  https://learn.microsoft.com/en-us/power-bi/create-reports/copilot-semantic-models

- **Install Power BI Desktop for Power BI Report Server**

  Clarified virtualization support: Azure Virtual Desktop and Windows 365 are fully supported, while Citrix VDI and other non-Azure/Windows 365 environments aren’t supported. This guidance helps teams choose compliant virtualization platforms and avoid unsupported deployments.

  https://learn.microsoft.com/en-us/power-bi/report-server/install-powerbi-desktop
